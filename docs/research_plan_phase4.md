# 研究計画（第 4 期）：非トーラス結び目の [2,1] を決める原理と、3 箱の検証の拡張

作成：2026-10-06。背景は docs/REPORT_phase3.md と docs/open_problems.md。ステージ記号は V0〜V6。
長時間の計算は CLAUDE.md の規則（見積もり、高速化、再開、分割と並列、独立プロセス）に従い、準備の内容を実行前に progress.md に書く。

---

## 0. 出発点

- 3 箱の正値性は、[2,1] が定義どおりに得られる範囲（トーラス結び目 5 個 + KN の表、代数的な iterated torus 4 個）で全て成立した（第 3 期）。
- 非トーラス結び目の [2,1] は、t = q、ミラー対称性、EGP、U(2) への簡約、Laurent 性、G 展開、正値性を課しても一意に決まらない（三葉結び目で解の差の階数 6）。文献にも定義に基づく入力は無い。
- したがって、KN を超えた 3 箱の検証を双曲結び目に広げるには、**[2,1] を決める追加の原理**が要る。これが第 4 期の主題。
- 並行して、計算基盤の高速化を行う。

計算機：8 コア（性能 4、効率 4）、メモリ 8 GB。K9 の 3 箱で 2.1 GB を使ったので、重い計算の並列数はメモリで制限される。

## 1. ステージ

### V0：計算基盤の高速化と再開性（他のステージの前提）

- 現状の重い部分：`reformulated_exact`（n = 3）は評価点ごとに \hat f を数値計算し、2 素数で補間する。単一プロセスで、途中結果を保存しない（K9 で 4 時間）。
- やること
  1. 評価点のまとまりと素数ごとに計算を分割し、`multiprocessing` で並列化する。各まとまりの結果を data/cache/ に保存し、再開時は読み込む。
  2. 小さい例（T(2,3)、K1）で、並列版が従来の結果と全係数で一致することをテストにする。
  3. 時間とメモリを測り、並列数とメモリの関係を記録する（8 GB で何並列まで可能か）。
- K8・K7 は現在の独立プロセスで続ける。V0 の完成が先なら、K7 は並列版で計算し直す（K8 の rCS は data/cables/ に保存済みの分を再利用）。
- 第 3 期の残り：2 段の反復ケーブル（(2,13)-ケーブルの (2,53)-ケーブル、代数的）の 3 箱を、見積もりの後に並列版で計算する。

### V1：（削除、2026-10-06）

### V2：[2,1] を決める追加の原理（主題）

候補の原理を一つずつ、正解の分かる結び目（T(2,3), T(2,5), T(2,7), T(3,4), 4_1 の KN の候補）で検証し、整数計画（`scripts/u3_21.py`）の解の自由度がどれだけ減るかを測る。

1. **解の空間の構造の解析**：解の差（核）の基底を求め、因子の形（t = q、q = ±1、t = ±1、a = ±t² の因子と、残る自由な部分）を明らかにする。必要な追加条件の数の見積もりになる。
2. **他の特殊化**：a = t³（U(3)）、a = t⁻¹ や a = q^{±1}（supergroup 型）で、[2,1] と低い彩色の間に恒等式があるかを正解のデータで探す（U(2) の恒等式を見つけたのと同じ方法）。
3. **An. Morozov の一次ずれの公式**（1211.4596）：[2,1] について一次の制約として加える。
4. **refined の微分展開**：Morozov らのツイスト結び目の [2,1] 彩色 HOMFLY-PT の微分展開（1612.00422 など）に refined の Z 因子を入れた形を仮定し、その仮定の下で一意に決まるかを調べる（文献の原典で式を確認してから）。
5. **AMMM の 4_1 の候補（1211.6375）と KN の候補の比較**：両者が同じか、整数計画の解の集合のどこにあるか。

- 判定：ある原理の組で、トーラス結び目の [2,1] が一意に再現されれば、その原理を双曲結び目（4_1, 5_2, 6_1 などのツイスト結び目、6_3）に適用し、3 箱の正値性を判定する。
- **停止点 1**：V2 の 1〜5 の較正結果を報告する（一意に決まる原理の組が見つかったか）。

### V3：恒等式と正規化の導出（解析的）

- U(2) への簡約の恒等式（a = t² で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}）を、refined CS の主特殊化（a = t^N）から導く。
- V2 の 2 で見つかった恒等式も同様に導く。
- ケーブルの単項式正規化 (N1)(N2') を DAHA/EHA から導く（open_problems D1）。

### V4：2 箱の正値性の証明（ツイスト結び目）

- NRZS の二重和の式と t_c 次数（δ' = −S）から、ツイスト結び目の [2], [1,1] の \hat f を閉じた形で書き、G 展開の係数の正値性を示すことを試みる（open_problems B1）。
- 証明できない場合は、計算の範囲（p = −12〜12）を明記して予想として書く。

### V5：双曲結び目の 3 箱（V2 で原理が見つかった場合のみ）

- 入力：[1]（yui-kr）、[2], [1,1], [3], [1,1,1]（予想式、t_c 次数は δ' = −S）、[2,1]（V2 の原理）。
- 判定は G 展開の前後。正値性が自明に従わないこと（入力の別の割り当てで負になること）も確かめる。
- **停止点 2**：最初の 2〜3 結び目の結果を報告する。

## 3. リスク

- V2 で一意に決まる原理の組が見つからない：その場合、双曲結び目の 3 箱は「正の候補の存在」までにとどまる。解の集合の構造（V2-1）を成果としてまとめ、どの追加の構造が要るかを明確にする。
- 微分展開（V2-4）は予想に基づく仮定。採用する場合は【仮説】と明記し、トーラス結び目で正解を再現することを条件にする。
- メモリ 8 GB：重い計算の並列数は 2〜3 が上限の見込み（V0 で測る）。
