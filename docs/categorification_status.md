# 非代数的なケーブル K2, K4, K5a, K5c, K6b の [1]：圏化・ホモロジー化の状況（2026-10-05）

対象：T(2,3) の (2,1), (2,3), (2,5), (2,−1)-ケーブル（K2, K4, K5a, K5c）と T(2,5) の (2,1)-ケーブル（K6b）。
彩色は [1]（非彩色）。[1] では \hat f_{[1]} = (a^{1/2} − a^{−1/2}) rCS_{[1]} なので、refined LMOV 不変量の正値性は superpolynomial の正値性と同値に近い（CLAUDE.md）。
計算の詳細は docs/progress.md の 2026-10-05 の各節。文献情報は arXiv の概要で確認したものだけを書く。

## 1. 圏化・ホモロジー化の方向性

| 方向 | 対象 | 性格 | [1] の非代数的なケーブルへの適用 |
|---|---|---|---|
| (A) HOMFLY-PT ホモロジー（Khovanov–Rozansky） | 三重次数のホモロジー | 定義されたホモロジー論。行列因子化（Khovanov–Rozansky, math/0505056）、Soergel 双加群（Khovanov, math/0510265） | 定義はある。計算例は §2 |
| (B) sl(N) ホモロジー、Khovanov（N = 2）、knot Floer（「N = 0」） | 二重次数のホモロジー | 定義されたホモロジー論。(A) から sl(N) へのスペクトル系列がある（Rasmussen, math/0607544） | Kh と HFK は本研究で計算（§2） |
| (C) superpolynomial（Dunfield–Gukov–Rasmussen, math/0505662） | 正の整数係数の三変数多項式 | (A) の Poincaré 多項式を、微分 d_N と対称性などの構造から組み合わせ的に決める（予想に基づく構成） | 本研究で候補を構成（§3） |
| (D) refined CS / DAHA / 楕円 Hall 代数 | 三変数の多項式 | ホモロジーではなく代数的な構成。ケーブルは Cherednik–Danilenko（1408.4348）の DAHA 構成 | 本研究のケーブルの計算はこれ（§4） |
| (E) 平面曲線特異点の Hilbert スキーム | 重み多項式 | 代数的な結び目（特異点の絡み目）に限った幾何的な予想（Oblomkov–Rasmussen–Shende, 1201.2115） | 非代数的な結び目には特異点がなく、適用できない |
| (F) 物理（M2–M5 の BPS 状態、refined LMOV） | \hat N_{ρ,g,β,J_r} | KN（1703.05408）はトーラス結び目で (D) から読み、正値性を予想 | 本研究の判定の対象 |

トーラス結び目では、(A) は Hogancamp–Mellit（1909.00418）が正のトーラス絡み目について計算している。(D) との一致は KN が前提としている（本研究では直接は確認していない）。

## 2. 正統なホモロジー（(A), (B)）での計算例

- (A) HOMFLY-PT ホモロジーそのもの：対象の 5 結び目の計算例は見つからなかった。
  - 直接計算の最大の例は Nakagane–Sano（2111.00388）の 11 交点以下の素な結び目である。今回のケーブルのブレイド表示は 13〜29 交点で、表に含まれない（交点数そのものは未確認）。
  - 同じプログラム（yui-kr）を使えば計算できる可能性があるが、Rust が無いので未導入。
- (B) 本研究で直接計算した（data/homology/）。
  - reduced Khovanov（khoca、F_101）：全ケーブルで thick（δ が 3〜5 値）。総階数は K2 15, K4 13, K5a 11, K5c 17, K6b 39。
  - knot Floer（snappy）：総階数は K2 7, K4 5, K5a 5, K5c 9, K6b 15。L-space 結び目は K4, K5a（K2, K5c, K6b は違う）。
  - 文献の計算例：Anokhina–Morozov–Popolitov（2104.14491）が 2 本ケーブルの Khovanov 多項式を扱うが、対象の 5 結び目が含まれるかは未確認。
  - sl(N), N ≥ 3 は未計算（khoca の結果が自明な結び目で不正だったため）。

## 3. Gukov らの手法による superpolynomial（(C)）の計算例

- 文献：対象の 5 結び目の superpolynomial は見つからなかった（検索の範囲で）。
- 本研究の構成（scripts/construct_superpolynomial.py、data/superpoly/）：整数計画で総階数が最小の候補を探した。条件は次のとおり。
  - 𝐭 = −1 で HOMFLY-PT になる。
  - d_{±1} で 1 項だけ残る。
  - d_2 のホモロジーが Khovanov ホモロジー、d_0 のホモロジーが knot Floer ホモロジーになる。
  - DGR の対称性（Gorsky–Hogancamp–Mellit 2103.01212 が証明）を満たす。
  - 検証：T(2,3), K1, K3, K5b では候補が DAHA の不変量と全項で一致する。
  - 結果：5 結び目すべてで正の候補が存在する。

  | 結び目 | 総階数 | 一意性（乱数の目的関数 5 通り） | [1] の \hat f：G 展開の前 / 後 | 2J_r の偶奇 |
  |---|---|---|---|---|
  | K4 | 27 | 同じ解 | 正 / 正 | そろわない |
  | K2 | 41 | 同じ解 | 正 / 正 | そろわない |
  | K5c | 47 | 同じ解 | 正 / 正 | そろわない |
  | K5a | 77 | 別の解が 5 個（どれも正 / 正） | 正 / 正 | そろわない |
  | K6b | 289（狭い格子） | 未検査 | 正 / 正 | そろわない |

- 注意：d_2, d_0 がそれぞれ単独でホモロジーを与えることは DGR の予想で、thick な結び目では成り立たない可能性がある。したがってこれは候補であり、(A) の計算ではない。

## 4. ケーブルの計算（(D)）は上と整合するか

| 検査 | 代数的なケーブル・K5b | K2, K4, K5a, K5c, K6b |
|---|---|---|
| t = q で HOMFLY-PT（ブレイドの HOMFLY-PT と照合） | 整合 | 整合 |
| Euler 標数（Jones 多項式・Alexander 多項式、khoca・snappy の値） | 整合 | 整合 |
| DGR の対称性（GHM が証明） | 整合（ずれなし） | 整合（ずれなし） |
| 正の整数係数（[1] では homological な不変量に必須） | 整合 | **不整合**（負の項あり） |
| Rasmussen のスペクトル系列の必要条件 P(𝐚=𝐪²) − Kh = (1+t)Q, Q ≥ 0 | 整合（t のずれ 0） | **不整合** |
| (C) の候補との一致 | 一致（K1, K3, K5b, T(2,3)） | **不一致** |

- まとめ：非代数的な 5 結び目の [1] では、ケーブルの計算（DAHA）は Euler 標数のレベル（HOMFLY-PT・Jones・Alexander）と対称性までは (A)–(C) と整合する。正値性とスペクトル系列のレベルでは整合しない。したがって、DAHA の不変量はこれらの結び目の HOMFLY-PT ホモロジーの Poincaré 多項式ではない【計算＋Rasmussen の定理】。
- DAHA と (C) の候補の関係：
  - K4 では、候補は DAHA の負の項 −c·m を +c·m·𝐭^{−1} に置き換えたものである。DAHA の値は、候補の一部の生成元で 𝐭^{−1} を −1 に置き換えた「部分的な Euler 標数」になっている。
  - これは CD14 が Cab(5,2)T(3,2) の Khovanov 多項式で観察した「−1 ↦ 1/t」と同じ型である。K5c も大部分がこの型で、K2, K5a, K6b ではこの置き換えだけでは足りない。
- 1703.05408 の立場との関係：(C) の候補では [1] の refined LMOV 不変量が G 展開の前後とも正になる。2J_r の偶奇がそろわない点は KN の 4_1 と同じである。KN が非トーラス結び目で superpolynomial（(C)）を使ったのと同じ枠組みに入る。負になるのは (D) を使った場合に限られる。
- 未解決：
  - (A) の直接計算（yui-kr）による候補の確認。
  - K5a, K6b の候補の一意性。
  - DAHA の値を (C) の候補の特殊化として説明する規則（CD14 の「−1 ↦ 1/t」の一般化）。
