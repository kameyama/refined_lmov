## 0. 結論

1. **双曲結び目の [2,1]（sl(3) 随伴を含む）の彩色ホモロジーを計算した例は、ホモロジー側の文献に一つも見つからなかった**【本文検索の範囲で】。
   [2,1] を含む構成（Cautis 1611.09924、Elias–Hogancamp 1801.00191、Cautis 1207.2074、Rose 1109.1745、Webster 1309.3796）の計算例は、**自明な結び目**（と 2 本のトーラス絡み目）に限られる。
   [2,1] のホモロジーの具体値として文献にあるのは、三葉結び目の [2,1] 三重次数ホモロジー（GGS 1304.3481、構造的な性質から決めた予想、41 生成元）だけ。
2. **非 minuscule の彩色（[2,1]、sl(3) 随伴）では、射影子で作るホモロジーは無限次元になる**【明記】。
   自明な結び目の sl(3) 随伴ホモロジーは、ホモロジー次数の無限列に台をもつ（Rose 1109.1745、Cautis 1207.2074）。Webster も有限次元性は minuscule でしか分からないと明記している。
   したがって「Poincaré 多項式」ではなく、t の冪級数（有理関数）になる。KN の rCS（index）と比べるには正規化の規則が要る（W3）。
3. **計算ソフトで [2,1]・sl(3) 随伴・射影子に対応するものは無い**【README・論文・ウェブページの範囲で】。
   sl(3) の彩色なしホモロジーなら KnotJob（Java）と FoamHo（C++、入手先は未確認）で計算できる。khoca は sl(N)（N>2）では bipartite な結び目に限られる。yui-kr は彩色なしの HOMFLY-PT のみ。
4. **W2 の見通し**【導出・推測】
   - HOMFLY-PT（a 依存性あり）の [2,1]：4_1 の 3 本ケーブル（9 本・ブレイド長 36）に射影子を入れた複体が要る。yui-kr の規模（家庭用の計算機でブレイド長 13 まで）を大きく超えるので、8 コア・8 GB では現実的でない。局所的な（タングルごとの）Soergel 双加群の計算プログラムを新しく作る必要があり、研究規模の開発になる。
   - sl(3) 随伴（N = 3 の断面だけ）：Rose の定理により、随伴射影子は 2 本の撚りの極限なので、「4_1 の反平行 2 本ケーブル＋k 回の full twist」（16 + 2k 交点）の彩色なし sl(3) ホモロジーを既存ソフト（KnotJob）で計算すれば、安定な範囲で近似できる。規模は小さい（分〜時間の見込み）。ただし導入に許可が要る。また得られるのは sl(3) の断面だけで、無限級数の打ち切りである。

### 補足：(iii) KN の rCS（index）との対応について文献から言えること
- 射影子による構成（Cautis・Rose・Webster・EH）では、**[2,1] の自明な結び目でさえホモロジーは無限次元**で、Poincaré 級数は分母をもつ有理関数になる【明記：Rose `:5695-5703`、Cautis 1207.2074 `:1999`、Webster `:9547-9550`】。
  KN の unreduced な rCS も、Macdonald 次元の分母をもつ有理関数である。そのため、**自明な結び目どうしの比較（射影子の Poincaré 級数 vs KN の refined 次元）**が、index と Poincaré の対応を調べる最も安い試験になる【推測】。比べる対象は、Cautis 1207.2074 `:1999`（sl_m 随伴、m = 3）、GNR 1608.07308 `:6317-6354`（[2,1] のタブローの End(P_T)、予想）、KN の [2,1] の refined 次元の a = t³（U(3)）への特殊化。
- GNR は、トーラス結び目の refined CS を旗 Hilbert スキーム上の層の**同変 Euler 標数**として書いている（`:3071`）。これは「rCS は index であって Poincaré 多項式ではない」という本研究の立場（Arthamonov–Shakirov 1504.02620 も同じ）と整合する【導出】。
- KN の rCS と彩色ホモロジーの Poincaré 級数の対応を [2,1] で述べた文献は見つからなかった。

## 4. W2（ホモロジー側の計算）の現実性

### 4.1 経路 H：HOMFLY-PT の [2,1]（EH の P_T を 3 本ケーブルに挿入）
- 必要なもの：4_1 の 3 本ケーブルのブレイド（4_1 = σ₁σ₂⁻¹σ₁σ₂⁻¹ のケーブルで 9 本・36 交点）、S_3 の [2,1] タブローの K_T（EH `:4950, 4999` に明示）または打ち切った P_T、Soergel 双加群（または行列因子化）の複体の簡約と Hochschild ホモロジー。
- 規模【導出】：yui-kr は家庭用の計算機でブレイド長 13 まで（2111.00388 `4.tex:33`）。ブレイド長 36 は、複体の大きさの素朴な目安 2^ℓ で 2^23 ≈ 10⁷ 倍になる。8 コア・8 GB では現実的でない。
  さらに P_T は無限複体なので、K_T を何段も重ねる打ち切りが要る。
- 実装：yui-kr は大域的なアルゴリズムで、射影子の挿入や局所的な簡約（Bar-Natan 型）は持たない。Soergel 双加群の局所的な計算プログラムを新しく作る必要があり、研究規模の開発になる【推測】。
- 判断：**現時点では実行しない方がよい**。CLAUDE.md の 24 時間の停止条件を明らかに超える。

### 4.2 経路 S：sl(3) 随伴（N = 3 の断面）
- Rose 1109.1745 の主定理（`:716-728`）により、随伴射影子は (+−) の 2 本のツイストの安定極限。したがって、L_k = 「4_1 の反平行 2 本ケーブル（16 交点）＋ k 回の full twist（2k 交点）」の**彩色なし** sl(3) ホモロジーを計算し、Rose の次数のずらしを施せば、低いホモロジー次数から順に随伴射影子のホモロジーに安定する【導出】。
  同じ考え方は Gorsky–Lewark 1404.0623 が FoamHo でトーラス結び目の安定 sl(3) ホモロジーを調べた例にある。
- 規模【推測】：FoamHo は T(6,5)（24 交点）を 6 分。L_k は k = 10 で 36 交点だが girth は小さいので、KnotJob／FoamHo で分〜時間の範囲と見込む。小さい k で時間を測ってから外挿する。
- 検算：自明な結び目では L_k は反平行の T(2,2k) で、Cautis 1207.2074 `:1999`（m = 3）と Rose `:5695-5703` の値に収束するはず。
- 限界：
  - 得られるのは sl(3) の断面で、a 依存性は無い。
  - 無限級数の打ち切りである。
  - KN の rCS の U(3) 特殊化と比べる規則が無い（W3）。
  - 本研究の自由な因子 δ = A⁴(A²−T⁴)(A²Q⁴−1)… は、U(2) の点 A = T² では消えるが、U(3) の点（a = t³ に当たる点。対応は conventions.md で要確認）では消えない。もし sl(3) 随伴の値を rCS の U(3) 特殊化と結べれば、u に一つの断面の制約が付く【推測】。
- 導入：KnotJob（Java 23）または FoamHo（入手先は未確認）。どちらも**ユーザーの許可**が要る。

### 4.3 経路 S′：有限次元の「ケーブル版」（仮説）
- sl(2) では、有限次元の彩色 Khovanov の Poincaré 多項式がケーブルの Khovanov の包除で書ける（2505.03916 定理、`:160-178`）。
- sl(3) で V ⊗ V* = 随伴 ⊕ 自明 を使った類似「Pol(H_sl3(反平行 2 本ケーブル)) − 1」は、**文献に無い仮説**。4_1 なら 16 交点なので KnotJob で数秒の規模【推測】。採用するなら、まず自明な結び目とトーラス結び目（随伴の index が EHA で分かる例）で意味を検証する必要がある。

### 4.4 W3 に先に回すべき安い試験【推測】
- 自明な結び目の比較：Cautis 1207.2074 `:1999`（sl(3) 随伴の Poincaré 級数）、GNR 1608.07308 `:6317-6354`（[2,1] のタブローの End(P_T) の級数、予想）と、KN の [2,1] の refined 次元（U(3) への特殊化を含む）。
- 三葉結び目の比較：GGS 1304.3481 の [2,1] 三重次数ホモロジー（41 生成元）と、本研究の EHA による三葉結び目の [2,1]（index）。
- これらで index と Poincaré 級数の対応規則が見えなければ、W2 の結果を KN の入力に変換できないので、経路 S の計算の価値も下がる。
