## 主張の要約

1. **四重次数**（§3.1, `:1144-1250`）：長方形 λ = R×S で色付けた HOMFLY-PT ホモロジー H^λ(K) は、四つの次数 (a, q, t_r, t_c) をもつ（予想）。
   - t_r は Gukov–Stošić（GS）の規約、t_c は Aganagic–Shakirov・DGR などの規約（`:340`）。refined CS は t_c に対応する。
   - どちらの t でも Euler 標数は色付き HOMFLY-PT：P(a,q,t_r=−1,t_c=1) = P(a,q,t_r=1,t_c=−1)。
   - 補助の次数 Q = (q + t_r − t_c)/R（tilde 版）を使うと、対称性が簡潔に書ける。
   - **非彩色（λ = [1]）では t_r = t_c、Q = q で、DGR の三重次数の理論に戻る**（`:1250` 付近）。
2. **自己対称性と鏡映対称性**（§3.2-3.3, `:1255-1324`）：自己対称性は四重次数でのみ見える新しい対称性である。鏡映対称性は H^λ ≅ H^{λ^T} で、t_r と t_c を入れ替える。
   - 非彩色では両者は一致し、DGR の対称性になる。DGR の対称性は Gorsky–Hogancamp–Mellit（2103.01212）が証明した。
3. **sl(n|m) の微分**（§3.4, `:1325-1447`）：(n,m) の二変数族の微分 d_{n|m} があり、次数は (a,q)[d] = (−2, 2(n−m))、t_c[d] = −2m−1 である。
   - d_{n|m} のホモロジーは sl(n|m) のホモロジーで、a = q^{n−m} に特殊化される（予想）。
   - DGR の d_N は境界上の d_{N|0}（N > 0）、d_0 = d_{1|1}（HFK）、d_{−N} = d_{0|N} に当たる。
   - 新しい微分（例：d_{2|1}、d_{1|2}）は、十分大きな結び目では非彩色でも非自明（`:363`、T(4,5) の例 `:2688-2715`）。
4. **色付き微分**（§3.5, `:1448-1650`）：行・列を取り除く微分 d^±_{λ→μ}。d_{±1} の一般化である。
   - 非彩色の d_1 で残る 1 項の次数は (Σ, −Σ, 0)（S 不変量 Σ、`:1488`）。
5. **refined exponential growth**（§3.7, `:1718-1780`）：2 橋結び目とトーラス結び目に限った予想。
6. **対称・反対称表現**（§3.9, `:1824-1843`）：δ 次数と thin の定義、HFK 型の微分 d_{1|r} の予想。
7. **例**（§4）：三葉結び目、4_1（S^2 の四重次数版、`:1999-2042`）、T(3,4)（thick、d_0 が非自明、`:2043-2098`）、(2,2), (2,2,2), (2,1) 表現。
   - 予想は「全ての結び目」が対象と明言（`:1999`）。GS で計算された 6 交点以下の素な結び目の S^2 も四重次数に拡張できるとする。
8. **トーラス結び目の代数的なモデル、B 模型・A 模型による実現、bottom row の組合せ論**（§5-8）：トーラス結び目に限った構成。

## 本研究の 5 結び目（K2, K4, K5a, K5c, K6b）との関係

- 対象かどうか：論文の予想は全ての結び目が対象なので、形式的には含まれる。ただし論文はケーブル・iterated torus 結び目に言及しておらず（grep で該当なし）、計算例もない。
  - refined exponential growth（2 橋結び目・トーラス結び目に限定）の対象ではない。2 本ケーブルはサテライト結び目で、どちらでもない。
- [1] では四重次数は三重次数（t_r = t_c）に戻る。したがって、[1] の DAHA の値の負の係数を「t_r と t_c の規約の違い」で説明することはできない。
- 本研究の [1] の superpolynomial の候補（scripts/framed_knot/construct_superpolynomial.py）は、この論文の [1] での要請を次のとおり扱っている。
  - 満たすもの：DGR（＝自己）対称性、d_{±1}（S 不変量の位置 (Σ,−Σ,0)、(Σ,Σ,Σ) を含む）、d_2 → Khovanov、d_0 = d_{1|1} → HFK。
  - 課していないもの：新しい微分 d_{2|1}, d_{1|2} などの存在。ホモロジーの値が未知なので数値的な条件にならない。
