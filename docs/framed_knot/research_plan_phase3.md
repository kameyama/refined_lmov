## 0. 目的と問題の所在

本来の目的は、KN（1703.05408）の結果を超えて、ヤング図の箱が 3 個の refined LMOV 不変量（\hat{𝐍}_{ρ}, \hat N_{ρ,g,β,J_r}、|ρ| = 3）の正整数性を検証すること。

- \hat f_ρ（|ρ| = 3）は |λ| ≤ 3 の全ての rCS_λ（[1], [2], [1,1], [3], [2,1], [1,1,1]）と Adams 像を使う。f^q_μ は |λ| = 3 の C_λ について一次なので、\hat f_ρ も rCS_{[2,1]} について一次。
- 長方形の [3], [1,1,1] は、thin な族では予想式（NRZS 1209.1409、GNSSS 1512.07883）から t_c 次数で得られる（第 2 期 T3 と同じ方法）。
- **非長方形の [2,1] が要点。** HOMFLY-PT ホモロジー側に非長方形の構成は確立しておらず、S, T 行列から計算できるのはトーラス結び目と iterated torus 結び目だけ。
- 第 2 期の教訓：(1) [1] の正値性は構造から従うので証拠にならない。(2) 2 箱では次元の指数増大性が形の条件になり、正値性は t_c 次数の選び方に依存する。
  したがって 3 箱の検証では、「入力が独立に決まっているか」と「正値性が自明に従うのではないか」を必ず確かめる。

KN の結果として既知のもの（成果として書かない）：トーラス結び目の全彩色、4_1 の 3 箱（[2,1] は KN が構成した候補）。

### C3 の方法（[2,1] の構造的な決定）

未知数 rCS_{[2,1]}（太字で負の係数も許す。KN の 4_1 の候補も負を含む）に、次の一次の条件を課す。

1. **t = q で [2,1] 彩色 HOMFLY-PT になる。** [2,1] 彩色 HOMFLY-PT は、(3, s)-ケーブル（s = 1, 2, 4 など 3 と互いに素な 3 通り）の HOMFLY-PT をブレイドから Sage で計算し、
   ケーブル公式（p₃ = s₃ − s₂₁ + s₁₁₁）を逆に解いて [3], [2,1], [1,1,1] を同時に求める（第 2 期 T4 の 2 本ケーブルの方法の拡張）。
2. **ミラー対称性**：[2,1] は自己転置なので rCS_{[2,1]}(a,q,t) = rCS_{[2,1]}(a,t⁻¹,q⁻¹)。
3. **refined 指数増大性**：q = 1 で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}、t = 1 で rCS_{[2,1]} = rCS_{[1]}·rCS_{[2]}（KN の式 (EGP)、[2,1] = ω₁ + ω₂）。
4. **\hat f_ρ（|ρ| = 3）が Laurent 多項式**（分母の零点での一次の条件。第 2 期 T4 の整数計画と同じ作り方）。
5. 両手型の結び目では両手型性（6_3 など。KN が 4_1 で使った条件）。

1〜5 の解の集合を整数計画で調べ、次の三つに分けて判定する。
- 解が一意：その [2,1] で |ρ| = 3 の正値性を判定する。正値性は独立な検証になる。
- 解が複数：正値性を満たす解が存在するか、全ての解で正か（最小化・最大化で調べる）。「存在する」だけなら検証としては弱いと明記する。
- 解が無い：入力（[3], [1,1,1] の予想式、t_c 次数）か、形そのものの破れ。

## 4. 主なリスク

- **[2,1] が条件で決まらない**：正値性は「存在」の主張にとどまる。U3 で早めに判定し、追加の条件を検討する。
- **3 本ケーブルの HOMFLY-PT が重い**：7 交点以上の結び目で Sage が終わらない可能性。その場合は対象を小さい結び目に絞るか、文献の [2,1] 彩色 HOMFLY-PT を使う（U1）。
- **入力の予想式の信頼性**：NRZS・GNSSS の [3] は予想に基づく。t = q で彩色 HOMFLY-PT（U2 の 3 本ケーブルの値）と照合して確かめる。
- **3 箱でも正値性が自明に従う可能性**：第 2 期の 5_2 の実験と同様に、別の入力の割り当てでは負になるかを確かめ、検証の意味を保証する。
