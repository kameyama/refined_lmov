### A1. [2,1] の refined 入力が無い（2026-10-07：本研究では打ち切り、別研究 docs/framed_knot/research_plan_21.md に移した）

- 分かっていること：トーラス結び目は KN が全彩色で計算。4_1 の [2,1] は、KN が構造的な条件（ミラー対称性・指数増大性・両手型性）で候補を作った（負の係数を含む）。
  第 1 期では代数的なケーブル 3 個（K1, K3, K6a）で、[2,1] を含む全彩色の正値性を確認した。
- 足りないもの：トーラス結び目・ケーブル以外の結び目での [2,1]。→ 第 3 期の主題。
- 第 3 期の結果（docs/framed_knot/REPORT_phase3.md）：構造的な条件（t = q、ミラー、EGP、U(2) への簡約、Laurent 性、G 展開、正値性）だけでは [2,1] は一意に決まらない（三葉結び目で解の差の階数 6）。
  文献にも定義に基づく非トーラスの [2,1] は無い（Cherednik 2607.25666 は列型の彩色のみ）。
  手がかり：解の集合の構造、AMMM 1211.6375 の 4_1 の候補との比較、An. Morozov 1211.4596 の一次ずれの公式、U(2) 以外の特殊化（a = t³ など）。
- 第 4 期の結果（docs/framed_knot/REPORT_phase4.md §3, §6）：解の差は「結び目によらない因子の積 × 自由な多項式 u」。a = t³ などに新しい恒等式は無く、一次ずれの公式と colored differential は新しい条件にならない。

  - 道 2：Elias–Hogancamp の [2,1] 射影子（full twist の圏論的対角化で作る無限複体）を挿入する計算を新たに実装する。研究規模のソフトウェア開発で、計算量も 3 本ケーブルの複体の上にさらに乗る。

### F1. refined の Racah 行列による構成（arborescent 計算の refined 化）
- 目的：[2,1] の Racah 行列 S̄, S の refined 版を作り、ダブルツイスト結び目（と arborescent 結び目）の refined [2,1] を定義どおりの手続きで計算する。Z̃_X は 4_1 の項として、反常チャネルは S̄ の非対角の成分として出てくるはず。
- 拡張元：t = q の [2,1] の Racah 行列（Gu–Jockers 1407.5643 の 6j 記号、1612.00422 が微分展開の導出に使ったもの）、KNTZ の 𝓑 を S̄T̄²S̄ の三角化として説明した A. Morozov 2001.10254、
  1903.00259 の「多重度による gauge の自由度」の議論。Kononov–Morozov 2609.09437 は長方形の行列式表示の [2,1] への拡張を未解決としている。
- 難しさ：(i) refined の Racah 行列は長方形でも一般には定義されていない（refined の S, T が使えるのはトーラス型の構成だけ）。(ii) [2,1] ⊗ [2,1]̄ には多重度 2 があり、t = q でも gauge が残る（1903.00259）。
  (iii) refined の値が定義どおりに分かる検証点が族の中で三葉結び目だけ。
- 判定：t = q で X0 のデータに戻る、三葉結び目で EHA、X2 の EGP・U(2) で決まった Z̃_X の特殊化での値を再現する、Laurent 性・転置・ミラー。予言として 4_1 の KN・AMMM の候補との比較と 3 箱の正値性。
- 規模：数か月。refined の S̄ の定義そのものが未解決の問題。

### F2. DAHA/EHA 型の定義の双曲結び目への拡張（research_plan_21.md の Y4）
- 目的：DAHA/EHA のように定義から値が決まる構成を双曲結び目に広げ、その [2,1]（一般の λ）を計算する。本研究の第 1 期で、トーラス結び目と iterated torus 結び目ではこの型の構成が [2,1] を定義どおりに与えた。
- 拡張元：Cherednik 2607.25666（双曲 Coxeter 結び目。列型の彩色のみ、A1 の文献調査）、Galashin–Lam の構成（arXiv 番号は本文書では未確認）、本研究の EHA の実装（src/rcsknots/ehall.py, gn.py）。
- 難しさ：結び目の不変量であること（Reidemeister 不変性）が未知。非長方形の彩色での正規化の単項式（本研究の (N1)(N2')、conventions.md §13）を決める原理が要る。
- 判定：F1 と同じ。加えて、構成が双曲結び目とトーラス結び目で同じ式から出るなら、トーラス結び目での EHA との一致が強い検査になる。
- 規模：研究規模（結び目の不変性の証明を含む）。
- **追加調査（2026-10-08、ユーザーの指摘、docs/framed_knot/literature/f2_genus2_daha.md）**：種数 2 の refined CS・DAHA・skein 代数（Arthamonov–Shakirov 1504.02620, 1704.02947、Hikami 1901.02743 と続編 2402.09106, 2408.17021, 2507.01665、Cooke–Samuelson 2008.12695）は、
  ツイスト結び目・ダブルツイスト結び目・pretzel 結び目に q,t の値を与える既存の構成で、F2 の最も具体的な拡張元。ただし全て rank 1（sl_2）で、a が無く、[2,1] には届かない。
  高ランク化の障害は 3 価のグラフの頂点のテンソル積の多重度（1504.02620 :747）で、X2 の障害と同じ。どの論文も未解決として挙げている。
  sl_2 の部分を KN 型の値（rCS_{[1]} の a = t²）と比べると、4_1, 6_1, 8_1 で単純な変数の対応による一致は無かった【計算、探した範囲で】。|Z|² どうしの比較は未実施。

### F3. [2,1] 彩色 HOMFLY-PT ホモロジーの計算と、KN の rCS への変換規則
- 目的：定義のあるホモロジー（Cautis 1611.09924、Elias–Hogancamp の [2,1] 射影子）で 4_1 などの [2,1] の Poincaré 多項式を計算し、X2 の族の式に対する定義どおりの条件（データ点）にする。
- 必要なもの（どちらも未整備）：
  (i) 計算：3 本ケーブルの複体に Elias–Hogancamp の射影子（無限複体）を挿入する新しい実装。規模は既存ソフトの限界の約 10⁷ 倍（research_plan_21.md §5）。yui-kr は彩色なしのみ（A1）。sl(3) の foam など他の道は非 minuscule で無限次元になり、計算ソフトが無い。
  (ii) 変換規則：KN の rCS_{[2,1]} はトーラス結び目でも負の係数をもつので、Poincaré 多項式そのものではない。[2,1] は長方形でないので GGS の四重次数と t_c 次数の規則（conventions.md §15 の 𝐐 → 𝐪^R）が定義されず、
  長方形でも thick な結び目では t_c 次数が t_r のデータから決まらない（conventions.md §12）。Poincaré 多項式から index（rCS）を得る規則そのものが研究課題。
- 判定：トーラス結び目の [2,1]（Poincaré 多項式と EHA の rCS の両方が分かる）で変換規則を較正してから、4_1 に使う。三葉結び目の [2,1] では GGS 1304.3481 のホモロジーの予想（Y5）と比べられる。
- 規模：研究規模（ソフトウェア開発と、変換規則の理論の両方）。3 つの中で最も遠い。
