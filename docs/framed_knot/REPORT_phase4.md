## 0. 要約

第 4 期の主題は、KN（1703.05408）を超えた 3 箱の refined LMOV 不変量の正整数性の検証を、双曲結び目へ広げることだった。そのために要る非長方形の [2,1] の入力を決める原理を探した。

1. **[2,1] は、手元の構造的な条件では決まらない（V2）。** t = q での [2,1] 彩色 HOMFLY-PT、ミラー対称性、refined 指数増大性、U(2) への簡約、3 箱の \hat f の Laurent 性、G 展開、正値性を全て課しても、解の差は「結び目によらない因子の積 × 自由な多項式 u」の形で残る【計算＋導出】。
   a = t³ などの他の特殊化に新しい恒等式は無く【計算】、An. Morozov の一次ずれ公式や colored differential は新しい条件にならない【導出】。足りないのは u を固定する、定義に基づく構成である。
2. **双曲結び目の 3 箱は「正の候補が存在する」までにとどまる（V5、弱い判定）。** 4_1 では KN の候補が全条件を満たし、6_1 では正値性を満たす整数の [2,1] が存在する【計算】。5_2 は有理数の解は存在するが整数解は未決。
   正値性と両立しない例は見つからなかった。[2,1] が一意でないので、これは KN の予想の検証ではなく「矛盾しない」ことの確認である。
3. **定義どおりに [2,1] が得られる代数的な iterated torus 結び目では、3 箱の正値性が成り立つ（§9）。** 第 3 期の K1, K3, K6a, K9 に K8（T(3,4) の (2,25)-ケーブル）が加わり、5 個で |ρ| ≤ 3 の全 6 つの ρ が G 展開の前後とも非負【計算】。
   2 段の反復ケーブル K10 も 3 箱まで非負（2026-10-08、§1.1）。K7（3 本ケーブル）も 3 箱まで非負（§9）。
4. **計算基盤（V0）**：3 箱の \hat f と rCS の計算を約 4〜6 倍に高速化し、並列化と途中からの再開を可能にした（従来の結果と全係数で一致）。
5. **その他**
   - ツイスト結び目の 2 箱の正値性を、GNSSS の予想式の下で全ての p で証明した（V4、§5.1）。pretzel K_{s,t} では s, t が同符号の領域で全て、異符号の領域で min(|s|, t) ≤ 20 まで証明した（§5.2）。
   - [1] の 2J_r の偶奇がそろう条件は Chandler–Gorsky の parity knot と同じ。11 交点以下の非トーラスの parity knot は 10_125, 10_140（C2）。
   - GNSSS の pretzel の式は、11 交点以下で特定できる 23 件では実際のホモロジーと一致する（B2）。次元が二乗にならない 16 個と special polynomial の性質の破れは、入力スクリプト `scripts/framed_knot/t3_pretzel.py` の浮動小数点のバグ（q-Pochhammer の初期値が Python の int で、qbinom(0,0) が 1.0 になり、sympy の約分が数値誤差で壊れ、`int(c)` で切り捨てられた）によるもので、修正後は s, t ∈ [−5, 5] の 55 個全てで成り立つ（2026-10-07 訂正、§8）。
   - U(2) への簡約の恒等式は既知（Cherednik–Danilenko、AMMM）と判明した（V3）。

## 3. V2：[2,1] を決める原理

| 候補 | 結果 |
|---|---|
| V2-1 解の空間の構造 | 三葉結び目の整数計画の解と正解の差 δ = A⁴(A² − T⁴)(A²Q⁴ − 1)(Q² − 1)(T² − 1)(Q − T)(Q²T⁴ − 1)(Q⁴T² − 1)·u/(Q⁵T¹¹)。各因子は既存の条件に由来し、u は自由。因子は結び目によらないので、どの結び目でも現在の条件では一意に決まらない【計算＋導出】 |
| V2-2 他の特殊化 | 正解 10 結び目で、A = ±Q^i T^j（\|i\|, \|j\| ≤ 3）での単項式倍の関係と 2 項の一次関係を探索。U(2) の恒等式（a = t²）とそのミラー（a = q⁻²）以外は無し【計算】（`scripts/framed_knot/v2_specializations.py`, `scripts/framed_knot/v2_linear_relations.py`） |
| V2-3 An. Morozov の一次ずれ公式 | δ は (Q² − 1)(T² − 1) で割れるので、新しい条件にならない【導出】 |
| V2-4 refined の微分展開 | 実施せず（AMMM 1211.6375 自身が構成のパラメータの自由度を認めており、一意性は得られない見込み。ユーザーの判断） |
| V2-5 AMMM と KN の 4_1 の候補の比較 | 同上 |
| V2-6 colored differential の類似 | 微分の条件は非負の Poincaré 多項式に対するもので、負の係数をもつ rCS_{[2,1]} には適用できない【導出】 |

結論：一意性に足りないのは、自由な因子 u を固定する新しい種類の構造（定義に基づく構成）。双曲結び目の 3 箱は、弱い判定（V5）にとどまる。

## 5. V4：ツイスト結び目の 2 箱の正値性の証明（GNSSS の予想式の下で証明、2026-10-07）

- 方針：NRZS の式では p が (a t² q^{ℓ−1})^{pℓ} の形でだけ入るので、\hat f_{[2]}(K_p) は p についての指数多項式 Σ_j A_j m_j^p になるはず。
  各ブロック A_j の G 展開の正値性と、大きい |p| で台が分離することが言えれば、小さい |p| の計算と合わせて証明になる。
- 結果【計算：p = 1〜12】（`scripts/framed_knot/v4_twist_structure.py`, `scripts/framed_knot/v4_roots.py`, `scripts/framed_knot/v4_fit.py`、ログ同名）
  - p > 0 で、\hat f_{[2]}(K_p) と \hat f_{[1,1]}(K_p) は p について次数 5 の線形漸化式を満たす（ハンケル行列式）。
  - 特性根は（素数の点で厳密に求めて因数分解）1, 𝐚²𝐭², 𝐚⁴𝐭⁴, 𝐚⁴𝐪⁴𝐭⁸, 𝐚⁴𝐪⁻⁴𝐭⁴。すなわち \hat f(K_p) = Σ_j A_j m_j^p（A_j は p によらない明示的な有理関数）。p = 1〜5 で解き、p = 6〜12 で成立。
  - A_j は個々には Laurent 多項式でない（分母に (𝐚𝐭 − 1)², (𝐚𝐪𝐭² ± 1) など）。和で約分される。m_j のうち 3 つは 𝐚 次数が同じ（4）。
- 文献：superpolynomial の段階での p についての漸化式は実質的に既知（NRZS 1209.1409 の式の構造、Mironov–Morozov–Morozov 1306.3197 の evolution の固有値）。\hat f（refined LMOV）の段階で論じた文献は見つからなかった。
- 結論：「各ブロックの正値性 ＋ 大きい |p| での台の分離」による証明はそのままでは成立しない。証明には NRZS の和（q-Pochhammer の積）の段階での正値性など別の筋が要る【未解決】。
  閉じた形により、大きい |p| での確認は速くできる（未実施）。p < 0 は未解析。

### 5.1 証明（2026-10-07、サブエージェントの作業を確認して記録）
- 閉じた形【導出】：GNSSS の式では p は ((𝐚𝐭)^{2j}(𝐭𝐪)^{2j(j−1)})^p の形でだけ入り、入力の根は P_[1]：{1, X}、P_[2]：{1, X, Y}、P_[1,1]：{1, X, Ȳ}（X = 𝐚²𝐭², Y = 𝐚⁴𝐪⁴𝐭⁸, Ȳ = 𝐚⁴𝐪⁻⁴𝐭⁴）。
  \hat f は入力の積と Adams 演算の一次結合を命題 2 の分母 2A²(Q⁴−1)(T⁴−1)(Q²T²−1) で割ったものなので、\hat f(K_p) = ε_p Σ_j A_j m_j^p（根 1, X, X², Y, Ȳ）。
  ε_p = 1（p > 0）、𝐭²（p < 0）：p < 0 で変わるのは前因子 (−t_r t_c)^{−r·sgn} だけで、これは入力の一様な単項式倍 C_λ → c^{|λ|} C_λ（c = −𝐭）に当たる【導出、p = −1, −2, −3 で全係数一致】。
- ニュートン形【導出】：s_{1+n} = Σ_{k=0}^{4} c_k h_{n−k}(m_{π0}, …, m_{πk})（h は完全斉次対称式）。c_k は s_1..s_5 の整数多項式係数の一次結合なので Laurent 多項式で、A_j の分母はこのブロック化で消える。
- 正値性【計算：|p| = 1..5 から作る c_k、有限個の厳密な判定】：並び (1, X, X², Y, Ȳ) で、p の両方の符号・ρ = [2], [1,1] の両方で c_0..c_4 の全係数が同符号。
  単項式の h_n は非負係数なので、全ての p ≠ 0 で \hat f は G 展開の前で一様な符号を持つ。
- G 展開の後【導出】：σ:(e_𝐚, e_𝐪, e_𝐭) ↦ (e_𝐚, −e_𝐪, e_𝐭 − e_𝐪) は根の集合を保つ（Y ↔ Ȳ）ので、σ 不変性は |p| = 1..5 から全ての p に従う。
  補題：G 展開が閉じ（𝐚 の各行が σ 不変で 𝐪 の指数が偶数）、展開前に非負係数なら、\hat N も非負整数（命題 1 の補題：𝐭^l(y^k + y^{−k})、y = 𝐪²𝐭 の G 展開は非負）。逆は成り立たない（第 1 期の K5c）。
- 確認【計算】：|p| ≤ 30（p ≠ 0）の全 120 件で前後とも負の項 0 個（全体の符号は一様）。閉じた形は c_k の作成に使っていない |p| = 6..12, 15, 20, 30 で直接計算と全係数一致。
  `scripts/framed_knot/v4_closed.py`, `scripts/framed_knot/v4_newton.py`, `tests/framed_knot/test_v4_twist.py`（7 件）、ログ `logs/framed_knot/v4_closed.log`, `logs/framed_knot/v4_newton_*.log`。
- **結論**：GNSSS の式（予想式）と δ' = −S の t_c 次数を前提として、ツイスト結び目の 2 箱の refined LMOV 不変量は全ての p ≠ 0 で G 展開の前後とも正整数係数【導出（入力は予想式）】。
- c_k の構造（2026-10-07、サブエージェントの作業を確認して記録。`scripts/framed_knot/v4_ck.py`、`logs/framed_knot/v4_ck.log`：34 件の照合が全て成立、親セッションで再実行して確認）

## 8. B2：pretzel の thick さ

- GNSSS の pretzel K_{s,t}（s, t ∈ [−5, 5]）を [1] の HOMFLY-PT で結び目表（yui-kr、両カイラリティ）と照合。

- **訂正（2026-10-07、V4 の pretzel への拡張で判明）**：次元が二乗にならないことと、下の special polynomial の性質の破れは、どちらも入力スクリプト `scripts/framed_knot/t3_pretzel.py` の浮動小数点のバグ（q-Pochhammer の初期値が Python の int で、qbinom(0,0) が 1.0 になり、sympy の約分が数値誤差で壊れ、`int(c)` で切り捨てられた）による。
