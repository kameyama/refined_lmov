## 0. 出発点

- **目的**：KN（1703.05408）の正値性予想を、トーラス結び目・代数的な iterated torus 結び目以外（特に双曲結び目）で、3 箱（|ρ| = 3）まで検証する。
  \hat f_ρ（|ρ| = 3）は |λ| ≤ 3 の全ての rCS_λ を使い、非長方形の [2,1] が欠けている。
- **本研究で分かったこと**：
  - 定義どおりに [2,1] が得られる範囲（トーラス結び目、代数的な iterated torus 結び目 K1, K3, K6a, K7, K8, K9, K10）では、3 箱まで全て正【計算】。入力の rCS_{[2,1]} 自体は負の係数をもつが、BPS 不変量の段で正になる。
  - 双曲結び目の [2,1] は構造的な条件では決まらない：解の差は δ = A⁴(A²−T⁴)(A²Q⁴−1)(Q²−1)(T²−1)(Q−T)(Q²T⁴−1)(Q⁴T²−1)·u/(Q⁵T¹¹) で u は自由（REPORT_phase4.md §3）。
  - 弱い判定：正値性を満たす [2,1] は 4_1（KN の候補）と 6_1 に存在、5_2 は有理数解のみ（REPORT_phase4.md §6）。
  - 2 箱はツイスト結び目・pretzel で証明済み（予想式の下）、thick な 10_139・10_152 で正（REPORT_phase5.md）。
- **W0 の文献調査の結論**（docs/framed_knot/literature/w0_21_survey.md、A〜E）：
  - 双曲結び目の [2,1] を a と t の両方つきで定義に基づいて計算した構成は、どの系統（ホモロジー、物理・表現論、ホモロジーを作らない構成）にも無い。
  - t = q の [2,1] 彩色 HOMFLY-PT は多くの双曲結び目で既知（ツイスト結び目の全族 MMM 1408.3076、8 交点以下の 2 橋結び目 Gu–Jockers 1407.5643、3 本ブレイド、pretzel など）。
  - ダブルツイスト結び目の [2,1] の微分展開（A. Morozov 1612.00422、予想）と、それを KNTZ 型の三角行列 𝓑^{[2,1]} に書き直したもの（Morozov 1903.00259「Extension of KNTZ trick to non-rectangular representations」、Phys. Lett. B 793 (2019)、arXiv で確認）がある。
    **1903.00259 は結びで「𝓑 の Macdonald 変形は素直に作れるはずで、それが hyper 多項式を与えるか（非長方形では完全には正でないと疑われている）を見るのは興味深い」と書き、未着手の課題として残している**（main.tex、確認済み）。
  - KNTZ 1902.02275（Kameyama–Nawata–Tao–Zhang、長方形の円分展開と refined 版）は、refined の構成要素 𝐅_λ を任意の λ で定義し、各要素が有理関数でも 𝐅_λ は常に Laurent 多項式で、length(λ) ≤ 2 なら正係数と述べている（tex の 741 行、確認済み。[2,1] は長さ 2）。長方形に限られるのは、出発点の 4_1 の式・撚りの固有値・四重次数の 3 箇所。
  - **Fang–Zhou 2610.00303（2026-09 投稿、10-08 更新）が KNTZ の長方形の予想を t = q で証明した**（任意の結び目の二重 Newton 展開と、全ての長方形の彩色でのダブルツイスト結び目の明示式。docs/framed_knot/literature/w0_21_F_fang_zhou.md）。
    方法は長方形に特有（R⊗R* の多重度なしの分解、不変量の空間 = 1 行の外冪）で、[2,1] にはそのままでは使えない。refined と非長方形は扱わず、「今後の問い」で次数付き（refined）の類似を未解決として挙げている。
  - Beliakova–Gorsky 2101.08243 の円分展開は t = q のみ（t は「期待」として述べられるだけ）。sl_3 の F_K 2508.15171 は正のブレイドの結び目（10_139 を含む）で sl_3 の随伴まで定理として扱うが、a と t が無い。
  - ホモロジー側（射影子、sl(3) の foam）は非 minuscule で無限次元になり、計算ソフトも無い。

## 1. 中心の問い

1. 双曲結び目の rCS_{[2,1]} を、**既存の構成の素直な拡張**で決められるか。決まらないなら、どの自由度が残るか。
2. 決まった [2,1] で、3 箱の refined LMOV 不変量は G 展開の前後とも正整数か。
3. 入力（hyper 多項式）が正でなくても BPS 不変量の段で正になるか（本研究の主結果と同じ型の現象が双曲結び目でも起きるか）。

**循環論法を避ける原則**：正値性は候補を選ぶ条件に使わない。候補を決める条件（t = q での一致、構造的な条件、定義どおりに分かる点での一致）と、予言として確かめる量（正値性、KN の 4_1 の候補との一致）を分けて報告する。

## 2. 判断：[2,1] は既存文献の拡張となる練習問題として挑戦できるか

**挑戦できる。** 最も適した題材は、Morozov 1903.00259 の [2,1] の 𝓑 行列の Macdonald 変形（KNTZ の refined 版の非長方形への拡張）である（docs/framed_knot/literature/w0_21_E_exercise_feasibility.md）。
- 拡張元がはっきりしていて（KNTZ の refined 𝐁、1903.00259 の 𝓑^{[2,1]}、1612.00422 の Z 因子）、原著者が未着手の課題として明記している。
- KNTZ の長方形の t = q の部分は Fang–Zhou 2610.00303 で定理になった。その方法は長方形の多重度なしの構造に依存し、主軸 X の 2 つの方向（非長方形、refined）はどちらも Fang–Zhou が扱っていない。
  ただしこの分野は活発なので（Fang–Zhou は 2026-09 投稿、10-08 更新）、X0〜X2 は早めに進める価値がある。
- t = q の正解（ケーブルの逆解き、Gu–Jockers、MMM）と、refined の正解（3_1 は EHA で定義どおり）で検証できる。
- 計算は軽い：3 本ケーブルの HOMFLY-PT は p = 20 のツイスト結び目でも 31 秒、ケーブルの逆解きは改良すれば K_12 で 13 秒（E の調査）。
- **リスク**：族の中で refined の値が定義どおりに分かるのは自明な結び目と 3_1 だけ。Z 因子に t をどう入れるかの曖昧さ（AMMM 1211.6375 が 4_1 で遭遇したもの）が族全体の条件で消えなければ、第 4 期と同じ非一意性の族版が得られて終わる。成否は最初の数日（X0〜X2）で分かる。

## 3. 主軸 X：[2,1] の 𝓑 行列の Macdonald 変形

### X0：t = q の再現と規約の固定（半日〜1 日）— **完了（2026-10-08）**
- 結果：長方形（[2], [1,1], [3], [1,1,1], [2,2], [4], [1⁴]）は KNTZ の式、[2,1] は 1612.00422 の (H21de) と 1903.00259 の 𝓑^{[2,1]}（Z を F^{(1)}F^{(−1)} で割って読む）が、
  ツイスト結び目 |p| ≤ 10 と K_{±2,2}, K_{±3,2} の 3 本ケーブルの逆解きと全係数一致【計算】。規約は conventions.md §14、記録は progress.md の X0 の節。
- 1903.00259 の 𝓑^{[2,1]} と 1612.00422 の Z 因子を実装する。
- まず長方形の彩色（[2], [1,1], [2,2]）で、KNTZ のダブルツイスト結び目の式（Fang–Zhou 2610.00303 で定理）を正解として、実装と規約（本研究の P_λ の正規化、framing、向き）を確かめる。
- 次にツイスト結び目 K_p（|p| ≤ 10 程度）と数個のダブルツイスト結び目 K_{m,n} で、[2,1] を 3 本ケーブルからの逆解き（scripts/framed_knot/colored_from_cables.py。逆行列を先に作る高速化を入れる）と全係数で照合し、正規化の対応（本研究の P_{[2,1]}、framing、向き）を固める。
- 副産物：1612.00422 の予想式を大きい (m,n) で独立に検証（Y2）。

### X1：KNTZ の refined 𝐁 の実装（1〜2 日）— **完了（2026-10-08）**
- 結果：KNTZ の補助ファイル（Wolfram で実行）と全係数一致。[r], [1^r] は GNSSS と一致、t = q で X0 に戻り、三葉結び目の [1], [2], [1,1], [2,2] は EHA と一致（Y6 の一部）。
  t = q で 𝓑^{[2,1]} の正則な行の F は KNTZ の Tw に等しい。規約は conventions.md §15、記録は progress.md の X1 の節。
- KNTZ の refined 𝐁（補間 Macdonald）を実装し、対称・反対称表現で GNSSS 1512.07883 の式（第 2 期で使った入力）に戻ることを確かめる。

### X2：未知数と条件の数え上げ（1〜2 日）→ **停止点 1** — **完了（2026-10-08）、報告して確認待ち**
- 結果：KN の変数でのチャネル分解を作り、EGP と U(2) の過剰決定系（各 25 本、未知数 5）は矛盾なく解けた。正則なチャネルの Z̃ は Laurent 多項式として解が存在するが一意でない（自由度は第 4 期の δ の族版）。
  refined の微分の積という離散的な仮定は [2,1] チャネルで EGP と転置の両立に否定された。詳細は progress.md の X2 の節、規約は conventions.md §16。
- 𝓑^{[2,1]} の正則な行は X1 の refined 𝐁 から、X̃₂ の行（A に本質的に依存する反常チャネル）と Z 因子の t 依存性は未知数とする。
- 条件：t = q で X0 に戻る、族全体での Laurent 性・ミラー対称性・U(2) への簡約・指数増大性、3_1 で EHA の rCS_{[2,1]} に一致、自明な結び目。正値性は使わない。
- 解の数を数え、一意に決まるか、残る自由度を報告して止める。

### X3：決まった場合の判定（数日）— **実施しない（2026-10-08）**：X2 で一意に決まらなかったため。残る道は研究規模の課題として docs/framed_knot/open_problems.md §F（F1 refined の Racah 行列、F2 DAHA/EHA 型の定義、F3 ホモロジー）に記録した。
- ツイスト結び目・ダブルツイスト結び目（4_1, 5_2, 6_1, 7_2, 8_1, …）の refined [2,1] を求める。
- 予言として確かめる：(i) 4_1 で KN の候補・AMMM の候補と一致するか、(ii) 3 箱の refined LMOV 不変量の G 展開の前後の正値性（本研究の判定のコードをそのまま使う）、(iii) hyper 多項式自体が正でないか（Morozov の疑い）と、BPS の段での正値性の関係。
- 第 4 期の弱い判定（4_1, 6_1 に正の解、5_2 は有理数解のみ）と整合するか。
