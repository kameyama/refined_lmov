# 研究計画（ケーブル以外の方針）：結び目表の非トーラス結び目での refined LMOV 正値性

作成：2026-10-05。ケーブルを続ける案は docs/framed_knot/research_plan_phase2.md。この文書はそれに代わる別の方針である。
第 1 期の結果は docs/framed_knot/REPORT.md、文献の状況は docs/framed_knot/categorification_literature_map.md（以下「文献地図」）、規約は docs/framed_knot/conventions.md。
ステージ記号は第 1 期・ケーブル案と区別するため T0〜T6 とする。

> **2026-10-05 追記（T1 の結果）**：T1 で、[1] の正値性（G 展開の前後）は「P が非負係数で DGR の対称性をもつ」ことから一般に従うことが分かった（conventions.md §11 の命題）。
> DGR の対称性は GHM の定理なので、ホモロジーを入力とする [1] は任意の結び目で正になる。したがって P1 は解析的に解決し、P2（T2）は不要になった。
> 801 結び目の計算は命題の確認にとどまる。残る非自明な問いは、2 箱以上（T3, T4, T5）と、2J_r の偶奇（S_R の解釈）である。以降の方針はユーザーと相談して決める。

## 0. 方針の要点

第 1 期は、refined 不変量を S, T 行列（DAHA/EHA）から計算できる結び目（iterated torus）に限っていた。
この案では入力を **HOMFLY-PT ホモロジーそのもの** に切り替え、結び目表の非トーラス結び目に広げる。

- 根拠 1：[1] では \hat f_{[1]} = (a^{1/2} − a^{−1/2})·rCS_{[1]} なので、入力が三重次数ホモロジーの Poincaré 多項式なら、G 展開の前の正値性は自動的に成り立つ。
  判定の中身は **G 展開が整数で閉じ、展開の後も正になるか** にある（CLAUDE.md：KN の立場をとるなら [1] で確認できなければならない）。
- 根拠 2：Nakagane–Sano（arXiv:2111.00388）が、11 交点以下の全素結び目の reduced HOMFLY-PT ホモロジーを計算した。
  結果はプログラム yui-kr のリポジトリ（github.com/taketo1024/yui-kr）の `results` に JSON で置かれている（README で確認）。
  したがって、予想（DGR の仮定）に頼らず、定理に基づくホモロジーで [1] を判定できる。
- 根拠 3：KN（1703.05408 §6）が非トーラス結び目で調べたのは、thin な結び目（4_1, 5_2, 6_1, 6_2, 6_3, 7_2, 8_1、(2s−1,1,2t−1)-pretzel）の 2 箱までと、4_1 の 3 箱である。
  thick な 9_42 は **2 箱**（[2], [1,1]）で形 (hat-f-2) に乗らないと述べている（TeX `:1092-1102`）。[1] についての記述は無い。
  thick な結び目の [1] は、KN でも調べられていない。

### 問い

| # | 問い |
|---|---|

| P2 | thin な結び目では、P1 の判定は HOMFLY-PT と符号数だけで決まるはずである。正値性の条件を HOMFLY-PT の言葉で書けるか（解析的な判定条件） |
| P3 | 族（ツイスト結び目 K_p、(2s−1,1,2t−1)-pretzel）について、[1], [2], [1,1] の正値性を全ての p, s, t で証明できるか |

## 1. ステージ

どのステージでも、まず [1] の結果（G 展開の前と後）を確定し報告してから、彩色付きに進む。

### ステージ T0：データの取得と規約の確定

1. yui-kr の `results`（JSON）を `references/` に取得する。リポジトリ全体ではなくデータだけを取る。
   Rust とプログラム本体は入れない（入れる場合は改めて許可を求める）。取得方法（`just fetch-refs` に加えるか）は、レシピの追加になるので事前に確認する。
2. 次数の規約を決める。Nakagane–Sano の (a, q, t) と DGR・KN の対応、reduced の正規化、鏡像の向き（KnotInfo のブレイドと DGR の「負の三葉結び目」）。
3. 自動テスト（tests/framed_knot/test_knot_table_conventions.py）
   - Euler 標数：全結び目で、ホモロジーの次数付き Euler 標数がブレイドから Sage で計算した HOMFLY-PT に一致する。
   - 既知の値：三葉結び目と 4_1 が DGR の superpolynomial に一致する。T(3,4) = 8_19 と T(3,5) = 10_124 が、第 1 期のトーラス結び目の値（rCS_□、KN と一致済み）に一致する。
   - KN のノートブックの [1]（4_1, 5_2, 6_1, 6_2, 6_3, 7_2, 8_1）を再現する。
   - DGR の対称性（Gorsky–Hogancamp–Mellit 2103.01212 の定理）が全結び目で成り立つ。
4. 鏡像：[1] では \hat f の判定は鏡像で変わらないはずである（G = (Q−Q^{−1})(QT−Q^{−1}T^{−1}) は Q→Q^{−1}, T→T^{−1} で不変）。これを導出し、数例で確かめてから、各結び目で一方のカイラリティだけを判定する。

**停止点 1**：規約表と照合の結果を報告し、確認を求める。

### ステージ T1：結び目表の [1] の判定（P1）

- 対象：yui-kr の結果がある全素結び目（11 交点以下）。トーラス結び目（3_1, 5_1, 7_1, 8_19, 9_1, 10_124, 11a367 など）は対照に使う。
- 手順：第 1 期の `lmov.py` で \hat f_{[1]} を作り、G 展開の閉じ方（各 A^{2β} の係数が G の冪で整数に展開できるか）、展開の前と後の符号、(g,β) ごとの 2J_r の偶奇を判定する。
- 分類の軸：thin / thick（δ 次数の幅）、交点数、交代・非交代、正のブレイド、L-space 結び目、quasi-positive。
- 成果：結び目ごとの判定表（`data/framed_knot/knot_table/`）と集計（`data/framed_knot/knot_table_summary.md`）。破れた結び目は、負の項の位置 (g, β, J_r) と値を列挙する。
- 結論の型
  - 全結び目で正：KN の正値性予想の [1] が、thick な結び目を含めて実データで支持される【計算】。
  - 破れがある：ホモロジーが入力なので、[1] で KN の枠組みが閉じないことになる。どの性質（thick さ、非交代性など）と相関するかを調べる。
- 計算量：1 結び目あたり数秒の見込み。

**停止点 2**：[1] の判定表を報告し、確認を求める。以降のステージの優先順位はこの結果で決める。

### ステージ T2：thin な結び目の解析的な判定条件（P2）

- thin な結び目の reduced superpolynomial は、HOMFLY-PT と符号数 σ で決まる（DGR、Rasmussen）。これを \hat f_{[1]} と G 展開に代入し、正値性の条件を HOMFLY-PT の係数で書く【導出】。
- T1 の thin な結び目の全データで、その条件と計算の判定が一致することをテストにする。
- 期待：条件が「HOMFLY-PT の genus 展開（非 refined の LMOV/BPS 不変量）の符号が一様」に近い形になる。そうなれば、非 refined のデータだけで判定でき、12 交点以上の thin な結び目（KnotInfo の HOMFLY-PT）にも広げられる。

### ステージ T3：族での 2 箱までの証明（P3）

- 入力：対称彩色の superpolynomial の閉公式。
  - ツイスト結び目 K_p：Nawata–Ramadevi–Zodinmawia–Sun（arXiv:1209.1409）。反対称彩色はミラー対称性から得る。
  - (2s−1,1,2t−1)-pretzel：Gukov–Nawata–Saberi–Stošić–Sułkowski（arXiv:1512.07883 §5.3）。
- 手順
  1. 閉公式を実装し、KN のノートブックの値（5_2, 6_1, 7_2, 8_1 など）と照合する。
  2. p, s, t を広い範囲で動かして [1], [2], [1,1] を判定する【計算】。
  3. 族全体での証明を試みる：\hat f を p について閉じた形に書き、G 展開の係数が正であることを示す【導出を目標。できなければ範囲を明記した計算にとどめる】。
- 新規性：個々の結び目の 2 箱は KN が計算済み（pretzel・6_2・6_3 は本文、5_2・6_1・7_2・8_1 はノートブック）。新しいのは族全体の主張だけである。

### ステージ T4：thick な結び目の 2 箱（P4）

- 入力：Gukov–Stošić（arXiv:1112.0030）付録 B の 9_42 の [2] 彩色ホモロジー（t_r 次数）。論文から取得する。
- 手順
  1. KN の主張（9_42 の 2 箱は形 (hat-f-2) に乗らない）を再現し、何が破れるか（G 展開が閉じないのか、閉じて負になるのか、どの (g, β) か）を特定する。
  2. thick な結び目では、t_r 次数から t_c 次数への変換が一通りに決まらない可能性がある。変換の自由度を列挙し、正値性を回復する選び方があるかを調べる。
  3. T1 で [1] が破れた thick な結び目があれば、それとの関係を見る。
- 停止条件：[2] 彩色のホモロジーが 9_42 以外の thick な結び目で得られない場合は、9_42 だけで結論を書く。

### ステージ T5：thin な結び目の 3 箱（P5、探索的）

- |ρ| = 3 の \hat f には [2,1] の入力が要る。双曲結び目の [2,1] の refined 不変量は S, T 行列からは得られない（research_plan.md の対象外の項目）。
- KN が 4_1 で行ったように、ミラー対称性・指数増大性と t = q での [2,1] 彩色 HOMFLY-PT から候補を作り、全ての |ρ| = 3 で正値性を満たすものが存在するかを調べる。
- 先に文献で確認すること：ツイスト結び目の [2,1] 彩色 HOMFLY-PT の明示式があるか（4_1 は Anokhina–Mironov–Morozov–Morozov arXiv:1211.6375 にある。他は未確認）。無ければこのステージは行わない。
- 4_1 は両手型性を使えたが、他の結び目では使えないので候補が一意に決まらない可能性が高い。その場合は「正の候補が存在するか」だけを報告する。
