## 0. 結論

1. **候補 1（t = q の [2,1] の円分・微分展開の閉じた式）は、ほぼ既知。** A. Morozov 1612.00422 がダブルツイスト（反平行 double braid）結び目 K_{m,n} の [2,1] 彩色 HOMFLY-PT の微分展開を予想し（式 H21de）、
   1903.00259（「Extension of KNTZ trick to non-rectangular representations」）がそれを KNTZ 型の三角行列 𝓑 で書き直した。そのまま練習問題にすると「既知の予想の独立な検証」にとどまる。
2. **候補 2（その refined 版）は、文献が明示的に残している未解決問題で、練習問題として最も適している。** 1903.00259 は結びで「Macdonald 変形も単純に作れるはずで、それが hyper**多項式**を与えるか（ただし完全に正ではないと疑われている）を見るのは興味深い」と書いている（445 行）。2026-10 までに実行した文献は見つからなかった（§4）。
   正則な行は KNTZ の refined 公式（補間 Macdonald）でそのまま定義でき、新しい未知はほぼ「反常チャネル X̃₂ の行」と「[2,1] の Z 因子 5 個」だけ。判定は族全体に効く条件で行えるので、循環論法を避けられる。
3. **候補 3（Beliakova–Gorsky の補間 Macdonald 基底）は、練習問題には向かない。** BG は t = q（gl_N の RT 不変量）だけを扱い、t は付録の定義と「期待」（407 行）にしか現れない。外部調査 D の「t が基底に自然に現れる」は言い過ぎ。
   さらに、BG 型の Laurent 性（整除性）は第 4 期の自由度 δ の因子に既に含まれる見込みで、u を固定する新しい条件にならない（§3.3【見通し】）。
4. **計算の土台は十分。** ツイスト結び目 K_p の 3 本ケーブルの HOMFLY-PT（Sage）は p = 20（63 本・664 交点、3 つの傾き）で 31 秒。
   ボトルネックは既存の `colored_p` の sympy の解き方（K_3 = 7_2 で 138 秒、K_6 で 400 秒超）で、係数行列を先に逆にして cancel を 1 回にすると K_3 2.1 秒、K_6 4.2 秒、K_12 13.1 秒になった（K_3 で既存の方法と全係数一致）【計算】。|p| ≤ 20 程度は現実的。
5. **全体の判断**：[2,1] は「既存文献の拡張となる練習問題」として十分挑戦できる。題材は「Morozov の [2,1] の KNTZ 型 𝓑 行列（1903.00259）の Macdonald 変形」。
   ただし成否は「族全体の構造条件で refined の未知（X̃₂ の行と Z 因子）が有限個まで絞れるか」に懸かっており、絞れない場合は第 4 期と同じ非一意性（u の自由度）の族版を得て終わる。最初に未知数と条件を数える小さな較正（§6）で、数日のうちに判定できる。

## 1. 円分展開（cyclotomic expansion）の文献

### 1.1 KNTZ 1902.02275（Kameyama–Nawata–Tao–Zhang, "Cyclotomic expansions of HOMFLY-PT colored by rectangular Young diagrams"）

- **方法の要点**【原典】
  - 出発点は Kononov–Morozov 1609.00143 の 4_1 の [r^s] 公式：λ ⊂ [r^s] の和で、各項は D_λ^{(s)}(q) D_{λᵀ}^{(r)}(q⁻¹) Π_{□∈λ}{Aq^{r+a'−l'}}{Aq^{a'−l'−s}}（559–580 行）。
  - Schur 関数の二項定理（Macdonald の本 §3 例 10）の q 変形で B^{(s)}_{λ,μ} を定義し（612–626 行）、入れ子の部分ヤング図形 λ = λ₁ ⊃ … ⊃ λ_m の和でツイスト因子 F^{(m)}_λ を作る（631–640 行）。F は s によらない Laurent 多項式。
  - ダブルツイスト結び目 K_{m,n} の予想式（649–660 行）：4_1 の式の各項に Tw^{(m)}_λ Tw^{(n)}_λ / (Tw^{(1)}_λ Tw^{(−1)}_λ) を掛ける。
  - 任意の結び目の円分展開の予想（Conjecture、672–692 行）：H_{[r^s]} = (単項式)^{rs} Σ_{λ⊂[r^s]} C_{λ,s}(K) D_{λᵀ}^{(r)}(q⁻¹) Π{Aq^{r+a'−l'}}、C は r によらない。
  - refined 版（706–761 行）：Okounkov の補間 Macdonald 多項式 P*_λ の二項公式で 𝐁^{(s)}_{λ,μ}(A,q,t) を定義し（726–733 行）、𝐅^{(m)}_λ と Poincaré 多項式の予想式（746–758 行）を作る。変数は四重次数 (𝐚, 𝐐, 𝐭_r, 𝐭_c)（変数変換 721–722 行）。
- **長方形を使っている箇所**【原典から整理】
  1. 4_1 の出発点の式そのもの（λ ⊂ [r^s] の和と、r, s を含む因子分解した Z 因子）は長方形の 1609.00143 の結果。
  2. 反平行 2 本の撚りの固有値が「λ ⊂ R の対角の合成表現 (λ,λ)」だけで尽きるのは長方形に限る（1903.00259 の 172–176 行の説明と整合）。
  3. refined 版の四重次数 (𝐭_r, 𝐭_c) は長方形の彩色でだけ定義される（515 行：GGS, GNSSS の長方形での提案）。
- **非長方形への言及**：本文で非長方形への拡張について述べた箇所は無い。Discussion（763–771 行）は「一般の彩色の理解は限られており、この式が足がかりになることを望む」と書くだけ。
  ただし 741 行に重要な観察がある：𝐅^{(m)}_λ は**任意の λ について定義**され、常に Laurent 多項式で、length(λ) ≤ 2 なら正係数、> 2 では正負の係数が混ざる。**[2,1] の refined 𝐅 は既に KNTZ の公式で定義済み**（長方形 [2,2] などの和に λ = [2,1] として現れる）。
- 補助ファイル：src/anc/RefinedTwistFactor-and-DoubleBraidPoincarePolynomials.nb（3.6 MB）, UnrefinedTwistFactor-...nb, HOMFLYPTinvariants.m。refined 𝐅 の実装を流用できる見込み（中身は未確認）。

### 1.2 Beliakova–Gorsky 2101.08243（"Cyclotomic expansions for gl_N knot invariants via interpolation Macdonald polynomials"）

- 主定理（232–250 行）：偶数 framing の結び目について J_K(gl_N) = Σ_λ a_λ(K) σ_λ、a_λ(K) = Σ_{μ⊂λ} d_{λμ}(q⁻¹) J_K(V(μ)) ∈ Z[q^±]。J_K(V(μ)) は自明な結び目で 1 に正規化（1883 行）。**任意の彩色**（[2,1] を含む）、ただし **N ごと**。
- **t の扱い**：本文の補間多項式 F_λ は t = q（factorial Schur 関数、2550 行）。補間 Macdonald 多項式 I_λ(x; q, t) は付録（3774–3790 行）で定義を引用するだけで、「q = t で F_λ に特殊化する」と書く。
  t が入るのは 407 行の「圏化した補間多項式は、q を量子次数、t をホモロジー次数とする補間 Macdonald 多項式に対応すると**期待する**」だけ（障害は非斉次性）。外部調査 D の「t は基底パラメータとして自然に現れる」は、本文の範囲では言い過ぎ。
- **HOMFLY-PT 版**：命題「HOMFLY interpolation」（3053–3087 行）は補間多項式 F_λ^{(N)} の Schur 展開を A = q^N の式で与え、係数 b̄_{λμ} は N によらない。系 cor: stability（3034–3044 行）で c, c*, d も (−1)^{C(N,2)} q^{±C(N,3)} 倍を除いて N によらない。
  よって a_λ(K; A, q) := Σ_μ d̄_{λμ}(q⁻¹) H_μ(K; A, q) は A 一様に**定義はできる**。ただし Z[A^±, q^±] に入るかは示されていない。3120 行で「HOMFLY-PT 極限は KNTZ の結果・予想と関係しているようで、正確な関係を見つけるのは興味深い」と書く。
- **[2,1] の具体例**：gl_2 の 8 の字結び目で a_{2,1}(K) = q⁻⁶(−q⁸ − q⁷ − q⁶ − q⁵ + q⁴ + 2q³ + q² + q + 1)（3344 行付近）。gl_2 では V(2,1) ≅ V(1) ⊗ det なので、HOMFLY-PT の [2,1] の情報は持たない。双曲結び目の [2,1] の A 一様な例は無い。

### 1.3 Chen–Liu–Zhu 2110.03616、Fang–Zhou 2608.29585

- Chen–Liu–Zhu 2110.03616（"Cyclotomic expansion for the colored HOMFLY-PT invariants of double twist knots"）：**対称表現 (N) のみ**。Kawagoe の単一和公式から、ダブルツイスト結び目 K_{p,s} の円分展開を証明（定理 1.2、173–184 行）。
- Fang–Zhou 2608.29585（"Cyclotomic Newton Expansions and a Rank-Uniform Integer-Valued Newton Completion"）：**対称表現のみ**。CLZ の SU(n) 円分展開予想を全ての結び目で証明（BG の双対補間公式を入力）。
  A 一様化について：Laurent な微分係数 G_k(K; A, q) ∈ Z[A^±, q^±] は存在するが、Newton 係数の係数環は一般に Z[A^±, q^±] にできない（8 の字結び目が反例、3858–3863 行）。
  今後の課題として「長方形の彩色は多変数の Harish-Chandra 商になり、KNTZ の予想式と比べよ」と書く（3870–3874 行）。非長方形への言及は無い。

### 1.4 [2,1] の円分展開（t = q）は既に計算されているか

### 3.2 文献値との照合

- Gu–Jockers 1407.5643（8 交点以下の 2 橋結び目、4_1 の値は W0 で確認済み）と MMM 1408.3076（ツイスト結び目の全族の閉じた式、§2.1）とは、正規化を合わせれば全係数で照合できる。

### 3.3 BG 型の整除性は新しい条件になるか【見通し】

- 第 4 期の自由度 δ = A⁴(A²−T⁴)(A²Q⁴−1)(Q²−1)(T²−1)(Q−T)(Q²T⁴−1)(Q⁴T²−1)·u/(Q⁵T¹¹) は、[2,1] のフックの因子 (1−q)(1−t)(1−q²t)(1−qt²) 型を（KN の変数で Q² = q, T² = t と読むと）全て含む。
- refined の a_{[2,1]} の分母が d_{[2,1],[2,1]} のフックの因子なら、「a_{[2,1]} が Laurent」という条件は δ で自動的に保たれ、u を固定しない。refined の d の分母は未計算なので見通しにとどまる。

### 4.1 候補 2 の未知数と条件の見通し【見通し】

## 5. 全体の判断

- **挑戦できる**。候補 2 は (1) 拡張元が明確（KNTZ の refined 𝐁 と Morozov の [2,1] の 𝓑）、(2) 文献が未解決として明示（1903.00259 445 行、1208.3544 459 行）、(3) 必要な計算が小さい（|λ| ≤ 3、族のパラメータは整数 2 つ）、(4) t = q の照合データを本研究が定義どおりに大量に作れる、(5) 3_1 で定義どおりの refined の正解がある、の点で練習問題に向く。
- 候補 1・4・5 は数日の前段（ウォームアップ）として有用で、それ自体の新規性は小さい。候補 3 は練習問題には重すぎる。
- 第 4 期との関係：第 4 期は結び目ごとに [2,1] を未知数にして非一意（u が自由）だった。候補 2 は未知を「族に共通の有限個の量」に置き換えるので、族全体の条件が効く。これが本質的に新しい点で、効かなければそのこと自体が結果になる。

## 6. 推奨する最初の一歩

1. **（半日〜1 日）t = q の再現**：1903.00259 の 6×6 の 𝓑^{[2,1]} と Z 因子（1612.00422 の Z の表）を実装し、K_{m,n} の H_{[2,1]} を計算する。3 本ケーブル（§3.1 の高速化した逆解き）で K_p（|p| ≤ 10 程度）と数個の K_{m,n} を計算して全係数で照合する。規約（KN の (a, Q)、reduced、framing 0）の対応をここで固める。
2. **（1〜2 日）refined の正則部分**：KNTZ の refined 𝐁（補間 Macdonald）を |λ| ≤ 2 の行で実装し、対称・反対称の refined の式（GNSSS と同じもの）が出ることを確かめる。その上で [2,1] の行を作る。
3. **（1〜2 日）未知数と条件の数え上げ（停止点の候補）**：X̃₂ の行と Z 因子を未知数（refined の微分の積の有限族）にし、3_1 の EHA の値・族全体の Laurent 性・ミラー・U(2)・指数増大性・t = q を課して解の数を数える。正値性は使わない。
   - 一意（または少数）なら：4_1 で KN の候補と比べ、3 箱の \hat f の正値性を予言として判定する（W4 に接続）。
   - 一意でなければ：残る自由度の形を報告して止める（第 4 期 §3 の δ の族版）。
