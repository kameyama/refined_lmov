# 1703.05408 — Kameyama–Nawata, "Refined large N duality for knots"

- arXiv: 1703.05408（取得版 v3）。DOI・巻・頁：`stage0_bibliography.md` を参照

## 要点

- U(N) refined CS 理論（トーラス結び目・トーラス絡み目）の large N 双対を定式化し、refined CS 不変量を resolved conifold 上の
  refined BPS 不変量 \hat N_{ρ,g,β,J_r} に書き換えた（§3–5）。
- U(1)_R の S_R が BPS 状態に自明に作用するという仮定の下で、\hat N は非負整数になると予想した（正値性予想、`:876-890`）。
- §6（非トーラス結び目）：入力は彩色 HOMFLY ホモロジーの Poincaré 多項式（t_c 次数）を (cov) で書き換えたもの。
  - 付録 C の表：4_1 の [1],[2],[1,1],[3],[2,1],[1,1,1]、5_2・6_1・6_3 の [1],[2],[1,1]。
  - ノートブックのデータ：4_1, 5_2, 6_1, 6_2, 6_3, 7_2, 8_1。
  - 4_1 の [2,1] は既存の superpolynomial ではない。ミラー対称性・指数増大性・両手型性を課して KN 自身が求めた「[2,1] 彩色 refined 不変量」で、負係数を含む（式 (fig8-21)、`:1062-1089`）。
  - 本文に記載の結果：(2s−1,1,2t−1) pretzel 結び目と 6_2・6_3 は 2 箱まで形 (hat-f-2) に乗る（`:1054`）。
    homologically thick な 9_42 と、Whitehead link など非トーラス絡み目では乗らない（`:1099-1102`）。
- ケーブル・iterated torus 結び目・代数的結び目への言及はない（TeX ソースを grep して確認）。

## 使う式

docs/conventions.md §1（変数）、§2（unknot の正規化）、§8（BPS 抽出）に、行番号付きでまとめた。

## 規約

docs/conventions.md を参照。要点は次のとおり：
- (a,q,t) は Ω 背景の変数で a = t^N。太字（DGR）へは a = −**a**²**t**, √q = −**qt**, √t = **q**。
- 不変量は unreduced。ノートブックは対称な unknot 正規化を使う。
