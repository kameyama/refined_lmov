## 内容
- **KNTZ（1902.02275）の長方形の円分展開の予想を、任意の framing 0 の結び目の reduced 彩色 HOMFLY-PT について証明**（要旨、序論 64-159 行）。
  各結び目に係数が Z[A^{±1}, q^{±1}] の二重 Newton 展開を構成し、係数は長方形の幅と高さによらず一意に決まる。
- **KNTZ のダブルツイスト結び目の明示式を、全ての長方形の彩色・全ての 0 でない撚りの数 (m, n) について証明**（ガウス小行列式の三角行列 B^{(s)}）。1 行の場合は Chen–Liu–Zhu（CLZ）がスケインで証明済みだった。
- t = q（彩色 HOMFLY-PT）だけを扱う。refined（t）や非長方形は扱わない。

## 証明の方法（469-530 行）と、長方形への依存
- 一般の結び目：Laurent 整数性、符号と転置の対称性、有限階数の表現の対称性（A = q^M で rω_s と rω_{M−s} を同一視する図式の自己同型）で、幅と高さについて順に割り切れることを示す。
- ダブルツイスト結び目：R = S_{(r^s)}C^N について、Inv(R⊗R*⊗R⊗R*) を「各変数の次数が r 以下の s 変数の対称多項式」と同一視し、Vandermonde を掛けて 1 行の空間の外冪 ∧^s C[t]_{≤r+s−1} にする。
  隣り合う 2 つの Casimir 作用素が、ともに 1 行の作用素の外冪になる（Theorem two-residues）。KZ のモノドロミーで量子の純ブレイドに移し、ダブルツイスト結び目の値を 1 行の行列の語の主小行列式として書く。
- **この外冪の構造は長方形に特有**：長方形では R⊗R* が多重度なしに分解し、不変量の空間が 1 行の外冪になる。[2,1] では R⊗R* に随伴が 2 回現れ（多重度）、この同一視は成り立たない。
  これは Morozov 1612.00422・1903.00259 の [2,1] の微分展開・𝓑 行列に現れる反常チャネル X̃₂ と同じ所に当たる【導出（構造の比較）、論文には非長方形への言及が無い】。

## 「今後の問い」（531-555 行）
1. どの結び目で係数に余分な因子が付くか（T(3,4) では D_0 が E_{2,1} を割らない、Proposition obstruction）。Alexander 多項式や Kononov–Morozov 1504.07146・Lanina–Morozov の defect との関係。
2. A = q^N に特殊化した二重展開と、Beliakova–Gorsky 2101.08243 の中心元・補間 Macdonald 多項式による展開との比較（BG Remark 11.7 の HOMFLY-PT 極限）。
3. **Theorem all-solutions が記述する自由度から、分割で添字づけた係数の族を選ぶ追加の構造を見つけること。KNTZ §3 の refined とホモロジーの式は、有限の係数の恒等式の次数付き（graded）の類似を示唆する。同時のチャネルの比較を次数付きの設定に広げることも関連する問題**（551-555 行）。

## 別研究への影響
- KNTZ の長方形の t = q の部分は定理になった。主軸 X の X0（t = q の実装と規約の固定）では、長方形の彩色（[2], [1,1], [2,2] など）で Fang–Zhou の定理（＝KNTZ の式）を正解として実装を確かめられる。
- 主軸 X（[2,1] の 𝓑 行列の Macdonald 変形）は、Fang–Zhou が扱わない 2 つの方向（非長方形、refined）の両方にあたる。Fang–Zhou の方法は長方形の多重度なしの構造に依存し、[2,1] にはそのままでは使えない。
- Fang–Zhou の問い 3（次数付きの類似）は、KNTZ の refined の長方形の式（ダブルツイスト結び目の superpolynomial の予想）が未証明であることを示す。これも練習問題の候補（refined の長方形の式の検証、新しい副題 Y6）。
- この分野は活発（Fang–Zhou は 2026-09 に投稿、10-08 に更新。同じ著者の 2608.29585 もある）。非長方形・refined への拡張が他から出る可能性があるので、X0〜X2 を早めに進める価値がある。
