# 第 3 期 U1：トーラス・iterated torus 以外の結び目の [2,1] refined 不変量の文献調査（2026-10-06）

調査はサブエージェントによる（arXiv の概要ページ・API・TeX ソース）。† は TeX ソースまで確認したもの。引用・転載はしていない。

## 結論

- トーラス結び目・iterated torus 結び目以外で、[2,1] を含む |λ| ≤ 3 の全彩色の refined 量（3 変数）が、定義に基づく計算としてそろっている結び目は見つからなかった。
- 非トーラス結び目の [2,1] superpolynomial の明示式は、Anokhina–Mironov–Morozov–Morozov（1211.6375†）の 4_1 だけ。条件（Z 因子展開の変形、正値性など）から選んだ予想的な構成で、文献自身が曖昧さを認めている。KN の 4_1 の [2,1] と同じ性格。
  → 第 3 期 U3 の「条件だけでは [2,1] が一意に決まらない」と整合する。
- Cherednik 2607.25666†（Instanton slices and their superpolynomials）：
  - 対象は Coxeter（正ブレイド）結び目（K12n242 = P(−2,3,7)、K12n725 など）。論文中の λ は結び目を指定するヤング図で、彩色ではない。
  - 彩色は minuscule ω_m（列 [1^m]）だけ。明示式は K12n242 の [1] と [1,1] など。[2] は superduality の像として定義（一致は予想）。[2,1]（= ω₁ + ω₂）は構成の範囲外。
  - HOMFLY-PT 型（𝔞 = −t^N で gl_N）。t = q での一致は無彩色について 16 交点までの表で計算機で確認（証明ではない）。補助データは無い。
  - 4_1 は Coxeter 結び目でないので対象外。superpolynomial は負の係数を含むことがある。
