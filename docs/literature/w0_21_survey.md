## 1. 結論

1. **双曲結び目の [2,1] を、a と t の両方つきで、定義に基づいて与えて計算した構成は、どの系統にも無い。**
   - ホモロジー：Cautis 1611.09924（clasp）、Elias–Hogancamp 1801.00191（射影子）、Rose 1109.1745・Cautis 1207.2074・Webster 1309.3796（sl(3) の随伴を含む）は [2,1] を定義できるが、計算例は自明な結び目（と 2 本のトーラス絡み目）だけ。
     非 minuscule の彩色ではホモロジーが無限次元になる（射影子は半無限の複体、Rose の 1638 行など）。
   - 物理・表現論：refined の evolution 法の固有値の規則は多重度のない表現（対称表現）に限られる。4_1 の [2,1] superpolynomial は AMMM 1211.6375 の予想（曖昧さが残り、正値性などで選んだ）だけ。
     knots–quivers は対称表現のみ（KRSS 1707.04017 は任意のヤング図形を今後の課題と明記）。Aganagic らの構成は minuscule・階数固定。
   - ホモロジーを作らない構成：3d–3d の F_K は双曲結び目では sl_2 か対称表現まで（sl_3 の全表現の F_K 2508.15171 は a と t が無く、例はトーラス結び目のみ）。
     Cherednik 2607.25666 は双曲 Coxeter 結び目（K12n242 など）の DAHA 型と motivic の超多項式を与えるが、彩色は minuscule（列）だけ（instantons.tex 376-378 行、確認）。
     前作 2410.14703 は、非 minuscule では motivic 側は知られていないと明記（superpolynoms.tex 4945-4948 行、確認）。
   - Ekholm–Shende 2101.00619 は任意の結び目・任意のヤング図形の彩色 HOMFLY-PT を正則曲線の数え上げで与えるが、t の精密化は無い。
2. **「入力は負になりうるが BPS 不変量 \hat N の段で正」という本研究と同じ型の主張は、双曲結び目については文献に無い。**
   近いのは GPV16 1602.05302・GPPV17 1701.06567（KN が引用。数え上げの段で正）だが、t は Seifert 多様体にしかない U(1)_β から来る（GPPV17 799 行）。
3. **t = q の [2,1] 彩色 HOMFLY-PT は多くの双曲結び目で既知**：ツイスト結び目の全族（MMM 1408.3076、本文で確認）、8 交点以下の 2 橋結び目（Gu–Jockers 1407.5643、4_1 の値は GJ.v3.arXiv.tex 1601 行で確認）、10 交点までの 3 本ブレイドの結び目（1211.6375 付録、1508.02870、1801.09363）。
   本研究の t = q の条件（3 本ケーブルから求める）の照合に使える。
4. **計算ソフト**：[2,1]・sl(3) の随伴・射影子に対応するソフトは無い。KnotJob（Java）と FoamHo（C++）は彩色なしの sl(3)、yui-kr は彩色なしの HOMFLY-PT のみ（ブレイド長 13 程度まで）。

## 3. 停止点 0 で決めること

主軸の候補（推奨順）：
1. **W3 の安い比較**（三葉結び目の [2,1] の index とホモロジーの予想、自明な結び目の比較）：数時間の計算と文献の照合。index と Poincaré 多項式の関係が [2,1] でどうなるかが分かり、W2 の価値も決まる。
