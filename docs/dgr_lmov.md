# DGR・四重次数の考え方を refined LMOV 不変量の spin 表示・genus 表示で（2026-10-11）

ユーザーの依頼：「DGR や quadruply graded homology のような考え方を refined LMOV invariant の spin 表示や genus 表示でできるか研究せよ。同じ構造は成り立たないので、基本的には unrefined や refined の LMOV を観察して 0 から考えよ。」

- 用語は docs/paper/notation.md に従う。
  - spin 表示：genus 展開の前の \hat𝐍_{ρ;i,j,k}
  - genus 表示：展開の後の \hat𝐍_{ρ,g,β,F}
  - 変数は太字 (𝐚,𝐪,𝐭)、framing 0、a 次数のずらしは nontorus 規約。
- コード：`src/rcsknots/dgr.py`（道具）、`scripts/dgr_lmov_survey.py`（一括実行）。
- 記録：`logs/dgr_lmov.log`、`data/dgr_lmov/summary.json`。テスト：`tests/test_dgr_lmov.py`（既定 13 件、10 秒）。
- 印は CLAUDE.md の分類による：【導出】【計算（範囲）】【予想】【仮説】。

## 0. 出発点：何を「DGR 型の構造」と呼ぶか

DGR（math/0505662）と GGS（1304.3481）の構造は、次の 4 つに分けられる。

1. 微分 d_{n|m}（GGS §3.4）
   - 次数は (a,q,t_c) = (−2, 2(n−m), −2m−1)。
   - Poincaré 多項式では、対になった生成元が因子 1 + u_{n|m}、u_{n|m} = 𝐚²𝐪^{−2(n−m)}𝐭^{2m+1} として現れる。
   - KN の小文字では、u_{n|m} = −1 ⇔ a = t^n q^{−m}（U(n|m) への特殊化）。
   - DGR の d_N は d_{N|0}、d_{−N} は d_{0|N}、d_0 は d_{1|1}（HFK）に当たる。
2. 対称性 σ：(e_𝐚,e_𝐪,e_𝐭) ↦ (e_𝐚,−e_𝐪,e_𝐭−e_𝐪)。
   - σ(u_{n|m}) = u_{m|n} で、d_{n|m} と d_{m|n} を入れ替える【導出】。
3. 色付き微分（GS 1112.0030、GGS §3.5）：色付きの d_{±1} のホモロジーは 1 次元で、次数は |λ| に比例する。
4. δ 次数（thin な結び目では台が一つの平面にのる）、t_r と t_c の 2 つの t 次数。

refined LMOV 不変量 \hat f_ρ は、色付き不変量の plethystic log と M(t)^{-1} から作られ、ホモロジーではない。そこで上の 4 つが \hat f_ρ のどの性質に「翻訳」されるかを、データから一つずつ調べた。

## 1. 結果の要約

| DGR / GGS の構造 | spin 表示 | genus 表示 |
|---|---|---|
| d_{0|0}（a = 1）、d_{1|0}（a = t）、d_{0|1}（a = q⁻¹） | \|ρ\| ≥ 2 で各々が \hat f_ρ の因子（§2）。[1] は d_{0|0} だけ | d_{1|0} と d_{0|1} は単独では現れない。σ の軌道の積 (1+u_{1|0})(1+u_{0|1}) = (1+𝐚²𝐭)(1+𝐚²𝐭³) + 𝐚²𝐭²G が、genus を 1 上げる演算子として現れる |
| d の非輪状性（「自由加群」） | 因子 D = Π(1+u) で割った商 R_ρ が非負（§3） | R_ρ が genus 表示でも非負。D も非負なので、KN の正値性は R_ρ の正値性から従う |
| 色付き d_{±1} のホモロジー ≅ 自明な結び目 | framing x では \hat f^{(x)}(K) ≡ c^{\|ρ\|}\hat f^{(x)}(○)（§4） | 同左（σ 不変な形で） |
| d_{1|1}（HFK、a = t/q） | hook 型の λ の値が [1] の量 A_K で決まる（§5） | 𝐚² = −𝐭^{−3} は 𝐪 を含まないので genus ごとに定義される。d_{1|1} で残る最大の genus は \|ρ\|·g(K) − c_ρ で、Seifert genus に比例（§5） |
| d_{n|m} の一般の σ 軌道 | — | (1+u_{n|m})(1+u_{m|n}) は genus 表示で非負、genus の次数は \|n−m\|。d_{n|n} は genus を保つ特殊化（§6） |
| δ 次数（thin） | 成り立たない：商 R_ρ の台は thin な結び目でも 3 次元に広がる（§7） | 成り立たない |
| t = q（非 refined） | d_{0|0} と d_{1|1} が重なり、\hat f_R は (1−a)²(1−aq)(1−aq⁻¹) で割り切れる（§8） | — |

一言で言えば、genus 表示に乗るのは σ の軌道ごとの微分だけで、軌道 {d_{n|m}, d_{m|n}} は genus を |n−m| だけ動かす。
DGR の「d_{±1} は 1 次元のホモロジーを残す」は、|ρ| ≥ 2 の BPS のスペクトルでは「完全に非輪状で、商が正」という、より強い形になる。

## 2. 普遍な因子 D（spin 表示）

**観察【計算】**：framing 0 で \|ρ\| ≥ 2 の全ての \hat f_ρ が
D = (1 + 𝐚²𝐭)(1 + 𝐚²𝐪⁻²𝐭)(1 + 𝐚²𝐪²𝐭³) = (1+u_{0|0})(1+u_{1|0})(1+u_{0|1})
で割り切れる。小文字では (1 − a⁻¹)(1 − t a⁻¹)(1 − q⁻¹a⁻¹) で、a = 1, t, q⁻¹ に零点がある。
- [1] は (1+u_{0|0}) だけで割り切れる（\hat f_{[1]} = (a^{1/2} − a^{−1/2}) rCS_{[1]} そのもの）。
- 他の d_{n|m}（(1|1), (2|0), (0|2)）は、一般には因子にならない。三葉結び目の [2], [3] の (1+𝐚²𝐭³) = (1+u_{1|1}) は結び目に固有のもの。

範囲（全て全係数の厳密な割り算）：
- 3 箱：トーラス結び目 T(2,3), T(2,5), T(2,11), T(3,4), T(3,5), T(3,7), T(4,5)、4_1（[2,1] は KN の候補）、代数的なケーブル K1, K3, K6a, K7, K8, K9、非代数的なケーブル K2, K4, K5a, K5b, K5c, K6b の |ρ| ≤ 3 の全て。
- 2 箱：ツイスト結び目 K_p（|p| ≤ 10、GNSSS の予想式）、10_124, 10_139, 10_152（10_139, 10_152 は quiver と KRSS の予想式）。

**導出【導出（仮定 S_{1|0}, S_{0|1} のもとで）】**：
- 自明な結び目の unreduced 因子 Π_{□∈λ}(t^{l'} − a q^{a'}) は、次の λ で 0 になる。
  - a = 1：全ての λ ≠ ∅。
  - a = t：ℓ(λ) ≥ 2。
  - a = q⁻¹：λ₁ ≥ 2。
- したがって a = t の生成関数 Σ \bar{rCS}_λ g_λ P_λ には、行 [r] だけが残る。
- 次の性質を仮定する。
  - (S_{1|0})：rCS_{[r]}(K)|_{a=t} = c^r
  - (S_{0|1})：rCS_{[1^r]}(K)|_{a=q^{-1}} = c^r
- このとき、a = t の生成関数は自明な結び目のもので x ↦ c x としたものになる。
- 自明な結び目の f^q_μ は μ ≠ [1] で 0 なので（KN :854-855）、\|μ\| ≥ 2 で f^q_μ(K)|_{a=t} = 0。
- M(t) は可逆なので \hat f_ρ(K)|_{a=t} = 0。a = q⁻¹ は f^{\bar t} の側で同様。a = 1 は Z = 1 から自明。

(S_{1|0}), (S_{0|1}) について：
- これは「色付きの d_{±1} のホモロジーは 1 次元で、次数は r に比例する」（GS 1112.0030 予想 4.2・式 (4.4)、GGS §3.5）の Euler 標数版である。
- DAHA の側では Cherednik 2410.14703 §6.3 の「a = −t（A_0）で自明」に当たる。§6.3 の内容はサブエージェントが原典で確認したもので、私は未確認。
- 本研究のデータでは、因子の存在そのものが (S_{1|0}), (S_{0|1}) の |ρ| ≤ 3 での確認になっている。

## 3. 商 R_ρ の正値性（spin 表示と genus 表示）

R_ρ = \hat f_ρ / D（[1] では \hat f_{[1]}/(1+𝐚²𝐭) = rCS_{[1]}）とおく。R_ρ は σ 不変で、genus 展開が閉じる。

**D の genus 表示【導出】**：
- 𝐚²𝐪⁻²𝐭 + 𝐚²𝐪²𝐭³ = 𝐚²𝐭²(w + w⁻¹)（w = 𝐪²𝐭）、G = w + w⁻¹ − 𝐭 − 𝐭⁻¹。
- これから D = (1+𝐚²𝐭)[(1+𝐚²𝐭)(1+𝐚²𝐭³) + 𝐚²𝐭² G] となる。
- D の係数は spin 表示でも genus 表示でも非負なので、R_ρ が非負なら \hat𝐍 と \hat N も非負になる。

**観察【計算】**：R_ρ は spin 表示・genus 表示とも、負の項が 0（全体の符号を一つ選べば、両表示で同じ符号）。対象は次のとおり。
- トーラス結び目 7 個、4_1、代数的なケーブル 6 個の |ρ| ≤ 3（例：K7 の [3] は spin 270929 項、genus 254518 項）。
- ツイスト結び目 |p| ≤ 10 と 10_124, 10_139, 10_152 の 2 箱。

非代数的なケーブル K2, K4, K5a, K5b, K6b は、元の \hat f と同じく、R_ρ にも両表示で負の項がある。K5c は spin 表示では全ての ρ で負の項があり、genus 表示では [1], [2], [1,1], [1,1,1] で正、[3] と [2,1] で負が 3〜4 個である。DAHA の値がホモロジーではないという既知の事情（open_problems D5）に当たる。

**解釈【予想】**：|ρ| ≥ 2 の refined BPS のスペクトルは、外積代数 Λ(d_{0|0}, d_{1|0}, d_{0|1}) 上の自由加群で、その生成元を数えるのが R_ρ だ、と読める。
- DGR では、[1] の d_{±1} は 1 次元のホモロジーを残す。
- |ρ| ≥ 2 の BPS のスペクトルは完全に非輪状で、そのうえ商が正（単に (1+u) で割り切れるより強い）。
- genus 表示では d_{1|0} と d_{0|1} は区別できず、genus を 1 上げる 𝐚²𝐭²G の項として一緒に現れる。

## 4. framing と「d_{±1} のホモロジー ≅ 自明な結び目」

**観察と導出**：framing x ≠ 0 では、framing 付きの自明な結び目の \hat f^{(x)}_ρ が 0 でない ρ で、因子 1+u_{1|0}, 1+u_{0|1} が消える。代わりに次が成り立つ。

  \hat f^{(x)}_ρ(K) ≡ c_K^{|ρ|} \hat f^{(x)}_ρ(○)   mod (1+u_{1|0}) と mod (1+u_{0|1})

- c_K = rCS_{[1]}(K)|_{d_{1|0}} = rCS_{[1]}(K)|_{d_{0|1}} = (−𝐭)^{−Σ}、Σ は S 不変量の半分。GS の残る生成元 (Σ,−Σ,0), (Σ,Σ,Σ) の像で、σ で写り合う。
- 【導出】§2 と同じ議論で、framing の単項式を [r] と [1^r] に掛けたもの。
- 【計算】ツイスト結び目 |p| ≤ 8、x ∈ [−6, 6]、[2], [1,1] の全てで、両辺が一致した。
- framing −1 の自明な結び目の \hat f_{[2]} は −(1+𝐚²𝐭)×単項式で、[1] の自明な結び目の状態がちょうど一つある【計算】。

**同じ構造が成り立たない点【計算】**：
- 分解 \hat f^{(x)}(K) = 𝐭^{−2Σ}\hat f^{(x)}(○) + D·R^{(x)} で、商 R^{(x)} の正値性を調べた。
  - Σ = 0（p < 0 のツイスト結び目）：|x| ≤ 6 の全てで R^{(x)} は両表示で正。
  - Σ = 1（p > 0、1 ≤ p ≤ 8）：x ≠ 0 の全てで、[2] か [1,1] の少なくとも一方に負の項がある（例：三葉結び目の [2] は x = 2 で 1 個、x = −6 で 12 個）。
- 原因は、d_{1|0} と d_{0|1} で残る生成元の次数が違う（σ で写り合う 2 つの単項式）ことにある。σ 不変な単項式で同時に持ち上げられるのは 𝐭^{−2Σ} だけで、これは正値性と両立しない。
- DGR では各微分が自分のホモロジーを残すので問題にならないが、σ で商をとった BPS の言葉では、一つの「自明な結び目の部分」を選べない。

## 5. d_{1|1}（HFK 型、a = t/q）：hook 型の性質と genus の検出

**観察【計算】**：hook λ = (arm+1, 1^{leg}) について、次が成り立つ。

  rCS_λ(K)|_{d_{1|1}} = (−𝐭)^{−(|λ|−1)Σ} · A_K(𝐪^{|λ|}𝐭^{arm(λ)}, 𝐭)、A_K := rCS_{[1]}(K)|_{d_{1|1}}

- d_{1|1} は 𝐚² = −𝐭^{−3} を代入すること。
- 小文字では、A_K の t^{1/2} を q^{arm/2}t^{(leg+1)/2} に置き換えることに当たる。
- 範囲：トーラス結び目 T(2,3), T(2,5), T(3,4), T(3,5)、4_1、K1、非代数的な K2, K4 の |λ| ≤ 3 の hook 全て（|λ| ≤ 3 は全て hook）。ツイスト結び目 |p| ≤ 6 と 10_124, 10_139, 10_152 の [2], [1,1]。
- t = q では、hook 型の色付き HOMFLY-PT は a = 1 で Δ_K(q^{|λ|})、という非 refined の性質に戻る。この非 refined の性質の出典は未確認（調査で見つけていない）。refined 版を述べた文献は見つかっていない。

**帰結【導出（上の性質のもとで）】**：
- a = t/q で自明な結び目の因子が 0 になるのは、(1,1) の箱を含む λ（hook でないもの）だけである。
- したがって \hat f_ρ|_{d_{1|1}} は、全ての ρ で A_K だけの普遍な式で決まる。

**genus 表示での帰結【計算】**：
- 𝐚² = −𝐭^{−3} は 𝐪 を含まないので、genus 表示 Σ \hat𝐍_{g,β,F}𝐚^{2β}𝐭^F G^g に、genus ごとに代入できる。
  - DGR の微分のうち、genus 表示にそのまま乗るのは q 次数 0 のもの（d_{n|n}）だけである（§6）。
- 代入後に 0 でない最大の genus は、商 R_ρ について次のとおり。

  | ρ | [1] | [2] | [1,1] | [3] | [2,1] | [1,1,1] |
  |---|---|---|---|---|---|---|
  | d_{1|1} 後の最大 genus | g | 2g−3 | 2g−2 | 3g−4 | 3g−3 | 3g−3 |

  - g は Seifert genus（[1] の行の値から読んだもの。トーラス結び目と代数的なケーブルでは Seifert genus そのもの）。[1] では A_K の 𝐪 次数が HFK の Alexander 次数なので g になる。
  - 表の式は g ≥ 2 の全ての結び目で成り立つ。g = 1 では [2] と [3] が 0 になる（T(2,3) では d_{1|1} の像そのものが 0）。
  - 代入の前の最大 genus は |ρ|² に比例して大きい。例：T(4,5)（g = 6）の [3] では、代入の前が 49、代入の後が 14 = 3·6−4。
  - 範囲：トーラス結び目 7 個、4_1、代数的なケーブル、非代数的な K2, K4, K5a, K5b, K6b、ツイスト結び目。
  - 例外は K5c だけで、[2] と [3] が表より 1 大きい。
  - D は d_{1|1} で −(1−𝐭⁻²)𝐭⁻¹G となり、ちょうど genus 1 だけを持つ。そのため \hat f_ρ では表より 1 大きい。
- 解釈【予想】：HFK が Seifert genus を検出するのと同じように、genus 表示の d_{1|1} 特殊化は、|ρ| に比例する形で genus を検出する。
  - c_ρ の値の理由（[2] と [1,1] で 1 違うこと）は未解決。
  - genus 1 の結び目（ツイスト結び目、T(2,3)、4_1）では、2 箱と 3 箱の全てで genus 0 だけが残り、𝐪 によらない。

## 6. 一般の d_{n|m} と genus 表示

**【導出】**：u_{n|m} + u_{m|n} = 𝐚²𝐭^{n+m+1}(w^{n−m} + w^{m−n}) で、w^k + w^{−k} は G + 𝐭 + 𝐭⁻¹ の k 次多項式である。
- よって (1+u_{n|m})(1+u_{m|n}) は (𝐚, 𝐭, G) の多項式で、genus の次数は |n−m|。
- n = m なら 1 + u_{n|n} = 1 + 𝐚²𝐭^{2n+1} で genus 0。

**【計算】**：0 ≤ n, m ≤ 3 の全てで、この積の genus 表示の係数は非負だった。

**まとめ**：genus 表示は σ で商をとった表示なので、DGR / GGS の微分は σ の軌道 {d_{n|m}, d_{m|n}} ごとにしか見えない。
- 軌道は genus を最大 |n−m| 上げる正の演算子として働く。
- d_{n|n}（U(n|n)、HFK 型）は genus を保つ特殊化として働く。
- これが「同じ構造は成り立たない」ことの具体的な形である。

**d_{2|0}, d_{0|2}, d_{1|1} は因子にならない**【計算】：
- a = t² では、2 行以下の λ が残り、自明にはならない。U(2) の簡約で関係式は出るが、零点は出ない（conventions §18 の [3,1] の条件と同種）。
- a = t/q では §5 の hook 型の性質になる。

## 7. δ 次数は移らない

**【計算】**：
- [1] は thin な結び目（ツイスト結び目、T(2,3), T(2,5)、4_1）で、DGR の δ = e_𝐚 + e_𝐪/2 − e_𝐭 が一定の平面にのる。
- 商 R_ρ（|ρ| ≥ 2）の台は、これらの結び目でも、spin 表示・genus 表示とも 3 次元に広がる（アフィン包の次元 3）。
- 例外は三葉結び目の R_{[2]}（4 項）で、平面 3e_𝐚 + e_𝐪 − 2e_𝐭 = 4 にのる。
- thin な結び目の色付きホモロジーが δ で決まるという構造は、plethystic log と M(t)^{-1} を通ると保たれない。

## 8. 非 refined（t = q、𝐭 = −1）の観察

**【計算】**：|R| ≥ 2 の非 refined の \hat f_R(a,q) は (1−a)²(1−aq)(1−aq⁻¹) で割り切れる（[1] は (1−a) のみ）。
- 範囲：T(2,3), T(2,5), T(3,4), 4_1, K1, K2, K8 の |R| ≤ 3。
- 4_1 の [2,1] だけは (1−a)³。KN の候補の入力であることに注意。
- (1−a)² の二重の零点は、refined で別々の d_{0|0}（a = 1）と d_{1|1}（a = t/q）が t = q で重なったもの【導出】。
- 非 refined の (1−aq)(1−aq⁻¹) は genus 表示（z² = (q^{1/2}−q^{−1/2})²）で (1−a)² − a z² となり、符号が混ざる。refined の 𝐚²𝐭²G が正になるのは、genus 表示の正値性が refined で初めて意味をもつことと整合する。

**文献との関係**（サブエージェントの調査で、原典の確認はサブエージェントによる）：
- a = 1 の零点は既知である。
  - LM hep-th/0004196 の式 (4.22) の観察。
  - Zhu 2105.02037 の Theorem 1.8 が framed で (a − a⁻¹) で割り切れることを証明。
- a = q^{±1} の因子は、LM の三葉結び目の式 (4.13), (4.21) を因数分解すると (λ−1)²(λ−t)(λt−1) として出てくる（サブエージェントの計算）。ただし、主張として述べた文献は見つからない。
- refined の a = t, q⁻¹ の零点、商の正値性、hook 型の性質の refined 版、genus の検出は、文献に見つからなかった。

## 9. 四重次数（t_r, t_c）について

- [1] では t_r = t_c なので、新しい情報はない。2 箱以上の t_r 次数の入力からは \hat f を作れない。plethystic log と M(t) は Macdonald の t を一つしか使わないためで、t_r と t_c を同時に持ち上げる手段は無い。
- 本研究で見えた「四重次数的」な要素は、GGS の 2 変数の微分族 d_{n|m} が LMOV の側で U(n|m) への特殊化 a = t^n q^{−m} として全て意味をもつこと、そして σ がその添字を入れ替えることである。
- notation.md の S_R（genus 表示の F = 2(J_r − S_R) で見えない次数）は t_r/t_c の分裂の類似の候補だが、rCS からは決められない（未解決）。
