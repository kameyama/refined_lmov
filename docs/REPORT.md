# REPORT：iterated torus（ケーブル）結び目の refined CS 不変量と refined BPS 不変量

作成：2026-10-05。研究計画は docs/research_plan.md、規約は docs/conventions.md、作業記録は docs/progress.md。

用語：superpolynomial は Gukov らの原典（DGR math/0505662 など）の意味、すなわち彩色 HOMFLY-PT ホモロジーの Poincaré 多項式として構造的な性質から組み合わせ的に構成される正整数係数の多項式に限って使う。本研究で計算した refined CS 不変量（DAHA の不変量と一致）は superpolynomial とは呼ばない。

主張にはそれぞれ次の印を付ける。
- 【導出】解析的に導出した。
- 【計算】計算機で確認した（範囲を明記）。
- 【予想】予想である。
- 【仮説】文献から直接取れない式で、裏付けとした検証を併記する。

既知の結果（novelty_report.md §2, §5）は本研究の成果として書かない。

---

## 0. 要約

1. **計算法。** ケーブル結び目の refined CS 不変量を、Gorsky–Negut の楕円 Hall 代数の公式で計算した。
   - DAHA の反復（Cherednik–Danilenko）を companion の段で線形に分解したもの。
   - 1703.05408 の BPS 抽出で、|λ|≤3 の全 6 彩色の refined BPS 不変量 \hat N_{ρ,g,β,J_r} を求めた。
   - 対象は 9 結び目（K1〜K6）。
2. **検証。**
   - トーラス結び目：1703.05408 のノートブックの 27 件の refined CS 不変量と、付録 C の 13 表（T(2,3), 4_1, T(2,5)）を全項で再現した【計算】。
   - ケーブル：Cherednik–Danilenko の DAHA 不変量の明示例 8 件と全係数で一致した（単項式倍を除く）【計算】。
3. **主結果。**
   - refined LMOV 不変量は、小文字の (a,q,t) で f^q, f^{\bar t}, \hat f を求め、読み取る直前に太字へ変換して得た。N^q, N^{\bar t}（f^q, f^{\bar t} の係数）と \hat N（\hat f の係数、G 展開の前と後）の両方を判定した。
   - **代数的なケーブル（K1, K3, K6a）：** トーラス結び目と同じ型【計算】。
     - \hat N：|λ|≤3 の全彩色で、G 展開の前と後の両方が同じ全体の符号の下で非負整数（非長方形の [2,1] を含む）。
     - N^q, N^{\bar t}：対称表現 [1],[2],[3] で非負整数。[1,1],[2,1],[1,1,1] では負の項をもつ（トーラス結び目でも同じ）。
     - refined CS 不変量自体が非長方形で負の係数をもつことは、三葉結び目で既に知られている（成果ではない）。
     - 1703.05408 の正値性予想は、少なくともこれらの代数的な iterated torus 結び目に拡張されると予想する【予想】。
   - **非代数的なケーブル：** 正値性が破れる。
     - K2, K4, K5a, K6b は [1] から破れる。
     - K5b は [1] だけ非負で、彩色付きで破れる。
     - K5c は、G 展開の後の \hat N では |ρ|≤2 と [1,1,1] で非負、[3], [2,1] で破れる（負の項は 6, 7 個だけ）。G 展開の前の \hat N と N^q, N^{\bar t} は [1] から破れる【計算】。
   - 整数性はすべての場合に成り立つ。\hat f は Laurent 多項式で、g 展開は整数で閉じる【計算】。
   - (ρ,g,β) を固定したときの 2J_r の偶奇は、全ケーブルでそろう（4_1 ではそろわない）【計算】。
   - 正値性の破れる項は、表の境界の一本の線（太字変数で最低 𝐭 次数の辺）に集中する例が多い【計算】。

## 1. 規約

docs/conventions.md にまとめた。要点は次のとおり。
- 基準は 1703.05408 の (a,q,t)。太字（DGR）へは a = −𝐚²𝐭、√q = −𝐪𝐭、√t = 𝐪。DAHA とは a_DAHA = −a_KN、(q,t) は同じ。
- ケーブル：(p₂,q₂)-ケーブル（q₂ は companion の Seifert framing）。DAHA の Newton 対は r = (p₁,p₂)、s = (q₁, q₂ − p₁q₁p₂)。代数的 ⇔ q₂ > p₁q₁p₂。
- 単項式の正規化【仮説】：
  - (N1) t=q で framing 0 の彩色 HOMFLY-PT に一致する。
  - (N2) □ で最低 𝐭 次数を 0 にする。
  - (N2') 彩色 λ では M_λ = M_□^{|λ|}·T_λ^{p₂q₂}。
  - 裏付け：トーラス結び目 27 件で KN と完全一致、全ケーブルで (N1) とミラー・転置対称性が成立、\hat f が Laurent 多項式になる。
- BPS 抽出は 1703.05408 のノートブックの手順に従う（M 行列 → a 次数シフト → 太字変数 → g 展開）。
  - 全体の符号は規約である。判定には「全体の符号を選んだときの負の項の最小数」を使う。

## 5. 考察

### 5.1 代数的 vs 非代数的

- 代数的な K1, K3, K6a は全彩色で、\hat N が G 展開の前と後の両方で非負。N^q, N^{\bar t} は対称表現 [r] で非負（トーラス結び目と同じ）【計算】。非代数的な 6 結び目はどれも、少なくとも一つの彩色で正値性が破れる【計算】。
- 非代数的でも、破れ方は一様ではない。
  - K2, K4, K5a, K6b：展開の前も後も [1] から破れる。
  - K5b（(2,7)-ケーブル）：CD14 の「pseudo-algebraic」（非彩色の DAHA 不変量の係数が正）。展開の前も後も [1] では非負で、彩色付きで破れる。
  - K5c（(2,−1)-ケーブル）：展開の後の \hat N は [1],[2],[1,1],[1,1,1] で非負で、[3], [2,1] の負の項は 6, 7 個だけ。ところが展開の前の \hat N と N^q, N^{\bar t} は [1] から負の係数をもつ（57 項中 5 項）。
  - したがって、非代数的な結び目では G 展開の前と後で正値性の判定が一致しない。両方を確かめる必要がある【計算】。
- 展開の後の負の項の位置：
  - K2 の [1]、K6b の [1]、K5c の [3], [2,1] では、少数派の符号の項がすべて一本の線 2J_r − β − g = 一定（太字変数で最低 𝐭 次数の辺）上にある。
  - K5a の [1] では、最大の β の側にある。
  - 破れは表の境界に局在している【計算】。

### 5.2 長方形 vs [2,1]

- refined CS 不変量自体が非長方形の彩色で負の係数をもつことは、三葉結び目で既に知られている。Cherednik–Philipp（1605.00978）も、DAHA の不変量の正値性について長方形が例外的だと述べている。
- 本研究の結果では、代数的なケーブルの refined BPS 不変量は、[2,1] でも G 展開の前と後の両方で非負になる【計算】。
  - 1703.05408 がトーラス結び目で観察した現象が、代数的な iterated torus 結び目でも成り立つ。
  - BPS 不変量の言葉では、長方形の特殊性は消える。
- N^q, N^{\bar t} の正値性は対称表現 [r] に限られ、長方形の [1,1], [1,1,1] でも破れる（トーラス結び目と代数的なケーブルの両方）。N^q で特別なのは長方形ではなく対称表現である【計算】。
- 非代数的なケーブルでは、長方形かどうかに関係なく正値性が破れる。

### 5.3 2J_r の偶奇と S_R

- KN は、トーラス結び目で (ρ,g,β) を固定すると 2J_r の偶奇がそろうことを、U(1)_R の S_R が自明に作用する証拠とした。
- 本研究の全ケーブル（非代数的なものを含む）で偶奇はそろう【計算】。4_1 ではそろわない（KN 付録 C）。
- 非代数的なケーブルの負の項は、偶奇がそろったまま現れる。したがって、S_R が自明に作用しても N̂ の符号の破れは説明できない（N̂ = dim A を前提にすると矛盾する）。これは KN の構成の適用範囲の外であることを示唆する【予想】。

## 6. 未解決点と次のステップ

- **正規化の仮説：** (N1)(N2)(N2') は、ケーブルでは文献から導かれていない。
  - 裏付けは、トーラス結び目での KN との完全一致、全ケーブルでのミラー対称性、\hat f の多項式性。
  - framing 0 の refined 正規化を DAHA または EHA の側から導くことが課題。
- **正値性の破れは、正規化に依存しない。** 表の中の相対的な符号は正規化（全項に共通の単項式）によらない。ただし g 展開の結果自体は q の冪の正規化 (N1) に依存する。
- **K7（3 本ケーブル）、3 段以上の反復：** 実装上は `GN.cable` の繰り返しで可能。
  - companion の次数が p·|λ|（K7 で 9）、パターンの演算子の次数がさらに上がる。
  - 計算量の見積もりと補間の CRT 化（実装済み）で対応できる見込み。
- **monotone/Coxeter links：** 絡み目の refined LMOV（KN §5）を、EHA の多成分版で扱う必要がある。
- **非代数的なケーブルの BPS が負になる理由：**
  - homologically thick な結び目では KN の形式が失敗する（9_42）という報告と同じ方向の現象か。
  - それとも、DAHA の不変量が非代数的な結び目でホモロジーの Poincaré 多項式（Gukov らの意味の superpolynomial）にならないこと（CD14）の反映か。
