## 1. 変数の対応表

### 1.1 基準：KN の (a, q, t)【確定】

- q = e^{iε₁}, t = e^{iε₂}（Ω 背景のパラメータ）。a = t^N で SU(N) refined CS 不変量に戻る。
  KN `refined-integrality.tex:462-465`。
- 「太字」変数（DGR 規約の **a**, **q**, **t**）への変換（KN 式 (cov)、`:861`）：
  a = −**a**²**t**,  q^{1/2} = −**q** **t**,  t^{1/2} = **q**。
  逆に **q** = t^{1/2}, **t** = −(q/t)^{1/2}, **a**² = t^N (t/q)^{1/2}。
- 半整数冪：KN の不変量は q^{1/2}, t^{1/2}, a^{1/2} を含む。太字への変換では上の符号付きの平方根を使う。
  ノートブックは q→q², t→t² としてから a→−A²T, q→−QT, t→Q と置換しており、同じ規約である。

## 2. Macdonald 多項式 P_λ(q,t) の正規化と主特殊化の公式

- P_λ は monic：P_λ = m_λ + Σ_{μ<λ} u_{λμ} m_μ。内積 ⟨p_λ,p_μ⟩_{q,t} = δ z_λ Π (1−q^{λ_i})/(1−t^{λ_i})（KN 付録 A `:1193-1203`、GN `main.tex:228-233`、AS も monic）。【確定】
  実装：`src/rcsknots/macdonald.py`。テスト：q=t で Schur（n≤8）、直交性とノルム（n≤9）、三角性（n≤8）、KN 付録 A の明示式（n≤3）。
- ノルム：(q/t)^{|λ|}/g_λ = ⟨P_λ,P_λ⟩_{q,t} = Π_{s∈λ} (1−q^{a+1}t^{l})/(1−q^{a}t^{l+1})（KN `:1206`）。【確定】（計算機で確認、n≤9）
- 主特殊化：P_λ(1,t,…,t^{N−1}) = Π_{s∈λ} (t^{l'(s)} − a q^{a'(s)})/(1 − q^{a(s)} t^{l(s)+1})（a = t^N）。
  KN 式 (unknot) `:468-475`、GN の ε_N(P_λ) `main.tex:316-332` と同じ。Macdonald の本（VI.6.11'）は手元になく原典未確認。【確定】（計算機で確認：N=2,3,4、n≤6 で直接代入と一致）
- **unknot の正規化**：KN の本文は上の非対称形。ノートブックは対称な主特殊化 P_λ(t^ρ) = (t/a)^{|λ|/2} × 上式を使う（`torusknotsym` の前因子 a^{−n/2} t^{n/2}）。
  BPS 表を再現するには**ノートブックの対称形に合わせる**（g 展開は単項式倍で結果が変わるため）。【暫定：ステージ 2〜3 で確定】

## 16. KN の変数での KNTZ の読み替えと、ダブルツイスト結び目のチャネル分解（別研究 [2,1] の X2、2026-10-08）

- **KN の変数への直接の読み替え**【計算：[2], [1,1], [2,2] × 6 結び目で §15 の経路と全係数一致】：§15 の (cov) と t_c 次数の規則（𝐐 → 𝐪^R, 𝐭_r → 1/𝐪, 𝐭_c → 𝐭𝐪）を合成すると σ → 1 になり、

  したがって KN の rCS は、長方形の行数 R に依らない式で書ける（[2,1] で式を組むときに使う）。
- **チャネル分解**：rCS_R(K_{m,n}) = (T/Q)^{|R|(sgn m + sgn n)/2} Σ_X Z_X τ_X(m) τ_X(n)/τ_X(1)。
  - 正則なチャネル X = λ ⊆ R の τ_λ(m) は KNTZ の 𝐓𝐰^{(m)}_λ から (t/q)^{rs} を除いたもの。R に依らない。τ_λ(−1) = 1, τ_λ(0) = 0。
  - τ_λ(m) = Σ_{μ⊆λ} U_{λμ} e_μ^m は負の m も含めて一つの指数和（refined の 𝓑 の正則な行）【計算：λ ⊆ [2,1]、m = −3..6】。
    固有値 e_μ = (A²Q/T)^{|μ|} Q^{4n(μ')} T^{−4n(μ)}（refined の framing の固有値の 2 乗 × (A²Q/T)^{|μ|}）。t = q で Morozov の Λ²。

    よって rCS の転置対称性とミラー対称性は、チャネルごとの Z̃_X(A, 1/T, 1/Q) = Z̃_{X^T}(A, Q, T)、Z̃_X(1/x) = Z̃_X(x) と同値（チャネルの関数は一次独立）。
  - 正規化の指数 |R|：[2,1] では EGP（rCS_{[1]}·rCS_{[1,1]} の正規化 (T/Q)^{1+2}）から c = 3 = |R| が要る【導出】。
