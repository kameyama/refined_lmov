# タスク指示書：iterated torus（ケーブル）結び目の refined CS 不変量（|λ|≤3 全ヤング図）と refined BPS 不変量の計算

## 0. 目的

Kameyama–Nawata "Refined large N duality for knots"（arXiv:1703.05408）では、主にトーラス結び目・トーラス絡み目について refined Chern–Simons（CS）不変量を resolved conifold 上の refined BPS 不変量 N̂_{R,g,β,J_r} に書き換え、正値性予想を検証している。非トーラス結び目は 4_1 の R=[1],[2],[1,1]（既存の superpolynomial を入力）にとどまる。

本タスクでは、これを **トーラス結び目以外の結び目クラス** に拡張する。

- **対象クラス**：iterated torus 結び目（トーラス結び目のケーブル）。refined 不変量を任意の Young 図形で計算できる非トーラス結び目は、現状これだけである（DAHA: Cherednik–Danilenko arXiv:1408.4348, 1509.08351, Cherednik arXiv:2410.14703。楕円Hall代数: Morton–Samuelson arXiv:1410.0859）。
- **必須の彩色**：|λ| ≤ 3 の全ヤング図形 λ ∈ {[1], [2], [1,1], [3], [2,1], [1,1,1]}。
- **最終成果物**：各結び目・各 λ について、
  1. refined CS 不変量（superpolynomial 型、(a,q,t) の有理式または多項式）
  2. 1703.05408 と同じ規約・同じ形式の refined BPS 不変量の表
  3. 正値性・整数性の判定

---

## 1. 計算対象（優先順）

ケーブルデータ [(p₁,q₁),(p₂,q₂)] は「T(p₁,q₁) の (p₂,q₂)-ケーブル」を表す。q₂ は companion の Seifert framing で測る。代数的になる条件は q₂ > p₁ p₂ q₁ である。

| ID | ケーブルデータ | 種別 | 優先度 |
|---|---|---|---|
| K1 | [(2,3),(2,13)] | 代数的（13 > 12） | 最優先 |
| K2 | [(2,3),(2,1)] | 非代数的 | 最優先 |
| K3 | [(2,3),(2,15)] | 代数的 | 高 |
| K4 | [(2,3),(2,3)] | 非代数的 | 高 |
| K5 | [(2,3),(2,5)], [(2,3),(2,7)], [(2,3),(2,-1)] | 非代数的 | 中 |
| K6 | [(2,5),(2,21)]（代数的: 21>20）, [(2,5),(2,1)] | 代数的／非代数的 | 中 |
| K7 | [(2,3),(3,q)]（q=19 等） | 3本ケーブル | 任意（計算量大） |

K1 と K2 を「代数的 vs 非代数的」の対照ペアとして最初に完成させること。正値性の破れが出るなら、それ自体が重要な結果である。

**対象外**：4_1 などの双曲結び目の [2,1]。refined CS の S,T 行列からは計算できないので手を出さない。

## 2. 基本方針と理論的な骨組み

### 2.1 トーラス結び目（AS の構成）

Aganagic–Shakirov（1105.5117, 1202.2489）。記法は Gorsky–Negut（1304.3328）の §2.6 に従う。

- Macdonald 基底での S,T 行列：
  - S_{λμ} = P_λ(t^ρ q^μ) P_μ(t^ρ)
  - T_{λμ} = δ_{λμ} q^{½Σλ_i(λ_i−1)} t^{Σλ_i(i−1)}
  - **注意**：正規化・γ因子・framing 因子は論文ごとに違う。必ず 1703.05408 の規約に合わせること。
- トーラス結び目：W_{n,m}^λ = K⁻¹ W_{1,0}^λ K（K ∈ SL(2,Z) は (1,0)↦(n,m)）、P_{n,m,λ}(q,t) = ⟨1|S W_{n,m}^λ|1⟩。
- 主特殊化（a = t^N で N 非依存化する）。Macdonald (VI.6.11') を使うが、**実装前に原典で確認すること**：
  P_λ(1,t,…,t^{N−1}) = t^{n(λ)} ∏_{s∈λ} (1 − q^{a'(s)} t^{N−l'(s)}) / (1 − q^{a(s)} t^{l(s)+1})

### 2.2 refined Rosso–Jones（Schur→Macdonald の持ち上げ）

参考文献：Dunin-Barkowski–Mironov–Morozov–Sleptsov–Smirnov（1106.4305）、Mironov–Morozov–Shakirov–Sleptsov（1201.3339）。

  P^{T(m,n)}_R ∝ Σ_{Q ⊢ m|R|} c^{(m)}_{RQ}(q,t) · T_Q^{n/m} · P_Q(主特殊化)

c^{(m)}_{RQ} は、Adams 作用（プレシズム p_k → p_{mk}）を施した Macdonald 多項式を P_Q で展開した係数である。q,t をそのままにするのか、変換が要るのかは、§4 Stage 2 で AS の結果と照合して**決定すること**（文献から推測で決めない）。

### 2.3 ケーブル（本タスクの核心。**仮説として扱い、必ず検証すること**）

非 refined の場合、ケーブル公式（Rosso–Jones の一般化。Morton、Lin–Zheng）は次の形である。

  W_λ(C_{p,q}(K)) = Σ_{μ ⊢ p|λ|} c^{(p)}_{λμ} · θ_μ^{q/p} · W_μ(K)   （K は framing 0、全体に framing 補正因子が付く）

refined 版の作業仮説は、これを次のように置き換えたものである。
- c^{(p)} → Macdonald 版プレシズム係数（§2.2 で確定したもの）
- θ_μ → refined T 固有値
- W_μ(K) → companion K の refined 不変量（§2.1）

これは DAHA の反復構成（Cherednik–Danilenko：各段で SL(2,Z) 作用 → Macdonald 多項式への評価 → 次段の重みに代入）と同値であると期待される。**同値性は Stage 5 で数値的に確認すること。** 一致しない場合は、DAHA 側（1408.4348 の定義）を正とする。

## 3. 環境

- **推奨**：SageMath（`SymmetricFunctions(QQ['q','t'].fraction_field()).macdonald()` が使える）。Sage がない場合は Python + SymPy で Macdonald 多項式を自前実装する。実装方法は Gram–Schmidt でも、Haglund の組合せ公式で修正 Macdonald H̃ を作ってから変換してもよい。
- **ディレクトリ構成**：
  ```
  refined_cables/
    refs/            # 論文PDF・補助ファイル（1703.05408 の Mathematica ノートブック）
    src/             # 実装
    tests/           # 検証（pytest）
    data/            # 計算結果（JSON + 人が読める .txt/.tex 表）
    REPORT.md        # 最終レポート
    LOG.md           # 作業ログ（規約の決定・不一致・未解決点）
  ```
- **データ形式**：各結果を `data/{knot_id}_{lambda}.json` に保存する。中身は多項式の係数辞書と、使った規約のメタデータ（変数対応、framing、reduced/unreduced）。
- **外部送信の禁止**：論文・補助ファイルのダウンロード以外で、外部に計算結果やコードを送信（git push、外部 API へのアップロード等）しないこと。必要な場合はユーザーに目的と内容を伝え、明示的な許可を得てから行う。

## 4. ステージ（順に進め、各ステージの検証が通るまで次へ進まない）

### Stage 0：文献と規約の確定
1. 以下を `refs/` に取得する：1105.5117, 1202.2489, **1703.05408（v3）と ancillary の Mathematica ノートブック2つ**, 1106.4305, 1201.3339, 1304.3328, 1408.4348, 1509.08351, 2410.14703, 1410.0859。
2. 1703.05408 から次を抜き出し、`LOG.md` に「規約表」として記録する：
   - refined CS 不変量の変数（a,q,t）と AS の変数の対応
   - reduced か unreduced か、U(N) か SU(N) か
   - framing の取り方、γ因子
   - refined BPS 不変量 N̂_{R,g,β,J_r} を抽出する式（refined LMOV 型の展開。Macdonald 版の f_R の定義を含む）
3. ノートブックが Mathematica で開けない場合は、テキストとして読んで式を移植する。

### Stage 1：Macdonald 基盤
- P_λ(q,t)（|λ| ≤ 6 は必須。K7 まで行うなら 9 以上）、主特殊化、S,T 行列、プレシズム p_k → p_{mk} を実装する。
- **テスト**：
  - q=t で Schur 関数に戻ること
  - 直交性
  - 主特殊化の閉公式と、N=2,3,4 での直接代入の一致

### Stage 2：トーラス結び目の再現（ここで規約を固定する）
- T(2,3), T(2,5), T(3,4) を全 |R| ≤ 3 で計算する。
- **テスト**：
  1. T(2,3), R=[1] が既知の reduced superpolynomial に一致すること（DGR 規約で a²q⁻² + a²q²t² + a⁴t³。1703.05408 の変数に変換して比較する）。
  2. 1703.05408 のノートブック、またはその表の値と全 R で一致すること。
  3. t=q で colored HOMFLY に戻ること（独立に計算した値と比較する。例えば Sage の `Link.homfly_polynomial()` で [1]。高次の彩色は非 refined の Rosso–Jones で）。
- §2.2 の「q,t を変換するかどうか」はここで確定する。

### Stage 3：refined BPS 抽出コードの検証
- Stage 0 で抜き出した式を実装する。
- **テスト**：
  - T(2,3) について 1703.05408 の表を再現する。
  - 4_1 の [1],[2],[1,1]（論文の Table 16–18）を、論文が入力に使った superpolynomial から再現する。抽出コード単体の検証として行う。

### Stage 4：非 refined ケーブル公式の検証
- §2.3 の公式を t=q で実装する。
- **独立検証**：ケーブルのブレイド表示から HOMFLY（R=[1]）を Sage で計算して比較する。
  - companion の n 本ブレイド β（writhe w）の各ストランドを p 本の平行線に置き換え、1つの束に (σ₁⋯σ_{p−1})^{q − p·w} を挿入する（blackboard framing の補正。**向きと符号を必ず小さな例で検証すること**）。
  - **自明性チェック**：companion を自明な結び目にすると T(p,q) が出ること。p=1 で companion が戻ること。
- K1, K2 の R=[1] で一致したら、R=[2],[1,1] は対称性（R↔Rᵀ）と special polynomial の性質 H_R(q=1) = H_□^{|R|} で確認する。

### Stage 5：refined ケーブル公式と DAHA の照合
- §2.3 の refined 版を実装する。
- **照合**：
  1. Cherednik–Danilenko（1408.4348, 1509.08351）または 2410.14703 に載っている明示例（ケーブル・代数的結び目の DAHA superpolynomial）を探し、少なくとも1例で完全一致させる。
  2. 一致しない場合は、1408.4348 の DAHA 反復を直接実装する（type A、a 安定化）。どちらが正しいかを `LOG.md` に記録する。
  3. Morton–Samuelson（1410.0859）の3変数多項式が利用できるなら、それとも比較する。
- **整合性チェック**：
  - q=t で Stage 4 の HOMFLY に戻ること
  - 鏡像・転置対称性（R↔Rᵀ と q↔t⁻¹ 型。規約は 1703.05408 に合わせる）
  - Anton Morozov（1211.4596）の一次ずれ公式 P_R ≈ P_□^{|R|} + (ħν_R − ħ̄ν_{Rᵀ}) σ_□^{|R|−2} σ₂ を R=[2,1] でチェックする。合わなくても失敗とはしないが、結果は記録する。

### Stage 6：本計算
- 表1の K1 → K2 → K3 → K4 → … の順に、全 6 つの λ について refined CS 不変量と refined BPS 不変量を計算する。
- **計算量の目安**：p=2 のケーブルでは companion を |μ| ≤ 6 で彩色する必要がある。companion が T(2,3) なら、そのプレシズム展開は |Q| ≤ 12 になる。記号計算が重すぎる場合は次の手順をとる：
  1. 各段の中間結果（c^{(p)}、companion の彩色不変量）をキャッシュして再利用する。
  2. それでも重ければ、q,t に多数の有理数点（または大きな素数の有限体）を代入して数値計算し、有理関数補間（a,q,t の次数上限を見積もってから）で復元する。補間の正しさは、補間に使っていない点での一致で確認する。
- 各計算の実行時間とメモリを `LOG.md` に記録する。

### Stage 7：解析とレポート
`REPORT.md` に次をまとめる。
1. 規約表（Stage 0）
2. 各検証の結果（パス／不一致とその解決）
3. 各結び目・各 λ の refined CS 不変量（係数表）と refined BPS 不変量の表（1703.05408 の Table と同形式）
4. 正値性・整数性の判定表：結び目 × λ のマトリクス。負の係数が出た場合は、位置（g, β, J_r）と値を列挙する。
5. 代数的（K1, K3, K6a）と非代数的（K2, K4, K5, K6b）の比較、および長方形（[1],[2],[1,1],[3],[1,1,1]）と非長方形（[2,1]）の比較。Cherednik–Philipp（1605.00978）は、正値性について長方形 Young 図形が例外的だと述べている。この主張とデータが整合するかを評価する。
6. 未解決点と次のステップ（K7、3段以上の反復、monotone/Coxeter links への拡張の見通し）

## 5. 自律作業のルール

- **規約を勝手に調整しない**：既知の結果と合わせるために係数や符号を場当たり的にいじらない。不一致は原因を特定し、規約表を更新して `LOG.md` に記録する。原因が特定できない場合は「未解決」として明記し、先に進めるステージだけを進める。
- **推測した式は明示する**：文献から直接取れなかった式（特に §2.3 の refined ケーブル公式）には「仮説」タグを付け、どの検証で裏付けたかを書く。
- **テストを先に書く**：各ステージで pytest を用意し、全部パスしてから次へ進む。
- **途中経過を保存する**：長時間計算は途中結果をファイルに保存し、中断しても再開できるようにする。
- **停止して報告する条件**：
  - Stage 2 で 1703.05408 の値を全く再現できない（規約の根本的な誤解の可能性）
  - Stage 5 で refined ケーブル公式と DAHA が一致せず、DAHA の直接実装もできない
  - 計算量が見積もりを大きく超える（1つの λ に24時間以上かかる見込み）
  
  これらの場合は、それまでの成果と問題点を `REPORT.md` にまとめて止まる。
