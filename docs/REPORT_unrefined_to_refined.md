# unrefined の LMOV から refined の LMOV を構成する仮定：[2,1]・[3,1] の線形解析（報告、2026-10-11）

ユーザーの指示（2026-10-11）：「この研究の目標は unrefined LMOV のデータから refined LMOV をいくつかの仮定の下で計算できるようになることである。その仮定を見つけたい。
特に重要なのはまだ数の少ない [2,1] や [3,1] のような不変量がこのアプローチで構成できるかどうかである」「unrefined の LMOV（t = q）ではなく 𝐭 = −1 の変数の方が良い可能性がある。どちらの変数が良いかも考えよ」。
印は【導出】【計算（範囲）】【予想】【仮説】。コードは scripts/lmov21_linear.py（[2,1]）、scripts/lmov31_linear.py（[3,1]）、scripts/lmov21_predict_check.py（予言の検査）。
記録は logs/lmov21_linear*.log、logs/lmov31_linear.log、データは data/lmovstruct/lmov21_linear*.json, lmov31_*.json。
3 箱の公式と条件の組み立て（build21）は別セッションの scripts/dgr_box3.py を再利用した（docs/dgr_lmov/report.md「3 箱」）。本報告の新しい点は、正値性（整数計画）を使わずに**一次の条件だけで決まるか**を零空間の次元で定量化したことと、その帰結である。

## 0. 要約

1. **小さな結び目では [2,1] は一次の条件だけで一意に決まる【計算】**：三葉結び目と 4_1 で、(U) t = q（𝐭 = −1）で非 refined の [2,1]、(T) 転置で不変、(E) EGP（q = 1）、(U2) U(2)（a = t²）、(L) 3 箱の \hat f_ρ の Laurent 性、の 5 つの一次の条件で rCS_{[2,1]} の零空間は 0 になり、唯一解は既知の値（三葉結び目は EHA、4_1 は KN の候補）に一致する。正値性も hook 性質も不要（hook は従う）。𝐭 の窓を 3 倍にしても変わらない。
   （第 3〜4 期の「構造的な条件では決まらない（差の次元 6）」は、3 箱の \hat f の Laurent 性を条件に入れていなかったか、窓の取り方が違う。本解析では Laurent 性が決定的に効く：§3。）
2. **結び目が大きくなると一次の条件では決まらない【計算】**：T(2,5) で零空間 70（hook を加えて 20）、T(3,4) で 850（hook で 560）、ツイスト結び目 K_2 で 100（hook で 56）、K_{−2} で 240（hook で 168）。零空間の次元は窓の大きさとともに増える（§3 の構造）。
3. **正値性を加えても決まらない【計算】**：T(2,5) で、3 箱の \hat f の spin 表示・genus 表示・既約表示の正値性を零空間の 20 個の座標の一次不等式にすると、多面体は非有界。非有界方向の \hat f の像は全て非負の係数で、𝐭 と δ の範囲は正解の \hat f の内側にある（正解の台の内外に半分ずつ）。つまり「正解に正の BPS 状態を加えたもの」が全ての条件を満たし、正値性ではこれを排除できない（§4）。
4. **したがって [2,1] を非 refined のデータから決めるには、3 箱の構造（U, T, E, U2, H, L）と正値性の外の仮定が要る**。候補と否定的な結果は §6。4_1 の [3,1] は §5。
5. **変数**：t = q（KN の小文字）と 𝐭 = −1（DGR の太字）は (cov) の下で同じ特殊化であり、入力の情報は同じ。未知数と条件を置く基底としては太字が良い（正値性・W 対称性・既約表示・特殊化の点が単項式の操作になる）。本解析の未知数は太字で置き、t = q の条件は 𝐭 = −1 の交代和として入れている（§1）。

## 1. 変数：t = q か 𝐭 = −1 か

- KN の (cov)：a = −𝐚²𝐭、q^{1/2} = −𝐪𝐭、t^{1/2} = 𝐪。t = q（半変数で Q = T）⇔ −𝐪𝐭 = 𝐪 ⇔ 𝐭 = −1。したがって「t = q の彩色不変量」と「𝐭 = −1 の彩色不変量」は同じ多項式（a = 𝐚²、q^{1/2} = 𝐪 の変数変換）であり、unrefined の入力として情報量は同じ【導出】。
  （もう一つの平方根 Q = −T は 𝐭 = +1 に当たり、Q + T の指数の偶奇が一様でない 4_1 の \hat f などでは別の数になるが、本プロジェクトの「t = q」は Q = T と定義している。）
- 違いは未知数の基底：
  - 太字では rCS_λ の単項式 𝐚^{2β} 𝐪^{2k} 𝐭^{f+k} の係数が未知数で、(U) は各 (β, k) の列で Σ_f (−1)^f x = HOMFLY の係数、つまり **HOMFLY-PT の各係数を 𝐭 次数に分配する圏化の問題**になる。正値性（長方形の rCS、\hat f の spin・genus・既約表示）、W（𝐪 → 1/(𝐪𝐭)、𝐭 固定）、δ 次数、d_{N|M} の対の因子 1 + u はこの基底で単項式の操作である。
  - KN の小文字では t = q の条件は Q と T の指数の対角線 Q + T = 一定 の和で、同じ一次式だが正値性は見えない。gl(N|M) の切り詰め点 a = t^N q^{−M} は両方で単項式代入。
- 結論：構成は太字（DGR の変数）で組み、特殊化の条件は小文字で読む。既存の build21 もそうなっている。「どちらが良いか」は情報ではなく基底の問題で、太字を推す。

## 2. 仮定の定式化（[2,1]）

未知数：rCS_{[2,1]} の太字の係数 x_m。窓は (𝐚, 𝐪) については非 refined の [2,1] の台の箱（打ち消しは 𝐭 の中だけで起きると仮定）、𝐭 は既知の結び目では正解の範囲 ±3〜4（頑健性は 3 倍の窓で確認）、ツイスト結び目では [1] の 𝐭 の範囲の 6 倍。
既知とするもの：refined の [1], [2], [1,1], [3], [1,1,1]（トーラス結び目は EHA、4_1 は KN のノートブック、ツイスト結び目は GNSSS/KNTZ の長方形の式）、非 refined の [2,1]（既知の結び目では正解の t = q、ツイスト結び目は 3 本ケーブルの逆解き data/x0/、Morozov の式と一致済み）。

| 記号 | 仮定 | 一次式の形 | 出所 |
|---|---|---|---|
| U | 𝐭 = −1 で非 refined の [2,1] | 列ごとの交代和 | 定義 |
| T | 転置で不変：rCS_{[2,1]}(a,q,t) = rCS_{[2,1]}(a,1/t,1/q) | x_m = x_{W(m)} | KN のミラー対称性（トーラス結び目で定理、一般は仮定） |
| E | EGP：q = 1 で rCS_{[1]}·rCS_{[1,1]} | 𝐪 方向の和 | KN (EGP)、GGS |
| U2 | a = t² で rCS_{[1]}·rCS_{[1,1]}（[2,1] ≅ [1] ⊗ det） | 単項式代入 | CD14 の安定化、AMMM (D)。非トーラスでは仮説 |
| H | hook：a = t/q で c²·A(𝐪³𝐭, 𝐭) | 単項式代入 | 別セッション §5（gl(1|1) の切り詰め） |
| L | \hat f_{[3]}, \hat f_{[2,1]}, \hat f_{[1,1,1]} が Laurent 多項式 | 分子が分母の各既約因子で割り切れる（因子ごとの代入・剰余、重複度 2 は微分も） | KN の refined LMOV の整数性 |

分母（scripts/dgr_box3.py の formula3）：3A³(Q∓1)²(T∓1)²(Q²+1)(T²+1)(QT∓1)(QT²∓1)(Q²T∓1)(Q²±Q+1)(T²±T+1)（ρ = [2,1] では (Q²+1)(T²+1) を除く）。
零空間の次元は法 p = 2³¹−1 の疎な消去で数え（有理数の次元の上界に一致する確率が高い）、一意なら解を法 p で求めて整数に戻し、全ての式を整数で検算する。

## 3. 零空間の構造【導出】と既知の結び目での結果【計算】

二つの解の差 δ は斉次の条件を満たす：δ(t=q) = 0、W(δ) = δ、δ(q=1) = 0、δ(a=t²) = 0（W で a = q^{−2} でも 0）、そして (L)：\hat f_ρ の C_{21} = unknot_{[2,1]}·rCS_{[2,1]} の項は係数 k_{ρ,21} = q(t−1)(qt+1)/(t^{1/2}(q−1)(q²t−1))（ρ = [2,1]）などを持ち、unknot_{[2,1]} の分母は (1−t)²(1−qt²) なので、δ は (q−1)(t−1)(1−qt²)(1−q²t) で割り切れなければならない。
よって δ = (q−t)(q−1)(t−1)(1−qt²)(1−q²t)(a−t²)(a−q^{−2})·v(a,q,t)（W 対称）の形で、v は窓に収まる必要がある。因子の次数は固定（a で 2、q・t で各 4 以上）なので、窓が小さい結び目では v = 0 が強制される。第 4 期の「差は結び目によらない因子の積 × 自由な多項式」はこの v で、(L) の因子 (1−qt²)(1−q²t) と (q−1)(t−1) が加わると小さな結び目では v の居場所が無くなる。

### 3.1 大きな結び目と 𝐭 の窓の規則【計算】

𝐭 の窓を正解から取るのは予言には使えないので、規則「rCS_{[2,1]} の 𝐭 の範囲 ⊂ rCS_{[2]}·rCS_{[1]} の 𝐭 の範囲」を立てた。既知の 5 結び目（T(2,3), 4_1, T(2,5), T(3,4), K1）で両者の範囲は一致する（T(2,3)：0..15、4_1：−10..10、T(2,5)：0..25、T(3,4)：0..40、K1：0..95）。
（単項式の台そのものは積の台に含まれない。δ = f − 2β の範囲も積の範囲に収まらない。）

## 4. 正値性の多面体（T(2,5)）【計算】

scripts/lmov21_polytope.py：解空間 x = x₀ + K y（K は 2 つの素数で復元した整数基底、整数で検算）の上で、\hat f_ρ = h₀ + Σ y_j h_j（h_j は K の列の像、厳密な割り算）。
正値性は (i) spin 表示（G 展開前の太字の係数 ≥ 0）、(ii) genus 表示（G 展開後 ≥ 0）、(iii) 既約表示（SU(2)_L の指標の係数 ≥ 0）、全体の符号 8 通り。
- T(2,3)：零空間 0 なので 1 点。3 表示とも正で正解。
- T(2,5)：(i), (i)+(ii), (i)+(ii)+(iii) のいずれでも多面体は非有界（乱数の 12 方向で幅 ∞）。非有界方向 d（3 本調べた）の rCS の方向は 448〜492 単項式で符号が混ざり、\hat f_ρ の像は 440〜608 単項式で**全て非負**、𝐭 は 1..25（正解の \hat f は 1..45）、δ は正解の範囲の内側、台は正解の台の内外に半分ずつ。
- 解釈：正解に「正の BPS 状態の組」を足したものも全ての条件を満たす。総数の最小化は原理ではない（別セッションの 2 箱の結果と同じ）。

## 6. 追加の仮定の候補と否定的な結果

| 候補 | 結果 |
|---|---|
| framing x ≠ 0 での Laurent 性 | 斉次部分は framing の単項式倍で変わらないので零空間は不変【導出】。役に立たない |
| 台の包含（rCS_{[2,1]} の台 ⊂ r₂r₁ などの積の台） | 既知の 5 結び目で成り立たない（単項式の偶奇が違う）【計算】 |
| δ の窓 | 正解の δ は積の δ の範囲に収まらない。規則が無い |
| q = 1 での 1 次のジェットの EGP 型の規則：∂_q log rCS_λ|_{q=1} = \|λ\| F₁ + κ_λ F₂（t = q では genus 展開の ħ¹ 次。[1], [2] で較正） | t = q では全ての λ で成立【計算：T(2,3), T(2,5)】。refined では行 [3] だけ成立、列 [1,1], [2,1], [1,1,1] で破れる。n(λ'), n(λ) を別の係数にした拡張（[1], [2], [1,1] で較正）でも [2,1], [1,1,1] で破れ、残差は (a − t³)(a + t³)(t − 1)² などの因子をもつ【計算：T(2,3), T(2,5), 4_1, T(3,4)】 |

| 外部のホモロジーの入力（sl(2) の像、彩色 Khovanov） | 別セッションの長方形の結果と同じく、これが要る可能性が高い |

## 7. 仮定のまとめと、構成できる範囲

- [2,1]：非 refined の [2,1] ＋ refined の長方形 ＋ {T, E, U2, L}（＋H）で決まるのは三葉結び目と 4_1 だけ。T(2,5) 以上では零空間が残り、正値性を加えても多面体が非有界で決まらない。
- したがって「unrefined から refined の [2,1]」は、3 箱の構造だけでは一般には成り立たない。足りないのは、正の BPS 状態の追加を禁じる仮定（上界型の条件）か、ホモロジー側の独立な入力である。
- 変数は太字（𝐭 = −1 が unrefined）で組むのが良い（§1）。
