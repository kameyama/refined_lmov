## 0. 論文の軸

**主張の骨格**
1. **拡張**：KN の refined LMOV（\hat f_ρ と G 展開）を、framing x をもつ結び目に拡張する（rCS^{(x)}_λ = framing[λ]^x rCS_λ）。x = 0 が KN の場合にあたる。
2. **構造**：x を記号のまま扱うと、𝐭^{−nx}\hat f^{(x)}_ρ は x の指数和になる。さらに、KN の枠組みで成り立つ構造的な性質は x によらない。対象は転置対称性・Laurent 性・G 展開が閉じる条件、命題 1・2。
3. **検証**：KN のデータを、2 つの軸で超えて検証する。
   - 結び目の軸：トーラス結び目と 4_1 などの thin な結び目から、代数的な iterated torus 結び目、結び目表の全 801 個、ツイスト・pretzel の族、thick な結び目へ広げる。
   - framing の軸：x = 0 から、有限の範囲の x、さらに全ての整数 x へ広げる。

**KN のデータ（超える対象）**：KN が扱ったのは次のデータで、すべて framing 0 である。
- トーラス結び目・トーラス絡み目の |λ| ≤ 3
- 4_1, 5_2, 6_1, 6_3 などの [1], [2], [1,1]
- 4_1 の [2,1] の候補
これらの再現は規約を固定するためのもので、本論文の成果としては書かない。

## 1. 章立て

仮題：*Refined large N duality for framed knots and positivity beyond torus knots*（日本語の作業題：framed knot への refined large N 双対の拡張と、トーラス結び目を超えた正値性の検証）

### Abstract
- 枠組みの拡張（framed）。
- framing によらない構造。
- 2 つの軸での検証。主な数字：[1] は全ての結び目・全ての x、2 箱は 8 結び目で全ての x とツイスト結び目の全ての p、3 箱は代数的な iterated torus 結び目 7 個。

### 1. 序論
- 1.1 KN の refined large N 双対：\hat f_ρ、G 展開、正整数性の予想。KN が検証した範囲を「KN のデータ」として明示する。
- 1.2 framing：非 refined では Mariño–Vafa が framed の整数性を扱った。refined の KN の枠組みで framing を入れる動機。
- 1.3 本論文の内容：(i) framed への拡張、(ii) x によらない構造、(iii) 2 つの軸での検証。ここに §0 の表を置く。
- 1.4 主結果の一覧（Theorem・Result の番号つき）。
- 1.5 構成。

### 2. 準備
- 2.1 変数と規約（a, q, t と太字の変数。DGR・AS との対応、conventions.md §1〜§6）。
- 2.2 Macdonald 多項式と、楕円 Hall 代数によるトーラス結び目の refined CS（GN の構成）。
- 2.3 KN の refined LMOV
  - \hat f_ρ の定義と G 展開。G 展開の前は \hat𝐍、後は \hat N。
  - 正値性の定義：全体の符号を一つ選べば、全ての項が非負整数になること。
  - [1] の特別な扱い：\hat f_{[1]} = (a^{1/2} − a^{−1/2}) rCS_{[1]}。

### 3. framed knot への拡張（枠組みの章）
- 3.1 定義：framing[λ] = (−(q/t)^{1/2})^{|λ|} q^{n(λ')} t^{−n(λ)}、rCS^{(x)}_λ = framing[λ]^x rCS_λ。これから \hat f^{(x)}_ρ、\hat𝐍^{(x)}、\hat N^{(x)} を定める。
  - 由来（docs/literature/framing_large_n.md）：Taki の refined vertex の framing の因子の逆数にちょうど一致する（IKV の形は誤り）。AS の refined T 行列の固有値とは、箱あたりの単項式を除いて一致する。t = q では MV の (−1)^{ℓp}q^{pκ/2} と x = p で一致する（確認済み）。太字の変数では、符号のない単項式 𝐭^{|λ|+2n(λ')}𝐪^{κ_λ} になる。
  - MV の符号が必要であること【導出】：符号を外すと、奇数の x で 2 箱の \hat f が Laurent でなくなる。
  - 物理的な説明：MV の framed の large N と KN の refined の large N の組み合わせとして述べる（framing_large_n.md §3。U(1)_R が保たれることと、符号の幾何的な導出は仮定・未解決）。
  - x = 0 は KN の場合にあたる。
  - t = q では、非 refined の framed の場合（Mariño–Vafa）に一致する（確認が要る）。
- 3.2 x についての構造【導出】
  - 𝐭^{−nx}\hat f^{(x)}_ρ は x の指数和になる。根は、2 箱で {𝐪²𝐭², 𝐪⁻², 1, −1}、3 箱で 7 個。
  - x の偶奇で分けると、根は係数 1 の単項式になる。
  - framing は、ツイスト結び目の撚りの数 p と同じ型の「撚りの変数」として振る舞う。
- 3.3 x によらない性質【導出】：転置対称性、σ 不変性、Laurent 性、G 展開の補題（閉じていて、展開の前が非負なら、展開の後も非負）。
- 3.4 命題 1（[1]）【導出】
  - 入力が非負係数で DGR の対称性（GHM の定理）をもてば、全ての x で正。
  - framing[□]^x = 𝐭^x なので、x を変えても \hat N の 2J_r がずれるだけである。
- 3.5 命題 2（2 箱の必要条件）【導出】
  - Laurent 性が成り立つには dim H^{[2]} = (dim H^{[1]})² が必要で、この条件は x によらない。
  - 9_42 が KN の形に乗らない理由も、この命題で説明できる。
- 3.6 全ての x での判定法
  - x の偶奇と向きごとにニュートン形を作り、係数の符号を調べる。
  - これに起点から 0 までの直接の判定を合わせれば、全ての x の判定が有限個の判定に帰着する。
- 3.7 正規化との関係【導出、確認済み】：(N2') の彩色依存部分は、ちょうど framing の F（= pq）単位分である（M_λ = (M_□(−(q/t)^{1/2})^{−F})^{|λ|} framing[λ]^F）。AS の三葉結び目の「−6 単位の framing」とも合う。基準の framing を偶数ずらすのは x のずれに吸収される。奇数ずらすのは MV の符号を落とすことにあたり、Laurent 性が壊れる。したがって、x ∈ ℤ の全体での主張は x = 0 の選び方によらない。

### 4. 入力：KN のデータを超える refined 不変量
- 4.1 トーラス結び目（EHA）。KN の 27 件の再現は、規約を固定したこととして述べる。
- 4.2 代数的な iterated torus 結び目（DAHA）
  - DAHA の定義を companion の段で分解して計算する。素朴な Rosso–Jones の t 変形が誤りであることは既知として引用する。
  - 正規化の閉じた式 M_□ は 22 結び目で成立した【計算】。仮説 H_sat の下で導出した【導出】。
  - 検証：CD14 の明示例、ブレイドから計算した HOMFLY-PT、転置対称性。
- 4.3 HOMFLY-PT ホモロジー（[1]、結び目表 801 個、yui-kr）。
- 4.4 2 箱の予想式
  - ツイスト・pretzel は GNSSS。
  - thick な結び目は、quiver（Stošić）と KRSS の (quad-C) を組み合わせる。8_19 で較正した。
- 4.5 厳密な計算
  - 複数の素数での補間と CRT、補間に使っていない素数での検証。
  - 規模：K10 の 3 箱は約 183 万項、係数の最大は 1.1×10¹⁹。
  - 詳細は付録 A に回す。

### 5. 検証 I：[1]
- 801 結び目で、全ての x について正【導出（命題 1）＋計算での確認】。
- 2J_r の偶奇が parity knot（Chandler–Gorsky）と対応すること。

### 6. 検証 II：2 箱
- 6.1 x = 0
  - ツイスト結び目は全ての p で正。
  - pretzel は、同符号は全て正。異符号は min(|s|, t) ≤ 20 で証明し、|s|, t ≤ 40 で確認した。残りが未証明であることを明記する。
  - thick な 10_139, 10_152 も正。
  - 正値性は自動的でない：5_2 では、t_c 次数を別の割り当てにすると負の項が出る。
- 6.2 全ての x【導出＋判定】
  - 自明な結び目、T(2,3), T(2,5), T(2,7), T(3,4), 4_1, K1, K3。
  - 観察：負の向きの起点は、結び目が複雑になるほど遠くなる。
- 6.3 (p, x) の 2 変数
  - ツイスト結び目は、p と x が同符号の向きなら全て正。
  - 逆符号は |p| ≤ 6, |x| ≤ 14 の直接計算だけ。

### 7. 検証 III：3 箱
- 7.1 x = 0：トーラス結び目 5 個と、代数的な iterated torus 結び目 7 個。後者には 3 本ケーブル K7 と 2 段の反復 K10 を含む。
  - 結び目ごとの表と K1 の \hat N の表を載せる。
  - rCS_{[2,1]} 自体は負の係数をもつのに、BPS の段では正になる。
- 7.2 x ≠ 0：自明な結び目、トーラス結び目 4 個、4_1、K1, K3 を、有限の範囲の x で判定した【計算】。
  - 7 根の指数和の構造は同じ。全ての x の証明書は、まだ得られていない。
- 7.3 双曲結び目の 3 箱へ：[2,1] の問題（2〜3 頁）
  - 構造的な条件では決まらない。解の差の因数分解。
  - 弱い判定：4_1 と 6_1 には整数解があり、5_2 は有理数解だけ。
