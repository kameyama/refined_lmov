## 3. V2：[2,1] を決める原理

| 候補 | 結果 |
|---|---|
| V2-1 解の空間の構造 | 三葉結び目の整数計画の解と正解の差 δ = A⁴(A² − T⁴)(A²Q⁴ − 1)(Q² − 1)(T² − 1)(Q − T)(Q²T⁴ − 1)(Q⁴T² − 1)·u/(Q⁵T¹¹)。各因子は既存の条件に由来し、u は自由。因子は結び目によらないので、どの結び目でも現在の条件では一意に決まらない【計算＋導出】 |
| V2-2 他の特殊化 | 正解 10 結び目で、A = ±Q^i T^j（\|i\|, \|j\| ≤ 3）での単項式倍の関係と 2 項の一次関係を探索。U(2) の恒等式（a = t²）とそのミラー（a = q⁻²）以外は無し【計算】（`scripts/v2_specializations.py`, `scripts/v2_linear_relations.py`） |
| V2-3 An. Morozov の一次ずれ公式 | δ は (Q² − 1)(T² − 1) で割れるので、新しい条件にならない【導出】 |
| V2-4 refined の微分展開 | 実施せず（AMMM 1211.6375 自身が構成のパラメータの自由度を認めており、一意性は得られない見込み。ユーザーの判断） |
| V2-5 AMMM と KN の 4_1 の候補の比較 | 同上 |
| V2-6 colored differential の類似 | 微分の条件は非負の Poincaré 多項式に対するもので、負の係数をもつ rCS_{[2,1]} には適用できない【導出】 |

結論：一意性に足りないのは、自由な因子 u を固定する新しい種類の構造（定義に基づく構成）。双曲結び目の 3 箱は、弱い判定（V5）にとどまる。

## 4. V3：恒等式の導出

- U(2) への簡約：a = t² で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}。
  - Macdonald の列の性質 P_{λ+(1^N)}(x₁, …, x_N) = e_N P_λ（N = 2 で確認）と、T 固有値が高さ N の列の追加で q^{|λ|} t^{N(N−1)/2} 倍になる（λ の形によらない）ことから、
    S, T 行列（DAHA/EHA）で書かれる不変量では W_{λ+(1^N)}/W_λ が単項式【導出、トーラス・iterated torus、単項式倍を除く】。
  - unknot の主特殊化でも a = t² で P_{[2,1]} = P_{[1]}·P_{[1,1]}【計算】。
  - 単項式まで含めた一致は正規化 (N1)(N2') に依存し、10 結び目で確認【計算】。非トーラス結び目では【仮説】。

## 5. V4：ツイスト結び目の 2 箱の正値性の証明（進行中）

- 方針：NRZS の式では p が (a t² q^{ℓ−1})^{pℓ} の形でだけ入るので、\hat f_{[2]}(K_p) は p についての指数多項式 Σ_j A_j m_j^p になるはず。
  各ブロック A_j の G 展開の正値性と、大きい |p| で台が分離することが言えれば、小さい |p| の計算と合わせて証明になる。
- 結果【計算：p = 1〜12】（`scripts/v4_twist_structure.py`, `scripts/v4_roots.py`, `scripts/v4_fit.py`、ログ同名）
  - p > 0 で、\hat f_{[2]}(K_p) と \hat f_{[1,1]}(K_p) は p について次数 5 の線形漸化式を満たす（ハンケル行列式）。
  - 特性根は（素数の点で厳密に求めて因数分解）1, 𝐚²𝐭², 𝐚⁴𝐭⁴, 𝐚⁴𝐪⁴𝐭⁸, 𝐚⁴𝐪⁻⁴𝐭⁴。すなわち \hat f(K_p) = Σ_j A_j m_j^p（A_j は p によらない明示的な有理関数）。p = 1〜5 で解き、p = 6〜12 で成立。
  - A_j は個々には Laurent 多項式でない（分母に (𝐚𝐭 − 1)², (𝐚𝐪𝐭² ± 1) など）。和で約分される。m_j のうち 3 つは 𝐚 次数が同じ（4）。
- 結論：「各ブロックの正値性 ＋ 大きい |p| での台の分離」による証明はそのままでは成立しない。証明には NRZS の和（q-Pochhammer の積）の段階での正値性など別の筋が要る【未解決】。
  閉じた形により、大きい |p| での確認は速くできる（未実施）。p < 0 は未解析。
