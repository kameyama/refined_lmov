## 3. V2：[2,1] を決める原理

| 候補 | 結果 |
|---|---|
| V2-1 解の空間の構造 | 三葉結び目の整数計画の解と正解の差 δ = A⁴(A² − T⁴)(A²Q⁴ − 1)(Q² − 1)(T² − 1)(Q − T)(Q²T⁴ − 1)(Q⁴T² − 1)·u/(Q⁵T¹¹)。各因子は既存の条件に由来し、u は自由。因子は結び目によらないので、どの結び目でも現在の条件では一意に決まらない【計算＋導出】 |
| V2-2 他の特殊化 | 正解 10 結び目で、A = ±Q^i T^j（\|i\|, \|j\| ≤ 3）での単項式倍の関係と 2 項の一次関係を探索。U(2) の恒等式（a = t²）とそのミラー（a = q⁻²）以外は無し【計算】（`scripts/v2_specializations.py`, `scripts/v2_linear_relations.py`） |
| V2-3 An. Morozov の一次ずれ公式 | δ は (Q² − 1)(T² − 1) で割れるので、新しい条件にならない【導出】 |
| V2-4 refined の微分展開 | 実施せず（AMMM 1211.6375 自身が構成のパラメータの自由度を認めており、一意性は得られない見込み。ユーザーの判断） |
| V2-5 AMMM と KN の 4_1 の候補の比較 | 同上 |
| V2-6 colored differential の類似 | 微分の条件は非負の Poincaré 多項式に対するもので、負の係数をもつ rCS_{[2,1]} には適用できない【導出】 |

結論：一意性に足りないのは、自由な因子 u を固定する新しい種類の構造（定義に基づく構成）。双曲結び目の 3 箱は、弱い判定（V5）にとどまる。

## 4. V3：恒等式の導出

> **注（文献確認、2026-10-06）**：この恒等式は既知。Cherednik–Danilenko 1408.4348 の安定化定理（A_{n−1} への制限で ω_n = 0、すなわち高さ n の列を除く）に含まれ、AMMM 1211.6375 は [2,1] の superpolynomial の要請 (D)（A = t² で [1] に帰着）として明記している。以下の導出は既知の事実の確認であり、成果ではない。

- U(2) への簡約：a = t² で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}。
  - Macdonald の列の性質 P_{λ+(1^N)}(x₁, …, x_N) = e_N P_λ（N = 2 で確認）と、T 固有値が高さ N の列の追加で q^{|λ|} t^{N(N−1)/2} 倍になる（λ の形によらない）ことから、
    S, T 行列（DAHA/EHA）で書かれる不変量では W_{λ+(1^N)}/W_λ が単項式【導出、トーラス・iterated torus、単項式倍を除く】。
  - unknot の主特殊化でも a = t² で P_{[2,1]} = P_{[1]}·P_{[1,1]}【計算】。
  - 単項式まで含めた一致は正規化 (N1)(N2') に依存し、10 結び目で確認【計算】。非トーラス結び目では【仮説】。

## 5. V4：ツイスト結び目の 2 箱の正値性の証明（進行中）

- 方針：NRZS の式では p が (a t² q^{ℓ−1})^{pℓ} の形でだけ入るので、\hat f_{[2]}(K_p) は p についての指数多項式 Σ_j A_j m_j^p になるはず。
  各ブロック A_j の G 展開の正値性と、大きい |p| で台が分離することが言えれば、小さい |p| の計算と合わせて証明になる。
- 結果【計算：p = 1〜12】（`scripts/v4_twist_structure.py`, `scripts/v4_roots.py`, `scripts/v4_fit.py`、ログ同名）
  - p > 0 で、\hat f_{[2]}(K_p) と \hat f_{[1,1]}(K_p) は p について次数 5 の線形漸化式を満たす（ハンケル行列式）。
  - 特性根は（素数の点で厳密に求めて因数分解）1, 𝐚²𝐭², 𝐚⁴𝐭⁴, 𝐚⁴𝐪⁴𝐭⁸, 𝐚⁴𝐪⁻⁴𝐭⁴。すなわち \hat f(K_p) = Σ_j A_j m_j^p（A_j は p によらない明示的な有理関数）。p = 1〜5 で解き、p = 6〜12 で成立。
  - A_j は個々には Laurent 多項式でない（分母に (𝐚𝐭 − 1)², (𝐚𝐪𝐭² ± 1) など）。和で約分される。m_j のうち 3 つは 𝐚 次数が同じ（4）。
- 文献：superpolynomial の段階での p についての漸化式は実質的に既知（NRZS 1209.1409 の式の構造、Mironov–Morozov–Morozov 1306.3197 の evolution の固有値）。\hat f（refined LMOV）の段階で論じた文献は見つからなかった。
- 結論：「各ブロックの正値性 ＋ 大きい |p| での台の分離」による証明はそのままでは成立しない。証明には NRZS の和（q-Pochhammer の積）の段階での正値性など別の筋が要る【未解決】。
  閉じた形により、大きい |p| での確認は速くできる（未実施）。p < 0 は未解析。

## 6. V5：双曲結び目の 3 箱（弱い判定）

- 入力：[1], [2], [3] は GNSSS の四重次数の式（t_c 次数）、[1,1], [1,1,1] はミラー。KN の 4_1 と三葉結び目の [3], [1,1,1] を全項で再現することを確認【計算】。
- 判定（`scripts/v5_weak.py`、ログ `logs/v5_weak.log`）：[2,1] を未知数とする系（t = q で 3 本ケーブルの [2,1] 彩色 HOMFLY-PT、ミラー、EGP、U(2) の簡約、両手型性（4_1）、
  3 箱の \hat f の Laurent 性、G 展開、正値性）が実行可能か。存在の判定であり、検証としては弱い。
  - 方法：まず LP 緩和を解く（不能なら、x の箱の中に解が無いことが確定）。実行可能なら、制限時間 30 分の整数計画で整数解を探す（見つからなければ未決）。
  - 当初は正値性なしの整数計画も解いていたが、4_1 で 1 時間 20 分たっても終わらなかったため、確認用のこの計算はやめた。
- **4_1（較正）**：dim H^{[3]} = 125 = 5³、[3] の t = q が 3 本ケーブルの値と一致。KN が構成した [2,1] の候補を代入すると、全条件（正値性を含む）を σ = +1 で満たす【計算】。
  σ = −1 では満たさない（全体の符号は一方しか取れない）。判定の仕組みが正しく動くことの確認になる。
- **5_2**：dim H^{[3]} = 343 = 7³、[3] の t = q が 3 本ケーブルの値と一致。σ = +1 は LP 緩和が実行可能（正値性を満たす有理数の [2,1] は存在）だが、整数解は見つからず【未決】。探索は 2 回：目的関数 0 の整数計画（30 分）と、LP の解を丸めた点の近くを目的関数 Σ|x − r| で探す整数計画（30 分、`scripts/v5_round.py`）。判定が弱い形で、強い結論（正値性と両立しない）は LP 緩和の実行可能性により出ないことが確定しているので、ここで打ち切った（ユーザーの判断）。σ = −1 は LP 緩和が不能（解なし）。
- **6_1**：dim H^{[3]} = 729 = 9³、[3] の t = q が 3 本ケーブルの値と一致。σ = +1 で、3 箱の正値性を満たす整数の [2,1] が存在（813 項）【計算】。σ = −1 は解なし。
  得られた [2,1] を入力に加えて従来のパイプライン（`hat_f_exact`）で \hat f を計算し直し、[3], [2,1], [1,1,1] の全てで G 展開の前後とも非負であることを独立に確認。2J_r の偶奇はそろわない（6_1 は parity knot でない）。
- まとめ（弱い判定）：調べた 3 つの thin な双曲結び目で、3 箱の正値性を満たす [2,1] は 4_1（KN の候補）と 6_1 で存在し、5_2 は有理数の範囲では存在（整数は未決）。
  正値性と両立しない例（LP 緩和が不能）は、σ を正しく選ぶ限り見つからなかった。ただし [2,1] は一意でないので、これは KN の予想の検証ではなく「矛盾しない」ことの確認にとどまる。

## 6'. C2：[1] の 2J_r の偶奇と parity knot

- Chandler–Gorsky 2209.13058 v2 §2.2 の parity knot（HHH(K) 上で t/2 の偶奇が一定）は、DGR の太字で「deg_𝐚/2 + deg_𝐭 の偶奇が一定」で、第 2 期で導いた [1] の 2J_r の偶奇がそろう条件と同じ（文献確認のエージェントによる規約の照合）。
- 原典には parity と判定した結び目の一覧は無い（トーラス結び目と T(4,5) のみ）。本研究のデータでは 11 交点以下の parity knot は 9 個で、非トーラスは 10_125, 10_140 だけ【計算】。
- 原典の系：parity knot では偶数番目の d_N^{(i)} が消える。KN の S_R の議論（2J_r の偶奇の一致）と parity knot を結びつけた文献は見つからなかった。
