## A. 3 箱の検証（本来の目的）

### A1. [2,1] の refined 入力が無い
- 背景：KN（1703.05408）の正値性予想を KN の結果を超えて検証するには、|ρ| = 3 の refined LMOV 不変量が要る。\hat f_ρ（|ρ| = 3）は |λ| ≤ 3 の全ての rCS_λ を使い、特に非長方形の [2,1] が必要。
  非長方形の彩色には HOMFLY-PT ホモロジー側の構成が確立しておらず（GGS 1304.3481 の四重次数は長方形のみ）、S, T 行列から計算できるのはトーラス結び目と iterated torus 結び目だけ。
- 分かっていること：トーラス結び目は KN が全彩色で計算。4_1 の [2,1] は、KN が構造的な条件（ミラー対称性・指数増大性・両手型性）で候補を作った（負の係数を含む）。
  第 1 期では代数的なケーブル 3 個（K1, K3, K6a）で、[2,1] を含む全彩色の正値性を確認した。
- 足りないもの：トーラス結び目・ケーブル以外の結び目での [2,1]。→ 第 3 期の主題。
- 第 3 期の結果（docs/REPORT_phase3.md）：構造的な条件（t = q、ミラー、EGP、U(2) への簡約、Laurent 性、G 展開、正値性）だけでは [2,1] は一意に決まらない（三葉結び目で解の差の階数 6）。
  文献にも定義に基づく非トーラスの [2,1] は無い（Cherednik 2607.25666 は列型の彩色のみ）。
  手がかり：解の集合の構造、AMMM 1211.6375 の 4_1 の候補との比較、An. Morozov 1211.4596 の一次ずれの公式、U(2) 以外の特殊化（a = t³ など）。

### A2. K8, K7 の 3 箱
- K8 = T(3,4) の (2,25)、K7 = T(2,3) の (3,19)-ケーブルは計算中（nohup、`logs/u4_cables2.log`）。K8 の [3] の rCS だけで 2 時間を超える。

### A3. U(2) への簡約の恒等式の導出
- a = t² で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}（T(2,3), T(2,5), T(2,7), 4_1 で成立）。refined CS の a = t^N 特殊化から導けるはず（未導出）。

## B. 2 箱（第 2 期）

### B1. 2 箱の正値性の証明
- 背景：[1] の正値性は非負性と DGR の対称性から一般に従う（命題 1）。2 箱は次元の指数増大性が必要（命題 2）だが十分ではなく、t_c 次数の選び方によって負になる（5_2 で確認）。
- 分かっていること：ツイスト結び目 24 個、pretzel 39 個で、δ' = −S（一定）の t_c 次数のとき正【計算、予想式に基づく】。
- 足りないもの：族全体での証明。δ' 一定の t_c 次数がなぜ正値性を与えるのかの理解（GGS の四重次数の構造、colored differential との関係か）。

### B2. 次元が二乗にならない pretzel 16 個
- 背景：GNSSS（1512.07883）の四重次数の式で、K_{s,t} の一部（例 K_{−5,−5}）は dim H^{[2]} ≠ (dim H^{[1]})² になり、\hat f が Laurent でない。
- 足りないもの：これらが実際に thick な結び目か（Nakagane–Sano の表は 11 交点まで）、予想式の適用範囲外か。

### B3. 9_42 の S² ホモロジーの確定
- 背景：GS 1112.0030 の式（誤植あり、修正後 401）、GGS の 401、Stošić 2402.03066 の別の候補（文献確認のエージェントによると 209, 241 生成元、本文は未確認）。命題 2 の結論はどれでも同じだが、ホモロジー自体は未確定。

### B4. thick な結び目の t_c 次数
- 背景：t_r 次数のデータから t_c 次数は決まらない（GGS も同旨）。8_19 では正解を再現する δ' が生成元ごとにばらつく。
- 足りないもの：thick な結び目の t_c 次数を決める原理（8_19 の δ' のパターンの説明）。

## C. [1] と 2J_r の偶奇（第 2 期）

### C1. 命題 1 の強化
- 背景：Chandler–Gorsky 2209.13058 は GHM の sl(2) 作用から各 Δ 次数での対称性と unimodality を述べる。これを使うと G 展開より細かい（sl(2) 既約表現への）分解が得られる可能性がある。ORS 1201.2115 の代数的結び目の BPS 型の展開と、KN の G 展開との関係も未確認。

### C2. parity knot との対応と S_R
- 背景：[1] で (g, β) ごとに 2J_r の偶奇がそろう ⇔ e_𝐭 + e_𝐚/2 の偶奇が一定（導出）。Chandler–Gorsky の parity knot と同じと考えられるが、規約の照合は未確認。
  KN は偶奇の一致を U(1)_R の電荷 S_R の自明作用の証拠としたが、非トーラス結び目 10_125, 10_140 でも偶奇がそろう。S_R の物理的な解釈は未解決。

## D. ケーブル（第 1 期）

### D1. 単項式正規化 (N1)(N2') の導出
- 背景：ケーブルの refined 不変量の単項式倍は DAHA では捨てられる。本研究は (N1)（t = q で framing 0 の HOMFLY-PT）と (N2')（M_λ = M_□^{|λ|} T_λ^{p₂q₂}）を仮説として使った。
  裏付けはトーラス結び目での KN との一致、ミラー対称性、\hat f の多項式性。DAHA/EHA から導いていない（conventions.md §5）。

### D2. 非代数的なケーブルの framing
- 背景：K5b は framing を δ ≤ −14 にずらすと全彩色で正になる。K5c は G 展開の後だけ正。δ が奇数では \hat f が閉じない（理由は未確認）。framing の選び方の原理は未解決。

### D3. 非代数的なケーブルの HOMFLY-PT ホモロジー
- 背景：DAHA の値は非代数的なケーブルではホモロジーの Poincaré 多項式ではない（スペクトル系列の必要条件が破れる）。DGR の手法で作った候補（d₂, d₀ の仮定に依存）は正。
- 足りないもの：yui-kr による直接計算（Rust の導入にユーザーの許可が要る。13〜29 交点で実行可能かは未知）、K5a・K6b の候補の一意性、DAHA の値を候補から得る規則（CD14 の「−1 ↦ 1/t」の一般化）。

### D4. 計算範囲の拡張
- K7（3 本ケーブル）、2 段以上の反復、T(3,4)・T(2,7) のケーブル。CD14・CP16 に [1] の明示例がある（notes_DAHA.md の辞書表）。
