## A. 3 箱の検証（本来の目的）

### A1. [2,1] の refined 入力が無い（2026-10-07：本研究では打ち切り、別研究 docs/research_plan_21.md に移した）
- 背景：KN（1703.05408）の正値性予想を KN の結果を超えて検証するには、|ρ| = 3 の refined LMOV 不変量が要る。\hat f_ρ（|ρ| = 3）は |λ| ≤ 3 の全ての rCS_λ を使い、特に非長方形の [2,1] が必要。
  非長方形の彩色には HOMFLY-PT ホモロジー側の構成が確立しておらず（GGS 1304.3481 の四重次数は長方形のみ）、S, T 行列から計算できるのはトーラス結び目と iterated torus 結び目だけ。
- 分かっていること：トーラス結び目は KN が全彩色で計算。4_1 の [2,1] は、KN が構造的な条件（ミラー対称性・指数増大性・両手型性）で候補を作った（負の係数を含む）。
  第 1 期では代数的なケーブル 3 個（K1, K3, K6a）で、[2,1] を含む全彩色の正値性を確認した。
- 足りないもの：トーラス結び目・ケーブル以外の結び目での [2,1]。→ 第 3 期の主題。
- 第 3 期の結果（docs/REPORT_phase3.md）：構造的な条件（t = q、ミラー、EGP、U(2) への簡約、Laurent 性、G 展開、正値性）だけでは [2,1] は一意に決まらない（三葉結び目で解の差の階数 6）。
  文献にも定義に基づく非トーラスの [2,1] は無い（Cherednik 2607.25666 は列型の彩色のみ）。
  手がかり：解の集合の構造、AMMM 1211.6375 の 4_1 の候補との比較、An. Morozov 1211.4596 の一次ずれの公式、U(2) 以外の特殊化（a = t³ など）。
- 第 4 期の結果（docs/REPORT_phase4.md §3, §6）：解の差は「結び目によらない因子の積 × 自由な多項式 u」。a = t³ などに新しい恒等式は無く、一次ずれの公式と colored differential は新しい条件にならない。
  弱い判定では 4_1（KN の候補）と 6_1 で正の [2,1] が存在、5_2 は有理数解のみ（整数は未決）。u を固定する定義に基づく構成が要る（未解決）。
- 文献調査（2026-10-07、docs/literature/a1_21_constructions.md）：定義・計算例・a 依存性がそろう枠組みは無い。[2,1] の定義があるのはホモロジー側の Cautis 1611.09924、Elias–Hogancamp 1801.00191 のみ（双曲結び目の計算例なし）。
  現実的な道は、これらの [2,1] 彩色ホモロジーを kr-calc（Rust、許可が要る）で 4_1 について計算すること。ただし得られるのは Poincaré 多項式で、KN の rCS（index）との関係は別問題。
- kr-calc（yui-kr）の機能の確認（2026-10-07、ユーザーの指示で A1 の実行に着手）：yui-kr が計算するのは**彩色なし**の reduced HOMFLY-PT ホモロジーだけで、彩色・射影子・ケーブルの機能は無い
  （README、Nakagane–Sano arXiv:2111.00388 の概要「11 交点以下の素結び目」で確認）。したがって「kr-calc で 4_1 の [2,1] を計算する」はそのままでは実行できない。
  - 道 1：yui-kr で 4_1 の 3 本ケーブル（9 本・36 交点の 3 成分絡み目）の彩色なしホモロジーを計算する。得られるのはケーブル絡み目のホモロジーで、ホモロジーの段階では彩色ごとに分解できないので [2,1] は得られない。36 交点が計算できるかも不明（論文の範囲は 11 交点）。
  - 道 2：Elias–Hogancamp の [2,1] 射影子（full twist の圏論的対角化で作る無限複体）を挿入する計算を新たに実装する。研究規模のソフトウェア開発で、計算量も 3 本ケーブルの複体の上にさらに乗る。
  - Rust は導入していない（判断待ち）。

## D. ケーブル（第 1 期）

### D1. 単項式正規化 (N1)(N2') の導出（2026-10-07 大きく前進：仮説 H_sat とトーラス結び目の事実 (I)〜(IV) から導出。conventions.md §13, §13.1）
- 背景：ケーブルの refined 不変量の単項式倍は DAHA では捨てられる。本研究は (N1)（t = q で framing 0 の HOMFLY-PT）と (N2')（M_λ = M_□^{|λ|} T_λ^{p₂q₂}）を仮説として使った。
  裏付けはトーラス結び目での KN との一致、ミラー対称性、\hat f の多項式性。
- 分かったこと：M_□ = (−q/t)^{b−1}(a(q/t)^{1/2})^{δ}（全 22 結び目）。これは
  (A) ケーブルの漸化式 M(C_{p,q}K) = M(K)^p M(T(p,q))、F = pq：framing 演算子による傾きのずれの恒等式（計算で厳密に確認）と refined 衛星公式 H_sat から【導出】。
  (B) トーラス結び目の式：正規化前の値の最低 a 係数が (−t/q)^{m−1} C_{m,n}(1/q,t)（有理 q,t-Catalan、11 例で確認）であることなどから【導出】。
- 足りないもの：(I) の因子 (−t/q)^{m−1} を GN の規約から書き下すこと、GN の Catalan 予想と Mellit の定理（1604.07456）の対応の原典での確認、(IV)「𝐭⁰ の項が最低 a 次数の 1 項だけ」の文献での確認（Hogancamp–Mellit 1909.00418 が候補）。
  H_sat は DAHA/EHA から導けない物理的な仮説として残る。

### D2. 非代数的なケーブルの framing
- 背景：K5b は framing を δ ≤ −14 にずらすと全彩色で正になる。K5c は G 展開の後だけ正。δ が奇数では \hat f が閉じない（理由は未確認）。framing の選び方の原理は未解決。

### D3. 非代数的なケーブルの HOMFLY-PT ホモロジー
- 背景：DAHA の値は非代数的なケーブルではホモロジーの Poincaré 多項式ではない（スペクトル系列の必要条件が破れる）。DGR の手法で作った候補（d₂, d₀ の仮定に依存）は正。
- 足りないもの：yui-kr による直接計算（Rust の導入にユーザーの許可が要る。13〜29 交点で実行可能かは未知）、K5a・K6b の候補の一意性、DAHA の値を候補から得る規則（CD14 の「−1 ↦ 1/t」の一般化）。

### D4. 計算範囲の拡張
- K7（3 本ケーブル）、2 段以上の反復、T(3,4)・T(2,7) のケーブル。CD14・CP16 に [1] の明示例がある（notes_DAHA.md の辞書表）。

### D5. 非代数的なケーブルの DAHA の値による計算は打ち切り（2026-10-06 決定）
- 理由：DAHA の値は [1] で既に HOMFLY-PT ホモロジーの Poincaré 多項式ではない（スペクトル系列の必要条件が破れる）。KN の正値性の前提を満たさない入力なので、負が出るのは予想どおりで、破れ方の分類は KN の予想についての情報にならない。
  型 I/II/III の切り分けと 3 箱までの負の項の数は第 1 期（docs/REPORT.md）で済んでいる。
- 扱うなら別の問い：ホモロジーと整合する入力（DGR 型の候補、命題 2 の次元の条件）が存在するか（D3）。
