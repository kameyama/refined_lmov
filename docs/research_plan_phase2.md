## 0. 出発点

### 0.1 第 1 期で得たもの（詳細は REPORT.md）

- 計算法：Gorsky–Negut の楕円 Hall 代数でケーブルの refined CS 不変量を計算し、KN（1703.05408）の手順で refined LMOV 不変量を読む。
  トーラス結び目 27 件・KN の 13 表・CD14 の 8 例と全係数で一致【計算】。
- 代数的なケーブル（K1, K3, K6a）：|λ|≤3 の全彩色で、\hat{𝐍}（G 展開の前）と \hat N（後）の両方が非負整数【計算】。
- 非代数的なケーブル（K2, K4, K5a, K5b, K5c, K6b）：正値性が破れる。原因は三つの型に分かれる【計算＋導出】。
  - 型 I（K4, K5a）：framing 0 の HOMFLY-PT の段階で、偶奇のそろった refinement では正値性が不可能。
  - 型 II（K2, K5c, K6b）：HOMFLY-PT は両立するが、DAHA の rCS_□ が負。
  - 型 III（K5b）：[1] は正。彩色付きの破れが framing に依存し、δ ≤ −14 で回復。
- [1] での圏化との比較：非代数的な 5 結び目で、DAHA の値は Rasmussen のスペクトル系列の必要条件を満たさない（HOMFLY-PT ホモロジーの Poincaré 多項式ではない）【計算＋定理】。
  DGR の手法で作った superpolynomial の候補は正で、[1] の refined LMOV は G 展開の前後とも正。ただし 2J_r の偶奇がそろわない（4_1 と同型）【計算＋DGR の予想】。

## 1. 目的と成果物

1. Q1, Q2 によって、「refined LMOV 不変量の正値性は代数的な iterated torus 結び目で成り立ち、非代数的なものでは型 I/II/III のどれかで破れる」という描像を、より広いクラスで確かめるか反証する。
2. Q3 によって、[1] での判定（CLAUDE.md の方針：[1] では homological な不変量は全て正整数係数であるべき）の根拠を、予想に基づく候補から定理に基づく計算に置き換える。
3. Q4, Q5 は、非代数的なケーブルで「正しい入力」と「正しい正規化」が何かを問う。結果によっては、KN の枠組みの適用範囲を明示的に述べる。
4. 成果物：REPORT.md の第 2 版、論文（docs/paper/）の改訂、各ステージの data/・tests/・logs/。

### ステージ 8：非代数的なケーブルの走査（Q2）

計算は軽い（[1] は数秒〜数分）ので最初に行う。

- 対象（notes_DAHA.md の辞書表。DAHA の [r,s] は全て照合済みの対応）
  - T(2,3) の (2,q₂)-ケーブル：q₂ = 11, 9（pseudo-algebraic）、−3（CD：非正）、−5（CD：正）。第 1 期の q₂ = 13, 15, 7, 5, 3, 1, −1 と合わせて族を q₂ = −5〜15 でそろえる。
  - T(3,4) の (2,17)-ケーブル（CD：非代数的で正）と (2,11)-ケーブル（C24：非正）。
- 手順
  1. [1] の rCS を計算し、CD14・C24 の明示例と照合する（(2,9), (2,11), (2,−3), (2,−5), T(3,4) の (2,17) は CD14 (6), (7), (f), (g), (h) に [1] がある）。
  2. ブレイドの HOMFLY-PT（`scripts/braid_homfly.sage`）と t = q 極限を照合する。
  3. [1] の \hat{𝐍}, \hat N を判定し、型 I（framing 0 の HOMFLY-PT による障害）を `negativity_cause.py` で判定する。
  4. Khovanov（khoca）と HFK（snappy）を計算し、スペクトル系列の必要条件を検査する（`compare_khovanov.py`）。
  5. [1] の結果を報告したあと、全 6 彩色に進む。|λ|=3 は 1 結び目あたり数分〜1 時間の見込み（K1 で 149 s、K6b で 523 s）。
  6. 型 III の可能性があるもの（[1] が正で彩色付きが負）は、framing 走査（`framing_scan.py`）を行う。
- 成果：q₂ を横軸にした判定表（DAHA の [1] の正値性、\hat{𝐍}/\hat N の正値性、型、L-space か、スペクトル系列の必要条件）。
- 見たい点
  - [1] の \hat N の正値性の境界が、DAHA の正値性の境界（CD：q₂ = 7 と 5 の間）と一致するか。K5c（q₂ = −1）のように G 展開の後だけ正になる例が他にもあるか。
  - CD が「正」とした非代数的なもの（(2,−5), T(3,4) の (2,17)）が、K5b と同じ型 III になるか。
  - 型 I と L-space 結び目であることの関係（第 1 期では型 I の K4, K5a はどちらも L-space、型 II の K2, K5c, K6b はどちらも非 L-space）【計算で観察、未検証】。

### ステージ 9：代数的な iterated torus 結び目への拡張（Q1）

- 対象（全て CD14・CP16 で代数的と確認済み）
  1. T(3,4) の (2,25)-ケーブル（companion が 3 本、CD14 (4) に [1] がある）
  2. T(2,7) の (2,31)-ケーブル（CP16）
  3. T(2,3) の (3,19)-ケーブル（3 本ケーブル、第 1 期の K7。CD14 (3) に [1] がある）
  4. (2,13)-ケーブルの (2,53)-ケーブル（2 段の反復。CD14 は Betti 多項式のみ）
- 手順
  1. まず [1] だけを計算し、計算時間とメモリを測る。companion の彩色の次数は p·|λ|（3 本ケーブルでは [3] で 9、2 段の反復では内側の K1 を |μ| ≤ 2|λ| で彩色）。
  2. [1] を CD14 の明示例と照合する。明示例が Betti 多項式だけのもの（4.）は、rCS_□ の (q=1, a=0) 特殊化と CD14 の DAHA-Betti 多項式を照合する（CD14 が Piontkowski の Betti 数と一致させた値。K1 の 1+3t+4t²+… も同じ照合をテストに加える）。
  3. [1] の \hat{𝐍}, \hat N を判定して報告する。
  4. 見積もりが 1 彩色あたり 24 時間以内なら、全 6 彩色に進む。超えるなら |λ| ≤ 2 で止め、計算量を記録する。
- 見たい点：代数的なら全彩色で正、という第 1 期の予想【予想】が、companion の次数・ケーブルの本数・反復の段数を増やしても保たれるか。
- 計算量の対策：第 1 期の CRT 化（2 素数＋検証用の 3 つ目）を使う。それでも重いときは、パターンの演算子をキャッシュする。

**停止点 A**：ステージ 8, 9 の [1] の結果と、彩色付きの計算量の見積もりを報告し、確認を求める。

### ステージ 10：HOMFLY-PT ホモロジーの直接計算（Q3）

- 道具：yui-kr（Nakagane–Sano 2111.00388 の kr-calc）。Rust が必要。**Rust と yui-kr の導入はユーザーの許可を得てから行う**（環境の変更、ソースのダウンロード）。
- 手順
  1. 導入後、文献の値で検証する：T(2,3)、4_1、Nakagane–Sano の表の thick な結び目（9_42 など）を数件。
  2. 実行可能性：最小のケーブルは 13 交点（K5a, K5b のブレイド）、15 交点（K4）。Nakagane–Sano の最大は 11 交点なので、まず K5b（[1] が正の対照）で時間とメモリを測る。
  3. 動けば K5a → K4 → K2 → K5c の順に計算する。[1] の reduced 三重次数ホモロジーを、DGR 型の候補（`data/superpoly/`）と DAHA の値の両方と比べる。
  4. 結果に応じた結論
     - 候補と一致：DGR の仮定がこれらの結び目で成り立つことの確認。[1] の refined LMOV が正であることが定理に基づく計算になる。
     - 候補と不一致：候補は誤り。ホモロジーそのものから \hat f_{[1]} を作り直して正値性を判定する。
     - いずれでも、DAHA の値との差（CD14 の「−1 ↦ 1/t」の一般化）を記録する。
- 計算が実行できない場合の代わり：sl(3) ホモロジー（khoca の N ≥ 3 は自明な結び目で不正だったので、原因を調べてから使う）と、Khovanov の q 次数の情報で候補を絞る。それでも決まらなければ「未解決」とする。
- 文献地図 §2.3 の通り、ケーブルの三重次数ホモロジーの直接計算例は見つかっていない。計算できれば、それ自体が新しいデータになる（novelty_report.md への追記が必要）。

**停止点 B**：ステージ 10 の結果（または実行不能の判断）を報告する。

### ステージ 11：正規化と framing の原理（Q5）

主に解析的な作業。

1. (N1)(N2') を DAHA の側から導く。CD14 の hat 正規化（単項式を捨てる）と、EHA の演算子の framing の扱い（GN）を比べ、framing 0 の refined 正規化が一意に決まるかを調べる。
2. δ が奇数で \hat f が閉じない理由を確かめる（第 1 期は未確認）。
3. K5b（と、ステージ 8 で型 III になったもの）で、正値性を回復する δ の範囲を、結び目のデータ（companion の Seifert framing、ケーブルの傾き、q₂ − p₁q₁p₂）と比べる。
4. 結論は【導出】か【予想】で分類する。導けない場合は仮説のまま残し、その旨を conventions.md に書く。

### ステージ 12：非代数的なケーブルの彩色付きの superpolynomial 候補（Q4、探索的）

KN §6 が 4_1 に対して行ったことを、ケーブルで試す。

- 対象：K5b（[1] が正、型 III）と K2（型 II）の [2], [1,1]。
- 条件：t = q で彩色 HOMFLY-PT、colored differential と mirror symmetry（Gukov–Stošić 1112.0030）、指数増大性、[1] の候補（ステージ 10 の結果があればそれ）との整合。
- 道具：第 1 期の整数計画（`construct_superpolynomial.py`）を彩色付きに拡張する。
- 判定：候補から \hat f_{[2]}, \hat f_{[1,1]} を作り、G 展開の前後の正値性を見る。
- 制約：彩色付きのホモロジーには Khovanov・HFK に当たる独立な制約が乏しく、候補が一意に決まらない可能性が高い。一意に決まらない場合は、「正の候補が存在するか」「全ての候補で正か」を分けて報告する。
- 停止条件：整数計画が 1 彩色で 24 時間を超える、または候補の自由度が大きすぎて意味のある結論が出ない場合は、そこで止めて報告する。

### ステージ 13：iterated torus 以外への拡張の可能性（Q6、文献調査）

- Cherednik 2607.25666（Instanton slices and their superpolynomials）の本文を取得して読む（論文の取得は許可不要）。
- 調べること：(1) 双曲結び目（K12n242, K12n725 など）の superpolynomial が、彩色付きで、a 依存性まで含めて与えられているか。(2) t = q で HOMFLY-PT に戻るか。(3) KN の \hat f の入力として使える形か。
- 使えるなら、まず [1] で G 展開の前後の正値性を判定する。使えないなら、理由を記録して終える。
- あわせて、文献地図 §5 の未確認事項のうち本研究に関わるもの（CD14 §4.1 の全文、Cab(3,2)T(3,2) の式、PRD 104, 106012 の著者）を確認する。
