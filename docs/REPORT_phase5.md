## 2. 2 箱の正値性の証明（REPORT_phase4.md §5.1, §5.2）

前提：入力は GNSSS 1512.07883 の四重次数の予想式と、t_c 次数 δ' = −S（第 2 期）。

### 2.1 ツイスト結び目 K_p（全ての p ≠ 0）
- \hat f(K_p) は p について根 {1, X, X², Y, Ȳ}（X = 𝐚²𝐭², Y = 𝐚⁴𝐪⁴𝐭⁸, Ȳ = 𝐚⁴𝐪⁻⁴𝐭⁴）の指数多項式【導出】。
- 差分商の形（ニュートン形）s_{1+n} = Σ c_k h_{n−k} の係数 c_k が全て同符号（有限個の厳密な判定）。G 展開の後は、補題「展開が閉じる ＋ 展開前に非負 ⇒ \hat N ≥ 0」（命題 1 の補題から）で従う。
- c_k の構造【導出】：c_4 は (1 + 単項式) 型の 8 因子の積、c_3 は sl_2 指標 [n]_v の正係数の和。c_2 の正値性は構造からは導けていない（相殺が必須）が、c_2 を使わない LP 証明書（根の部分集合ごとの完全斉次対称式の非負結合）でも全ての p での正値性を示した。
- 単峰性：\hat f(K_p) は全ての p で v = 𝐪²𝐭 について sl_2 指標の正係数の和【導出 ＋ 有限個の判定】。[1] の単峰性は Gorsky–Hogancamp–Mellit 2103.01212 の hard Lefschetz から全ての結び目で従う【導出（次数の対応は観察）】。

### 2.2 pretzel K_{s,t}
- 同符号の領域：2 変数のニュートン形で全ての (s, t)【導出 ＋ 有限個の判定】。
- 異符号の領域：直線ごとの 1 変数のニュートン形で min(|s|, t) ≤ 20【導出 ＋ 有限個の判定、80 件】。|s|, t > 20 は、くさびへの分割と鏡像型の恒等式で 1 変数の 3 つの数列の非正値性に帰着し、そのうち d_2, d_3, d_4 は LP 証明書で示した（証明書は data/v4/）。
  残る d_1（両 ρ）と対角線は u ≤ 25 で成立【計算】。d_1（ρ = [2]）の LP は約 14 時間で残差 2414 → 60.3 まで進んだが未収束で、**ユーザーの判断で打ち切った**（2026-10-08）。途中結果は data/cache/v4_pretzel_np2_cg_1_2_0.pkl（git に入れてある）。
- 直接の確認【計算】：|s|, |t| ≤ 20 の 820 点、異符号で 21 ≤ |s| ≤ 30・21 ≤ t ≤ 40 の 200 点で（2026-10-09 訂正：以前の「|s|, t ≤ 40 の 264 点」は、200 点に含まれる 21..28 の正方形 64 点を重ねて数えていた）、両 ρ・G 展開の前後とも負の項 0。

## 3. thick な非トーラス結び目の 2 箱（open_problems.md B4）

- 文献で S² ホモロジーが知られている thick な非トーラス結び目は 9_42 と 10_132 だけで、どちらも次元が二乗でない。命題 2 の帰結（H^{[2]} の 𝐚 次数は H^{[1]} の 𝐚 次数の対の和に収まる必要がある）により、t_c 次数によらず KN の形に乗らない【導出＋計算】。
- t_c 次数の原理：Stošić 2402.03066 の quiver 型の式を展開し、KRSS 1707.04017 の予想式 (quad-C) で S^r の四重次数を作る。8_19 = T(3,4) で EHA の [2], [1,1], [3], [1,1,1] と単項式倍なしで全項一致【計算】（8_19 の t_c 次数と refined CS の一致そのものは GNSSS で既知）。
  第 2 期で δ' が生成元ごとにばらついた原因は quiver の非対角成分 C_ij。
- **10_139, 10_152**：S² の次元は 441 = 21², 841 = 29²。t = q の極限はケーブルから逆に解いた [2], [1,1] 彩色 HOMFLY-PT と一致。2 箱の \hat f は G 展開の前後とも正【計算、予想式に基づく】。
  新規性：文献の範囲では見当たらず、knots–quivers の DT 不変量の正値性からも従わない（EKL 1811.03110 が KN の t_c の精密化は motivic 級数の形と両立しないと明言）。novelty_report.md §9。
- 3 箱は [2,1] の入力が無いので扱えない（別研究）。

## 4. ケーブルの正規化の導出（conventions.md §13, §13.1、open_problems.md D1）

- 閉じた式 M_□ = (−q/t)^{b−1}(a(q/t)^{1/2})^{δ}（b はブレイドの本数、δ は種数型の量）が保存済みの 22 結び目で成立【計算】。
- ケーブル → トーラス結び目【導出、仮説 H_sat の下】：framing 演算子による傾きのずれの恒等式（厳密に確認）と refined 衛星公式 H_sat から M(C_{p,q}K) = M(K)^p·M(T(p,q))。
- トーラス結び目【導出】：正規化前の値の最低 a 係数が (−t/q)^{m−1} C_{m,n}(1/q, t)（有理 q,t-Catalan 数）。これは GN の Catalan 予想で、Mellit 1604.07456 の定理の系（BGLX の演算子と本研究のコードの演算子の対応も導出）。
  最低 a 次数は Franks–Williams 1987、「𝐭⁰ の項は 1 つだけ」は Mellit 1704.07630 の Dyck 路の式から。
- 残り：Mellit の Cor (daha) の正規化（符号と a → a/q）の原典での確定（数値では確定、ここで止めた）。H_sat は DAHA/EHA からは導けない物理的な仮説として残る。

## 5. 訂正（REPORT_phase4.md §8）

- 第 2 期 T3 の「次元が二乗にならない pretzel 16 個は Laurent でない」と、第 4 期 B2 の「GNSSS の式は 19 個で special polynomial の性質を破る（式の不備）」は、どちらも入力スクリプト scripts/t3_pretzel.py の浮動小数点のバグ（q-Pochhammer の初期値が Python の int で qbinom(0,0) = 1.0）による。
- 修正後は s, t ∈ [−5, 5] の 55 個全てで次元が二乗、special polynomial の性質が成立し、全て 2 箱で正。V5 で使った 4_1, 5_2, 6_1 の入力は修正の前後で一致し、V5 の結論は変わらない。修正前のログは logs/*_float_bug.log。
