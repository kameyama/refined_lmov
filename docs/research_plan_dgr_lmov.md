## 0. 問いの整理

DGR（math/0505662）の superpolynomial の構造は (i) 正整数係数、(ii) 𝐭 = −1 で HOMFLY-PT、(iii) 微分 d_N（𝐚 = 𝐪^N で sl(N) ホモロジーに落ちる）、(iv) 対称性 𝐪 → 1/(𝐪𝐭)（本研究の規約。GHM が証明）、(v) d_1 で 1 項、d_0 で knot Floer、の組である。
GGS（1304.3481）の四重次数は、彩色の場合にこれを (vi) 彩色微分 d_{λ→μ}、(vii) ミラー対称性 λ ↔ λ^T、(viii) 指数増大性、(ix) 第 4 の次数 t_r/t_c で整える。

refined LMOV 不変量 \hat f_ρ（KN の \hat f、G 展開の前の \hat{𝐍}_{ρ;i,j,k} と後の \hat N_{ρ,g,β,J_r}）は superpolynomial ではない。|ρ| ≥ 2 では複数の彩色の rCS_λ と Adams の写しの非線形な組合せで、ホモロジーの Poincaré 多項式として定義されているものは無い。
したがって「同じ構造」は期待できない。本計画では、\hat f_ρ の側で**自然に定義できる次数・基底・特殊化**を列挙し、DGR・GGS の各構造に当たるものがあるかを、unrefined（t = q）と refined の LMOV の観察から決める。

## 1. 辞書（0 から考えるための変数の整理）【導出】

KN の小文字 (a, q, t) と太字 (𝐚, 𝐪, 𝐭)（a = −𝐚²𝐭, q^{1/2} = −𝐪𝐭, t^{1/2} = 𝐪、conventions.md §1）に対して、次の変数を使う。

| 記号 | 定義 | 意味 |
|---|---|---|
| w | w = 𝐪²𝐭 = −(qt)^{1/2} | SU(2)_L の重みの変数（refined topological string の q_L） |
| 𝐭 | 𝐭 = −(q/t)^{1/2} | U(1)_R の電荷の変数（SU(2)_R はブレーンで U(1)_R に破れる） |
| 𝐚² | 𝐚² = −a/𝐭 | a 次数（2β） |
| G | G = (q^{1/2}−q^{−1/2})(t^{−1/2}−t^{1/2}) = w + w^{−1} − 𝐭 − 𝐭^{−1} | KN の種数の因子。= χ_{1/2}(𝐭) − χ_{1/2}(w)（SU(2)_L の 1/2 と U(1)_R の ±1 の差） |
| W | (a, q, t) ↦ (a, 1/t, 1/q)、太字では (𝐚, w, 𝐭) ↦ (𝐚, 1/w, 𝐭) | SU(2)_L の Weyl 反転 ＝ DGR の対称性 𝐪 → 1/(𝐪𝐭) ＝ KN のミラー対称性 rCS_{λ^T} = W(rCS_λ) の変数の部分 |

単項式 𝐚^{2β} w^k 𝐭^f（太字 (e_𝐚, e_𝐪, e_𝐭) = (2β, 2k, f + k)）に対し、(β, k, f) = (a 次数, SU(2)_L の重み, U(1)_R 電荷)。KN の 2J_r は f に当たる。

この辞書で次が式の上で分かる。
- **G 展開が閉じる ⇔ \hat f_ρ が W 不変 ⇔ KN の形 (hat-f-2) ⇔ KN の整合条件 f^{\bar t} = M(q^{−1}) \hat f**。
  （(refined-GT1) と (refined-GT2) は互いに W の像で、f^{\bar t}_μ = (t/q)^{|μ|} W(f^q_μ)。f^{\bar t} = M(q^{−1})\hat f は \hat f = W(\hat f) と同値。）
  つまり KN の「G 展開が閉じる」は、DGR の対称性（GHM の定理）の彩色・LMOV 版である。
- **DGR の微分 d_N の消去点は a = t^N**：degree (−2, 2N, −1) の対 (β, k, f), (β−1, k+N, f−1−N) が恒等的に打ち消す特殊化は 𝐚² = −𝐪^{2N}/𝐭、すなわち KN の小文字で a = t^N（SU(N) refined CS の特殊化そのもの）。
  同様に a = 1（N = 0）は d_0 の消去点、a = t は d_1 の消去点。W の像 a = q^{−N} は転置した理論の SU(N)。
- **q = 1 と t = 1 では G = 0**：\hat f_ρ(q = 1) と \hat f_ρ(t = 1) は種数 0 の \hat N だけを含む。refined 指数増大性（q = 1 で rCS_λ = Π rCS_{ω_i}^{λ_i}）は、LMOV では「種数 0 の部分」の構造である。
- **q = t（unrefined）**：N_{ρ,g,β} = (−1)^g Σ_{J_r} (−1)^{2J_r} \hat N_{ρ,g,β,J_r}（KN）。unrefined の LMOV の q → 1/q 反対称性 f_ρ(a, 1/q) = −f_ρ(a, q) は W の t = q への制限。
- **δ 次数**：δ := f − 2β（= e_𝐭 − e_𝐪/2 − e_𝐚）。thin な結び目の P は δ が 1 値（4_1, T(2,3) など）。\hat f_{[1]} = (1 + 𝐚^{−2}𝐭^{−1}) P は δ ∈ {c, c+1}。

## 2. 計画を立てる前の観察（2026-10-11、保存済みデータ）【計算】

スクリプトは一時的なもの（$TMPDIR）。本番の実装は S0 で `src/rcsknots/lmovstruct.py` に移す。

1. **W 不変性**：data/bps/ の全 120 件（21 結び目 × |ρ| ≤ 3、非代数的なケーブル K2, K4, K5a-c, K6b を含む）で \hat f_ρ(A, Q, T) = \hat f_ρ(A, 1/T, 1/Q) が厳密に成立。正値性が破れる結び目でも成立（G 展開が閉じることと同値なので当然）。
2. **既約基底の非負性**：各 (β, f) 行で係数 c_k（k = SU(2)_L の重み）が k の偶奇ごとに |k| について単峰 ⇔ \hat f_ρ = Σ N^{(s)}_{ρ;β,j,f} 𝐚^{2β} χ_j(w) 𝐭^f（χ_j(w) = w^{2j} + w^{2j−2} + … + w^{−2j}）の係数 N^{(s)} = c_{2j} − c_{2j+2} が非負。
   KN の G 展開の前の正値性が成り立つ全ての (結び目, ρ)（トーラス結び目 7 個、代数的なケーブル K1, K3, K6a, K7, K8, K9, K10、4_1、|ρ| ≤ 3）で N^{(s)} の負の項は 0。
   非負性から単峰性は従わないので、これは KN の予想と独立な新しい観察。KN の正値性が破れる非代数的なケーブルでは単峰性も破れる。
3. **[1] の 801 結び目**（yui-kr の HOMFLY-PT ホモロジーを入力）：全てで既約基底が非負。GHM（2103.01212）の sl₂ 作用（Chandler–Gorsky 2209.13058 が各 δ 次数での単峰性として述べる）から従うはずで、文献の正確な主張を S1 で確認する。
   δ の値の数は 705 個が 1、96 個が 2。
4. **特殊化**：\hat f_ρ(a = 1) = 0（全 ρ、自明：unknot_λ(a=1) = 0）。**\hat f_ρ(a = t) = 0（|ρ| ≥ 2 の全 100 件、非代数的なケーブルを含む）**、\hat f_{[1]}(a = t) は 2 項。
   rCS_{[r^N]}(a = t^N) は単項式（T(2,3) の [1],[1,1],[1,1,1],[2],[2,2],[3]、T(3,4)、K1 の長方形 6 件）、rCS_{[2,1]}(a = t²) の項数 = rCS_{[1]}(a = t²) の項数（U(2) の恒等式、open_problems A3 と整合）。
   a = t²（sl(2)）では項数が約 1/4〜1/40 に減る。a = t^{−1}, t^{−2} には目立った縮退は無い。
5. **4_1 の両手型性**：\hat f_{[1,1]}(a, q, t) = \hat f_{[2]}(1/a, 1/q, 1/t) が単項式倍なしで厳密に成立（KN の \hat N_{ρ,g,β,J_r} = \hat N_{ρ^T,g,−β,−J_r} の \hat f での形）。

## 3. アイデア（DGR・GGS の各構造に当たるもの）

| DGR / GGS の構造 | refined LMOV での対応物（案） | 判定法 | 状態 |
|---|---|---|---|
| (iv) 対称性 𝐪 → 1/(𝐪𝐭) | W 不変性 ＝ G 展開が閉じること | 式の上で同値【導出】 | 済（§1） |
| (i) 正値性 | KN：G 基底（種数表示）。新：χ_j(w) 基底（**既約表示**）の非負性 ＝ 各 (β, f) 行の単峰性 | 単峰性の判定、sl₂（hard Lefschetz）との関係 | 観察済（§2.2, 2.3）。[1] は GHM から定理になる見込み |
| (iii) 微分 d_N | 特殊化 a = t^N（SU(N)）。N = 1 で |ρ| ≥ 2 の \hat f_ρ = 0（「彩色 d_1」）、N = 0 で全て 0（d_0 の消去点）、N = 2 で sl(2) の refined LMOV | 項数・消滅・因数分解、\hat{𝐍} = H_N + (1 + 𝐚²𝐪^{−2N}𝐭)Q_N（H_N, Q_N ≥ 0）の分解の存在 | a = 1, t は観察済。N = 2 と分解は未 |
| (v) d_1 で 1 項 | rCS_{[r]}(a = t) が単項式で、r について乗法的（\hat f_ρ(a=t) = 0 の理由） | 単項式の形 m_r = m_1^r を確認、一般の結び目で証明（framing 0 の正規化から） | 未 |
| (v) d_0 で knot Floer | \hat f_ρ の (a − 1) の 1 次の項。1 次では Log が線形になるので、λ ⊢ |ρ| の rCS_λ(a = 1)（refined 彩色 Alexander）の線形結合 | 1 次の項の正値性・構造、t = q で彩色 Alexander（Δ(q^{|λ|})）との比較 | 未 |
| (vi) 彩色微分 d_{λ→μ} | SU(N) の安定化 rCS_λ(a = t^N) = 単項式 × rCS_{λ−(1^N)}(a = t^N)（CD14 の安定化）。LMOV では a = t^N で |ρ| の層が N 以下の層に落ちるか | \hat f_ρ(a = t^N) を、SU(N) の有限個の彩色で作った LMOV と比較 | 未 |
| (vii) ミラー λ ↔ λ^T | rCS では W。\hat f では ρ は W で動かない。ρ ↔ ρ^T は M(t) の hook の構造（B_σ(t)、t 変形した ω）が担う | \hat f_{ρ^T} と \hat f_ρ の関係を、両手型でない結び目で探す（T(2,3) の [2] と [1,1]） | 未 |
| (viii) 指数増大性 | 種数 0 の部分：\hat f_ρ(q = 1)。refined EGP の下で、全ての ρ の種数 0 の \hat N は P（[1]）だけから決まる | 式を導出し、801 結び目で種数 0 の \hat N_{ρ,0,β,J_r}（|ρ| ≤ 3）を計算して正値性を判定。保存済みの彩色データと照合 | 未 |
| (ix) 第 4 の次数 | (β, k, f) に加えて、種数 g またはスピン j_L。LMOV では (ρ, β, j_L, f) または (ρ, β, g, f) | thin な結び目の δ = f − 2β の台と、(β, g) ごとの J_r（KN の偶奇）との関係 | 未 |
| thin / thick | δ の台の幅（P：1 または 2 値、\hat f_{[1]}：+1）。彩色では δ の台の幅と Adams の写しの寄与 | δ の幅の分布、G 展開後の J_r の広がり（二項係数型か） | 未 |

unrefined の LMOV（t = q）については、上の各項目を先に t = q で見る（N_{ρ,g,β} の符号、a = q^N、a → 1、既約基底）。unrefined では各 a 行の HOMFLY-PT の係数に符号が混ざるので既約基底の正値性は成り立たない。refined で 𝐭 が符号を分離することが、正値性の本質であると予想する。

## 4. 計画（段階と成果物）

各段階の成果物は、`src/rcsknots/lmovstruct.py`（辞書・基底変換・特殊化・判定）、`tests/test_lmovstruct.py`（小さな入力の機能テスト）、`data/lmovstruct/`（判定結果）、`logs/lmovstruct_*.log`、docs の更新。

- **S0 道具**：太字の \hat f からの (β, k, f) 行の抽出、既約基底への変換（と逆変換：N^{(s)} → \hat{𝐍} → \hat N の整合）、特殊化 a = t^N q^M、δ、項数、単項式判定。機能テスト：T(2,3) の [1], [2] で手計算と一致、既約基底 → G 基底の往復。
- **S1 [1]**：801 結び目で既約基底の非負性、δ の幅、a = t^N（N = 0, ±1, ±2）の構造、(a − 1) の 1 次の項（t = q で Alexander）。GHM・Chandler–Gorsky の主張を原典で確認し、[1] の既約表示の正値性を「定理（GHM から）」か「計算」かに分類する。
- **S2 彩色**：data/bps/（|ρ| ≤ 3、21 結び目）、data/framed/（framing つき）、data/highbox/（トーラス結び目の 4〜9 箱、再計算が必要なら scripts/highbox_torus.py）で、既約基底の非負性・δ・特殊化。彩色 d_1（\hat f_ρ(a = t) = 0）の証明の試み。
- **S3 種数 0**：refined EGP の下で \hat f_ρ(q = 1) を P から導く式を作り、保存済みデータで照合してから 801 結び目に適用（|ρ| ≤ 3、[1] だけを入力）。種数 0 の正値性の判定。
- **S4 微分の分解**：\hat{𝐍}_ρ = H_N + (1 + 𝐚²𝐪^{−2N}𝐭) Q_N（H_N, Q_N ≥ 0、N = 1, 2）の存在を LP で判定（[1] は DGR の予想の帰結、彩色は新しい）。a = t² の \hat f_ρ と「sl(2) の refined LMOV」（Habiro 型の cyclotomic 展開の refined 版、KNTZ）との関係の確認。
- **S5 ミラーと hook**：\hat f_{ρ^T} と \hat f_ρ の関係（T(2,3), K1）、M(t) の t 変形した ω としての解釈。GGS の彩色微分の点（長方形の文献値）で \hat f_{[2]}, \hat f_{[1,1]} がどう縮退するか。
- **S6 まとめ**：観察を予想の形にし、既知の結果（GHM の sl₂、CD14 の安定化、LMOV の q ↔ 1/q、Habiro・KNTZ）との境界を novelty_report に書く。

停止点：S1 の後（[1] の結果の報告）、S3 の後（種数 0 の結果の報告）。その他は作業の区切りで progress.md を更新する。

## 5. やらないこと・注意

- 非代数的なケーブルの DAHA の値を入力にした正値性の計算は計画に入れない（CLAUDE.md、open_problems D5）。§2 の表に非代数的なケーブルが出るのは、既存の保存値の観察（既約表示の正値性が KN の正値性と同じ場所で破れる）としてだけ。
- 既知との境界：W 不変性 ＝ G 展開の閉じ方（KN）、[1] の sl₂（GHM、Chandler–Gorsky）、SU(N) の安定化（CD14）、彩色 HOMFLY-PT の a = 1（Alexander）、cyclotomic 展開（Habiro、KNTZ）。これらを本研究の成果として書かない。新しいのは、LMOV の側での**既約基底の正値性**、**彩色 d_1（a = t で消える）**、**種数 0 の部分が [1] から決まること**、**a = t^N の分解**の各観察（と、証明できれば導出）。
- 別セッション（ワークツリー rename-literature-survey-doc-9cc5fc）の検証結果は再検証しない。その計画は使わない。
