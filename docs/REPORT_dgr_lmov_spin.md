# refined LMOV 不変量の既約表示・種数表示と DGR 型・四重次数型の構造（報告、2026-10-11）

計画は docs/research_plan_dgr_lmov.md。印は【導出】【計算（範囲）】【予想】【仮説】。
変数は docs/conventions.md §1（KN の小文字 (a, q, t)、太字 (𝐚, 𝐪, 𝐭)）。コードは src/rcsknots/lmovstruct.py、
スクリプトは scripts/lmovstruct_*.py、データは data/lmovstruct/、ログは logs/lmovstruct_*.log、テストは tests/test_lmovstruct.py（機能）と tests/test_lmovstruct_results.py（results）。
別セッション（docs/dgr_lmov/）の結果は再検証していない。重なりは §8 に書く。

**用語**：本プロジェクトでは「spin 表示」は G 展開の前の係数 \hat{𝐍}_{ρ;i,j,k}（重み s = e_𝐪/2 = J_1 − J_2 でラベルされた符号付きの数、docs/paper/notation.md）、「genus 表示」は G 展開の後の係数を指す。
本報告の**既約表示**は、spin 表示の各 (β, f) 行を SU(2)_L の既約表現（指標 χ_j(w)）にまとめ直したもので、spin 表示の重み s が本当に SU(2)_L の表現の重みになっているか（重み空間の次元が単峰か）を問う。
genus 表示は G^g（Jacobian H^*((T²)^g) の SU(2)_L 内容）による別の基底である。

## 0. 要約

1. **辞書【導出】**：w = 𝐪²𝐭 = −(qt)^{1/2} は SU(2)_L の重みの変数、𝐭 = −(q/t)^{1/2} は U(1)_R の電荷の変数で、KN の種数の因子は G = χ_{1/2}(w) − χ_{1/2}(𝐭)。
   DGR の対称性 φ: (e_𝐚, e_𝐪, e_𝐭) ↦ (e_𝐚, −e_𝐪, e_𝐭 − e_𝐪) は SU(2)_L の Weyl 反転 W: (a, q, t) ↦ (a, 1/t, 1/q) に等しく、**KN の G 展開が閉じること ⇔ \hat f_ρ の W 不変性 ⇔ KN の整合条件 f^{\bar t} = M(q^{−1}) \hat f** である。
   DGR の微分 d_N（N ∈ ℤ）の対が恒等的に打ち消す特殊化は、N > 0 で a = t^N、N < 0 で a = q^{N}、N = 0 で a = t/q。より一般に a = t^N q^{−M} は Macdonald の unknot を gl(N|M) の (N|M)-hook に切り詰める点で、GGS の d_{N|M} の点に当たる。
2. **既約表示の正値性【計算】**：\hat f_ρ = Σ N^{(s)}_{ρ;β,j,f} 𝐚^{2β} χ_j(w) 𝐭^f（χ_j は SU(2)_L の指標）の係数は、KN の G 展開の前の正値性が成り立つ全ての (結び目, ρ)（保存済み 452 件 ＋ 801 結び目の [1]）で非負。KN の正値性が破れる 35 件（非代数的なケーブル）では破れる。非負性から単峰性は従わないので、KN の予想と独立な予想。
   [1] は GHM（2103.01212）の sl₂ 作用（Chandler–Gorsky 2209.13058 の言い方で、各 Δ 次数・a 次数の中で 𝐪 次数 mod 4 ごとに単峰）から**定理**になる【導出】。
3. **彩色 d_1【導出 ＋ 計算】**：a = t（gl(1|0)）と a = 1/q（gl(0|1)）で |ρ| ≥ 2 の \hat f_ρ は恒等的に 0。根拠は rCS_{[r]}(a = t) = c^r（c = (t/q)^{δ/2}、22 結び目で確認）と、unknot の LMOV が [1] だけであること。a = 1 では全ての \hat f_ρ が 0。
4. **gl(1|1) の点 a = t/q（DGR の d_0）**：unknot が hook に切り詰まり、\hat f_ρ の項数が 1〜2% に落ちる。三葉結び目の対称な ρ = [2]〜[5] では 0【計算】。
5. **種数 0（q = 1）**：G = 0 なので \hat f_ρ(q = 1) は種数 0 の \hat N だけを含む【導出】。しかし \hat f_ρ の式は q = 1 に 1 位の極をもつので、種数 0 の部分は rCS_λ の q = 1 での値（refined EGP で [1^i] に帰着）だけでは決まらず、q = 1 での 1 次のジェットが要る【計算：2 箱】。計画 S3 の「種数 0 は P だけから決まる」は撤回。

## 1. 辞書【導出】

### 1.1 変数
太字の単項式 𝐚^{2β} 𝐪^{2k} 𝐭^{f+k} = 𝐚^{2β} w^k 𝐭^f（w = 𝐪²𝐭）に (β, k, f) = (a 次数, SU(2)_L の重み, U(1)_R の電荷) を対応させる。KN の 2J_r は f。

| 対象 | 小文字 | 太字 |
|---|---|---|
| G（KN の種数の因子） | (q^{1/2} − q^{−1/2})(t^{−1/2} − t^{1/2}) | w + w^{−1} − 𝐭 − 𝐭^{−1} = χ_{1/2}(w) − χ_{1/2}(𝐭) |
| W（SU(2)_L の Weyl 反転） | (a, q, t) ↦ (a, 1/t, 1/q) | (𝐚, w, 𝐭) ↦ (𝐚, 1/w, 𝐭)、すなわち DGR の φ |
| q = 1 | — | w = 𝐭^{−1}（G = 0） |
| t = 1 | — | 𝐪 = ±1（G = 0） |
| t = q（unrefined） | G = −z², q/t = 1 | 𝐭 = −1 の側ではなく、w = 𝐭^{−1}·𝐪⁴… の 1 変数への制限 |

（W の導出：a = −𝐚²𝐭 を固定し、q^{1/2} = −𝐪𝐭 ↦ t^{−1/2} = 1/𝐪、t^{1/2} = 𝐪 ↦ q^{−1/2} = −1/(𝐪𝐭) を解くと 𝐭' = 𝐭、𝐪' = −1/(𝐪𝐭)、w' = 1/w。）

### 1.2 G 展開が閉じる ⇔ W 不変 ⇔ KN の整合条件
KN の形 \hat f_ρ = Σ (−1)^{2J_r} \hat N (q^{1/2}−q^{−1/2})^g (t^{−1/2}−t^{1/2})^g (q/t)^{J_r−β/2} a^β は W で項ごとに不変（2 つの因子が入れ替わり、q/t と a は不変）。逆に W 不変なら各 (β, f) 行が w ↔ 1/w 対称で、G 展開（rcsknots.bps.g_expand の閉じる条件と同じ）が閉じる。
さらに (refined-GT1) と (refined-GT2) は互いに W の像である：KN の unreduced のミラー対称性 g_λ \bar{rCS}_λ(a,q,t) = (−1)^{|λ|} \bar{rCS}_{λ^T}(a,1/t,1/q) と P_λ(x; 1/t, 1/q) = P_λ(x; t, q)、g_λ(1/t,1/q) = (q/t)^{|λ|} g_λ(t,q)、g_{λ^T}(q,t) g_λ(t,q) = 1 から、GT1 に W を施すと GT2 の x → (q/t)x になる。よって f^{\bar t}_μ = (t/q)^{|μ|} W(f^q_μ)（KN の f^q の尺度 (t/q)^{|μ|/2} を除く）。
f^q = M(t)\hat f、f^{\bar t} = M(q^{−1})\hat f、W(M(t)) = M(1/q) なので、KN の整合条件 f^{\bar t} = M(q^{−1})\hat f は \hat f = W(\hat f)（単項式倍を除く）と同値。
【計算】保存済み 452 件（data/bps/ の 112 件、data/highbox/ の 340 件）と K7〜K9 の 3 箱で \hat f_ρ(A,Q,T) = \hat f_ρ(A, 1/T, 1/Q) が単項式倍なしで厳密に成立（正値性が破れる非代数的なケーブルでも成立）。

### 1.3 特殊化の点（微分の対応物）
DGR の d_N の次数（superpolynomial.tex:898-905）：N > 0 で (−2, 2N, −1)、d_0 は (−2, 0, −3)、N < 0 で (−2, 2N, −1+2N)。対 x, d_N x が 𝐚² = c 𝐪^m 𝐭^n で恒等的に打ち消す条件を解くと c = −1 で

| 微分 | (m, n) | 小文字の点 | Macdonald の unknot の切り詰め（unknot_λ = 0 ⇔） |
|---|---|---|---|
| d_N（N > 0） | (2N, −1) | a = t^N | (N+1, 1) ∈ λ、すなわち ℓ(λ) ≤ N が残る：SU(N) |
| d_{−N}（N > 0） | (−2N, −1−2N) | a = q^{−N} | (1, N+1) ∈ λ、すなわち λ_1 ≤ N が残る：転置した SU(N)（W の像） |
| d_0 | (0, −3) | a = t/q | (2, 2) ∈ λ、すなわち hook だけが残る：gl(1|1) |
| （(1 + 𝐚²𝐭) の零点） | (0, −1) | a = 1 | (1, 1) ∈ λ、すなわち全て消える |
| GGS の d_{N|M} | (2(N−M), −2M−1) | a = t^N q^{−M} | (N+1, M+1) ∈ λ、すなわち (N|M)-hook が残る：gl(N|M) |

切り詰めの根拠：unknot_λ(a) = (t/a)^{|λ|/2} Π_{s=(i,j)} (t^{i−1} − a q^{j−1})/(1 − q^{a(s)} t^{l(s)+1})（conventions.md §2）で、a = t^N q^{−M} のとき t^{i−1} = t^N q^{j−1−M} ⇔ (i, j) = (N+1, M+1)。
【計算：|λ| ≤ 5、N, M ≤ 2 で零の条件が一致】。したがって a = t^N q^{−M} での KN の生成関数は gl(N|M) の refined CS（(N|M)-hook の彩色だけ）になる。
GGS の d_{N|M} の点 a = t^N q^{−M}（u_{N|M} = 𝐚²𝐪^{−2(N−M)}𝐭^{2M+1} = −1）が gl(N|M) の切り詰めに一致するのは、超群の表現が (N|M)-hook で添字づけられることの Macdonald 版である。

## 2. 既約表示

### 2.1 定義
各 (β, f) 行 \hat f_{β,f}(w) = Σ_k c_k w^k は W 不変性から w ↔ 1/w 対称なので、SU(2)_L の指標 χ_j(w) = w^{2j} + w^{2j−2} + … + w^{−2j} で一意に展開できる：
  \hat f_ρ = Σ_{β, j, f} N^{(s)}_{ρ;β,j,f} 𝐚^{2β} χ_j(w) 𝐭^f、 N^{(s)}_{ρ;β,j,f} = c_{2j} − c_{2j+2}。
整数性は自動。非負 ⇔ 各行が k の偶奇ごとに |k| について単峰。KN の種数表示 Σ \hat N G^g 𝐭^F 𝐚^{2β} とは G^g = Σ_i C(g,i)(−1)^{g−i} χ_{1/2}(w)^i χ_{1/2}(𝐭)^{g−i} で結ばれ、符号が混ざるので一方の非負性は他方を含意しない（例：G 自身は種数表示では非負だが既約表示では χ_0 𝐭^{±1} の係数が −1。逆の例は tests/test_lmovstruct.py::test_spin_nonneg_is_not_implied_by_nonneg）。
最大種数 g_max(β) の項は最大スピン j = g_max/2 の項に一対一に対応し、N^{(s)}_{β, g_max/2, F} = \hat N_{g_max, β, F}【導出：G^g の χ_{1/2}(w)^g の係数は +1】。

### 2.3 [1] は定理【導出】
GHM 2103.01212 の Cor. (sl2 intro)（Lefshetz_revision_upd.tex:295-298）は y 化したホモロジー上の sl₂ 作用を与え、Chandler–Gorsky 2209.13058（main.tex:198）はその帰結として HHH(K) が Δ 次数と a 次数を保つ sl₂ 作用をもち、各 Δ 次数で q 次数 mod 4 ごとに対称かつ単峰であると述べる。
本研究の行 (β, f) は (a 次数, Δ 次数) の組に当たり（Δ は e_𝐭 − e_𝐪/2 の形の一次結合）、k の偶奇は q 次数 mod 4 に当たる。
よって P の各行は対称で単峰、すなわち P の既約表示は非負。\hat f_{[1]} = (1 + 𝐚^{−2}𝐭^{−1}) P の因子は行 (β, f) を (β−1, f−1) に写すだけで行の中を混ぜないので、\hat f_{[1]} の既約表示も非負。
（Δ 次数の正確な定義と y 化前のホモロジーへの帰着は原典の該当箇所を引用して論文に書く。801 結び目での計算はこの帰結の確認。）

### 2.4 予想
**予想 S（既約表示の正値性）**：KN の正値性予想が成り立つ結び目・彩色では、N^{(s)}_{ρ;β,j,f} ≥ 0。
これは「refined LMOV 不変量を SU(2)_L × U(1)_R の指標として読んだとき、各 (β, J_r) の SU(2)_L 表現が真の表現である」という物理的に自然な主張で、KN の種数表示の正値性（Jacobian の Lefschetz 型の基底での非負性）とは独立。両方が成り立つことは、\hat f_ρ の各 a 行が「G^g の非負結合」かつ「χ_j の非負結合」であることを意味し、それを同時に説明する構造（例：Jacobian ファイブレーションの sl₂ と底空間の重み）は未解明。

## 3. 特殊化と微分

### 3.1 彩色 d_1【導出】
命題 D1：rCS_{[r]}(K; a = t) = c^r（r ≥ 1、c は q, t の単項式）なら、\hat f_ρ(K; a = t) = 0（|ρ| ≥ 2）かつ \hat f_{[1]}(K; a = t) = c · \hat f_{[1]}(unknot; a = t)。
証明：a = t で unknot_λ(a = t) は ℓ(λ) ≥ 2 で 0、λ = [r] で 1（§1.3 の切り詰めと、分子・分母の集合 {t q^{j−1}} と {q^{r−j} t} の一致）。
よって Z_K(a = t; x) = 1 + Σ_r g_{[r]} c^r P_{[r]}(x) = Z_unknot(a = t; c x)（unknot の unreduced 値は unknot_λ そのもの）。c が単項式なので Adams 作用と可換で、plethystic log も x → cx で移る。
unknot の f^q_μ は |μ| ≥ 2 で 0（Cauchy の恒等式により Z_unknot は次数 1 の項の plethystic exponential）。M(t) は可逆なので \hat f_ρ(K; a = t) = c^{|ρ|} \hat f_ρ(unknot; a = t) = 0。∎
逆に \hat f_ρ(K; a=t) = 0（全ての |ρ| ≥ 2）なら Z_K(a=t) は次数 1 の項の plethystic exponential で、c_1 = rCS_[1](a=t) が単項式なら c_r = c_1^r が従う。
【計算】rCS_{[r]}(a = t) = c^r は保存済みの全 22 結び目（トーラス結び目 9、ケーブル 13、r ≤ 3）で成立し、c = (t/q)^{δ/2}（δ は conventions.md §13 の種数型の量。T(2,3) で (t/q)^{1/2}、K1 で (t/q)^4）。
δ の意味：c は (N1)(N2') の正規化で決まり、正規化前の値の a = t での振る舞いが M_□ の a^δ と打ち消す。
【計算】\hat f_ρ(a = t) = 0 は |ρ| ≥ 2 の全件（data/bps 100 件、highbox 340 件、K7〜K9 の 3 箱）で成立。非代数的なケーブル（DAHA の値）でも成立する（切り詰めは入力の正値性と無関係）。

### 3.2 W の像：a = q^{−1}【導出】
\hat f_ρ は W 不変なので、\hat f_ρ(a = q^{−1}; q, t) = \hat f_ρ(a = t; 1/t, 1/q) = 0（|ρ| ≥ 2）。gl(0|1) の点。【計算：全件で 0】
一般に a = q^{−N} での値は a = t^N での値の W の像で、転置した理論の SU(N) に当たる。

### 3.3 d_0 の点 a = t/q（gl(1|1)）【計算】
\hat f_ρ(a = t/q) は 0 ではないが項数が大きく減る（data/lmovstruct/loci.json：T(2,5) の [2] で 112 → 16、T(3,4) の [2] で 429 → 34、K1 の [2] で 4141 → 135、T(4,5) の 5 箱で約 0.4%）。
三葉結び目では ρ = [2], [3]（|ρ| ≤ 3）と ρ = [4], [5]（highbox）で 0、非対称な ρ では 0 でない。
意味：a = t/q では hook の彩色だけが残り、KN の M(t)（hook の指標 B_σ）がちょうどこの構造を担う。t = q では a = 1（Alexander、gl(1|1)）に当たる。三葉結び目の対称な ρ で消える理由は未解明。

### 3.4 その他の点【計算：T(2,3), T(2,5), T(3,4), 4_1, K1 の |ρ| ≤ 3、𝐚² = ±𝐪^m𝐭^n、|m|, |n| ≤ 8】
- |ρ| ≥ 2 で \hat f_ρ が 0 になる点は a = 1, t, 1/q の 3 点だけ（三葉結び目の対称な ρ では a = t/q も）。
- 次に縮退が強いのは a = t/q、a = t²（SU(2)）、a = qt（gl(1|−1) 型、W の像は a = 1/(qt)）、a = −t（𝐚² = +𝐪²𝐭^{−1}）で、順序は結び目による（T(2,5) では a = qt が a = t² より縮退し、T(3,4) と K1 では逆）。
- 4_1 では a = t² と a = qt に目立った縮退は無い（両手型の結び目で a ↔ 1/a の対称性が効く）。

## 4. 種数 0（q = 1）の部分【導出 ＋ 計算】
G は q = 1 と t = 1 で 0 なので、\hat f_ρ(q = 1) = Σ_{β, J_r} \hat N_{ρ,0,β,J_r} (−1)^{2J_r} t^{−J_r+β/2} a^β は種数 0 の \hat N だけを含む（t = 1 も同様で、W で移り合う）。
refined EGP（rCS_λ(q=1) = Π rCS_{ω_i}^{λ_i − λ_{i+1}}）により、q = 1 での rCS_λ は [1^i] の q = 1 での値で決まるが、
\hat f_[2], \hat f_[1,1] の記号式（rcsknots.bps.f_formulas）は Q = 1 に 1 位の極をもつ（分母 2T(Q−1)(Q+1)(Q²+1)(QT−1)(QT+1)）。
したがって \hat f_ρ(q = 1) には rCS_λ の q = 1 での 1 次のジェット（∂_q rCS_λ|_{q=1}）が要り、q = 1 での値だけでは決まらない。
q = 1 での値だけを代入して作った式は保存値（T(2,3), T(3,4), K1, K5c）と一致しなかった（一般の q では記号式が保存値を再現し、EGP も成立するので、原因は極）。
残る問い：q = 1 での 1 次のジェットに EGP 型の規則（t = q での特殊多項式の展開の refined 版）があるか。

## 5. δ 次数と thin【計算】
δ := f − 2β（= e_𝐭 − e_𝐪/2 − e_𝐚）。801 結び目の P では δ の値の数は 1 が 705 個、2 が 96 個（Chandler–Gorsky の Δ 次数の分布と同じ）。\hat f_{[1]} は δ ∈ {δ(P)} ∪ {δ(P) + 1}。
彩色では δ の幅は箱数とともに広がる（T(4,5) の 5 箱で [−28, 134]）。G = χ_{1/2}(w) − χ_{1/2}(𝐭) の 𝐭 の項が δ を ±1 ずらすので、種数表示の J_r の広がりは二項係数型になる（KN の 2J_r の偶奇の一様性はこの構造の mod 2）。

## 6. unrefined との比較
t = q では N_{ρ,g,β} = (−1)^g Σ_{J_r} (−1)^{2J_r} \hat N（KN）。unrefined の LMOV の q → 1/q 反対称性は W の制限。
unrefined では既約表示（z² = χ_{1/2}(q^{1/2}) − 2 の代わりに χ_j）の正値性は成り立たない（HOMFLY-PT の各 a 行の係数に符号が混ざる）。𝐭 が符号を分離することが refined の正値性の本質で、既約表示の正値性はその SU(2)_L 版。

## 7. 既知との境界（暫定、novelty_report.md に転記）
- 既知：DGR の対称性と微分の次数（DGR）、[1] の sl₂（GHM、CG の単峰性）、unknot の LMOV が [1] だけ（KN）、SU(N) の安定化（CD14）、GGS の d_{N|M}、Macdonald の主特殊化の積公式。
