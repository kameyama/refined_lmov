## 0. 要約

目的は、KN（1703.05408）の結果を超えて、箱が 3 個の refined LMOV 不変量（\hat{𝐍}_ρ と \hat N_{ρ,g,β,J_r}、|ρ| = 3）の正整数性を検証すること。
\hat f_ρ（|ρ| = 3）は |λ| ≤ 3 の全ての rCS_λ を使い、特に非長方形の [2,1] が要る。

1. **[2,1] を定義どおりに得られるのは、トーラス結び目と iterated torus 結び目だけ（文献調査、§4）。**
   非トーラス結び目では、条件から推定した 4_1 の候補（KN、AMMM 1211.6375）しかない。Cherednik 2607.25666 の双曲結び目は列型の彩色に限られ、[2,1] は範囲外。
2. **トーラス結び目 5 個と代数的なケーブル 1 個で、3 箱を含む |ρ| ≤ 3 の全 6 つの ρ について、\hat f が G 展開の前後とも非負【計算】（§3）。**
   KN の表に無いもの：T(3,4) の 3 箱、T(3,5), T(2,11), T(3,7), T(4,5)、K9 = T(2,7) の (2,31)-ケーブル。
   第 1 期の K1, K3, K6a と合わせ、代数的な iterated torus 結び目 4 個とトーラス結び目 5 個で 3 箱の正値性が成り立つ。
3. **非トーラス結び目の [2,1] は、構造的な条件だけでは決まらない【計算】（§2）。**
   t = q での [2,1] 彩色 HOMFLY-PT、ミラー対称性、EGP、U(2) への簡約、3 箱の \hat f の Laurent 性、G 展開、正値性まで課しても、三葉結び目で正解以外の解が多数ある（6 回の試行で 6 個、正解との差の階数 6）。
   したがって、条件で決めた [2,1] による 3 箱の判定は「正の候補が存在する」以上を言えない。
4. 付随する結果
   - [2,1] の新しい恒等式：**a = t² で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}**（U(2) への簡約）。T(2,3), T(2,5), T(2,7), 4_1 で厳密に成立【仮説】。
   - |λ| = 3 の彩色 HOMFLY-PT を 3 本ケーブルのブレイドから求める方法【計算で検証】（§1）。

## 1. 方法と検証

### 1.1 3 箱のパイプライン（U0）
- 第 1 期の \hat f の厳密計算（`hat_f_exact`, `reformulated_exact`）で、KN の T(2,3) と 4_1 の 3 箱の表 6 個を全項再現【計算】。
- \hat f_ρ（|ρ| = 3）は C_{[2,1]} について一次で、係数は α_ρ =（単項式）·(T² − 1)/((Q² − 1)(Q⁴T² − 1))（記号計算）。

### 1.2 |λ| = 3 の彩色 HOMFLY-PT（U2）
- 結び目の (3, s)-ケーブル（s = 1, 2, 4）の HOMFLY-PT をブレイドから Sage で計算し（`scripts/cable_homfly.sage`）、ケーブル公式（p₃ = s₃ − s₂₁ + s₁₁₁）を逆に解いて [3], [2,1], [1,1,1] を同時に求める（`scripts/colored_from_cables.py` の `colored_p`）。
- 三葉結び目と 4_1 で、KN の rCS の t = q 極限と単項式倍も含めて完全一致【計算】。76 交点のケーブルでも 1 秒未満。

### 1.3 [2,1] の構造的な性質（正解での確認）
T(2,3), T(2,5), T(2,7), 4_1 の rCS_{[2,1]}（KN のノートブック）で、次が厳密に成り立つ【計算】（`tests/test_phase3.py`）。
- ミラー対称性 rCS_{[2,1]}(a,q,t) = rCS_{[2,1]}(a,t⁻¹,q⁻¹)
- refined 指数増大性：q = 1 で rCS_{[1]}·rCS_{[1,1]}、t = 1 で rCS_{[1]}·rCS_{[2]}
- **U(2) への簡約【仮説】**：a = t² で rCS_{[2,1]} = rCS_{[1]}·rCS_{[1,1]}。このとき rCS_{[1,1]} は単項式（U(2) では [2,1] ≅ [1] ⊗ det）。[1,1,1] も a = t³ で単項式。
- 4_1 の両手型性 rCS_{[2,1]}(1/A, 1/Q, 1/T) = rCS_{[2,1]}

## 2. 非トーラス結び目の [2,1] を条件から決める試み（U3）

- 整数計画（`scripts/u3_21.py`, `scripts/u3_calibrate.py`）：未知数は rCS_{[2,1]} の係数（符号は自由）。§1.3 の条件、t = q での [2,1] 彩色 HOMFLY-PT、3 箱の \hat f の Laurent 性（分母は α と unk_{21} から）、G 展開、正値性を全て一次の条件として課す。
- 較正（三葉結び目、正解は楕円 Hall 代数で既知）【計算】（`logs/u3_calibrate_3_1.log`）

| 条件 | 解（|x| ≤ 20、乱数の目的関数 6 回） |
|---|---|
| U(2) なし、正値性なし | 6 個の異なる解、正解と一致 0、差の階数 6 |
| U(2) あり、正値性なし | 6 個、一致 0、差の階数 6 |
| U(2) あり、正値性あり | 6 個、一致 0、差の階数 6 |

- 解析的な見通し：解の差 δ は、t = q、q = ±1、t = ±1、a = ±t² で消え、ミラー対称で、3 箱の \hat f を Laurent に保つ必要がある。これらは δ に因子を課すだけで、因子を掛けた対称な多項式の自由度が残る【導出（見通し）】。
- 結論：条件だけでは [2,1] は一意に決まらず、正値性を満たす候補が多数ある。KN の 4_1 の [2,1]（と AMMM の候補）も、同じ意味で一意ではないと考えられる。
- 実装上の注意：D を大きくとると係数が 2×10⁵ になり HiGHS が不安定になる。乱数の目的関数では解の集合が非有界になる（解が一意でないことの別の表れ）。

## 4. 文献調査（U1、docs/literature/phase3_21_survey.md）

- トーラス・iterated torus 以外で、[2,1] を含む全彩色の refined 量が定義に基づいてそろう結び目は見つからなかった。
- 非トーラスの [2,1] superpolynomial は 4_1 の候補（AMMM 1211.6375）だけで、条件からの推定（原典も曖昧さを認める）。
- Cherednik 2607.25666：Coxeter 結び目（K12n242 など）の superpolynomial を DAHA で定義・計算。彩色は列型 [1^m] のみで [2,1] は範囲外。
- ツイスト結び目・3 本ブレイドの結び目の [2,1] 彩色 HOMFLY-PT（非 refined）は文献にある（Morozov ら）。本研究の 3 本ケーブルの方法で独立に計算できる。
