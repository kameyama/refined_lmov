## 2026-10-11 H1：(S_{1|0}), (S_{0|1}) の導出（ユーザーの指示「H1 の導出から進めて」）

**やったこと**：GN の構成で a = t（a = q⁻¹）の評価を 1 変数への評価として扱い、核と商の構造を調べた。検査は scripts/dgr_h1_lemma.py（有理数で厳密、logs/dgr_h1_lemma.log）、テストは 3 件を追加して計 18 件・7 秒。

**結果**（docs/dgr_lmov/report.md の D3 / H1）
- 【導出】GN/CD の構成の全ての結び目（トーラス結び目と iterated torus 結び目）で、rCS_{[r]}|_{a=t} = c^r T_{[r]}^F、rCS_{[1^r]}|_{a=q^{-1}} = c'^r T_{[1^r]}^F。F は (N2') の F と一致する。
- 証明の要点：
  - 核は H̃ 基底の部分集合が張る（行／列以外）。
  - 核は環準同型の核なのでイデアルで、∇ は対角。交換関係 [P_y, P_z] = κP_{y+z} により、EHA の上半分が核を保つ。
  - 商は各次数 1 次元で、作用は量子トーラス。
  - 代入の結果、二次の部分はちょうど framing の固有値になる。
- これで、|ρ| ≥ 2 の \hat f_ρ が D で割り切れることは、これらの結び目について導出された。
- 【計算】補題を全ての検査で確認：核の形、量子トーラスの閉じた形（9 個の傾き、k = 1, 2）、トーラス結び目 4 個とケーブル 4 個の最終式（r ≤ 3）。

**次にやること**：H2（hook 性質）は、核と核を保つことまで導出済み。hook の商での作用の決定が残る。

**未解決**：非原始的な元（n ≥ 2, k ≥ 2）の像の導出（計算で確認済み）。H̃_μ[1−u] の公式の原典の確認。

## 2026-10-11 DGR 型の構造（d_{n|m} の類似）を spin・genus 表示で（ユーザーの指示「DGR や quadruply graded homology のような考え方を refined LMOV invariant の spin 表示や genus 表示でできるか研究せよ」）

**やったこと**

- コード `src/rcsknots/dgr.py`、一括実行 `scripts/dgr_lmov_survey.py`（206 秒、logs/dgr_lmov.log、data/dgr_lmov/summary.json）、テスト `tests/test_dgr_lmov.py`（13 件、10 秒）。
- 文献調査（サブエージェント）：a = 1 の零点は既知（LM、Zhu 2105.02037 Thm 1.8）、a = q^{±1}・refined の a = t, q⁻¹・商の正値性は文献に見当たらない。

**結果**（詳細と範囲は docs/dgr_lmov/report.md）
1. framing 0 で |ρ| ≥ 2 の \hat f_ρ は D = (1+𝐚²𝐭)(1+𝐚²𝐪⁻²𝐭)(1+𝐚²𝐪²𝐭³)（d_{0|0}, d_{1|0}, d_{0|1}）で割り切れる【計算：全データ】。行・列の特殊化の性質 (S_{1|0}), (S_{0|1}) から【導出】。
2. 商 R_ρ = \hat f_ρ/D は spin・genus 表示とも非負【計算：トーラス 7、代数的ケーブル 6、4_1、ツイスト |p| ≤ 10、thick 3】。D は両表示で非負なので KN の正値性を含む。genus 表示で D = (1+𝐚²𝐭)[(1+𝐚²𝐭)(1+𝐚²𝐭³) + 𝐚²𝐭²G]【導出】。
3. framing x：\hat f^{(x)}(K) ≡ c^{|ρ|}\hat f^{(x)}(○) mod d_{±1}【導出＋計算】。Σ ≠ 0 では σ 不変な持ち上げ 𝐭^{−2Σ} の商に負が出る（同じ構造が成り立たない例）。
4. d_{1|1}（a = t/q）：hook λ で rCS_λ|_{d11} = c·A_K(𝐪^{|λ|}𝐭^{arm}, 𝐭)【計算】。genus 表示で d_{1|1} 後の最大 genus が |ρ|g − c_ρ（g ≥ 2、K5c のみ例外）【計算】。
5. genus 表示は σ の商なので、微分は σ 軌道 {d_{n|m}, d_{m|n}} ごとに genus を |n−m| 上げる正の演算子として現れる【導出＋計算（n,m ≤ 3）】。
6. δ 次数は移らない。非 refined では \hat f_R が (1−a)²(1−aq)(1−aq⁻¹) で割り切れる（d_{0|0} と d_{1|1} が重なる）【計算】。
