## 0. 出発点：何を「DGR 型の構造」と呼ぶか

DGR（math/0505662）と GGS（1304.3481）の構造は、次の 4 つに分けられる。

1. 微分 d_{n|m}（GGS §3.4）
   - 次数は (a,q,t_c) = (−2, 2(n−m), −2m−1)。
   - Poincaré 多項式では、対になった生成元が因子 1 + u_{n|m}、u_{n|m} = 𝐚²𝐪^{−2(n−m)}𝐭^{2m+1} として現れる。
   - KN の小文字では、u_{n|m} = −1 ⇔ a = t^n q^{−m}（U(n|m) への特殊化）。
   - DGR の d_N は d_{N|0}、d_{−N} は d_{0|N}、d_0 は d_{1|1}（HFK）に当たる。
2. 対称性 σ：(e_𝐚,e_𝐪,e_𝐭) ↦ (e_𝐚,−e_𝐪,e_𝐭−e_𝐪)。小文字では (a, q, t) ↦ (a, 1/t, 1/q)、SU(2)_L の Weyl 反転（§11）。
   - σ(u_{n|m}) = u_{m|n} で、d_{n|m} と d_{m|n} を入れ替える【導出】。
   - \hat f_ρ が σ 不変であること ⇔ G 展開が閉じること ⇔ KN の整合条件 f^{\bar t} = M(q^{−1})\hat f【導出、§11.2】。
3. 色付き微分（GS 1112.0030、GGS §3.5）：色付きの d_{±1} のホモロジーは 1 次元で、次数は |λ| に比例する。
4. δ 次数（thin な結び目では台が一つの平面にのる）、t_r と t_c の 2 つの t 次数。

refined LMOV 不変量 \hat f_ρ は、色付き不変量の plethystic log と M(t)^{-1} から作られ、ホモロジーではない。そこで上の 4 つが \hat f_ρ のどの性質に「翻訳」されるかを、データから一つずつ調べた。

## 1. 結果の要約

一言で言えば、genus 表示に乗るのは σ の軌道ごとの微分だけで、軌道 {d_{n|m}, d_{m|n}} は genus を |n−m| だけ動かす。
DGR の「d_{±1} は 1 次元のホモロジーを残す」は、|ρ| ≥ 2 の BPS のスペクトルでは「完全に非輪状で、商が正」という、より強い形になる。

## 2. 普遍な因子 D（spin 表示）

**観察【計算】**：framing 0 で \|ρ\| ≥ 2 の全ての \hat f_ρ が
D = (1 + 𝐚²𝐭)(1 + 𝐚²𝐪⁻²𝐭)(1 + 𝐚²𝐪²𝐭³) = (1+u_{0|0})(1+u_{1|0})(1+u_{0|1})
で割り切れる。小文字では (1 − a⁻¹)(1 − t a⁻¹)(1 − q⁻¹a⁻¹) で、a = 1, t, q⁻¹ に零点がある。
- [1] は (1+u_{0|0}) だけで割り切れる（\hat f_{[1]} = (a^{1/2} − a^{−1/2}) rCS_{[1]} そのもの）。
- 他の d_{n|m}（(1|1), (2|0), (0|2)）は、一般には因子にならない。三葉結び目の [2], [3] の (1+𝐚²𝐭³) = (1+u_{1|1}) は結び目に固有のもの。

範囲（全て全係数の厳密な割り算）：
- 3 箱：トーラス結び目 T(2,3), T(2,5), T(2,11), T(3,4), T(3,5), T(3,7), T(4,5)、4_1（[2,1] は KN の候補）、代数的なケーブル K1, K3, K6a, K7, K8, K9、非代数的なケーブル K2, K4, K5a, K5b, K5c, K6b の |ρ| ≤ 3 の全て。
- 2 箱：ツイスト結び目 K_p（|p| ≤ 10、GNSSS の予想式）、10_124, 10_139, 10_152（10_139, 10_152 は quiver と KRSS の予想式）。
- 4〜9 箱：トーラス結び目 8 個の 340 件（D1）。K7〜K9 の 3 箱（.xz）。a = t, q⁻¹ での消滅は合計 452 件 ＋ 11 件で確認（§13.1）。

**導出【導出（仮定 S_{1|0}, S_{0|1} のもとで）】**：
- 自明な結び目の unreduced 因子 Π_{□∈λ}(t^{l'} − a q^{a'}) は、次の λ で 0 になる。
  - a = 1：全ての λ ≠ ∅。
  - a = t：ℓ(λ) ≥ 2。
  - a = q⁻¹：λ₁ ≥ 2。
- したがって a = t の生成関数 Σ \bar{rCS}_λ g_λ P_λ には、行 [r] だけが残る。
- 次の性質を仮定する。
  - (S_{1|0})：rCS_{[r]}(K)|_{a=t} = c^r
  - (S_{0|1})：rCS_{[1^r]}(K)|_{a=q^{-1}} = c^r
- このとき、a = t の生成関数は自明な結び目のもので x ↦ c x としたものになる。
- 自明な結び目の f^q_μ は μ ≠ [1] で 0 なので（KN :854-855）、\|μ\| ≥ 2 で f^q_μ(K)|_{a=t} = 0。
- M(t) は可逆なので \hat f_ρ(K)|_{a=t} = 0。a = q⁻¹ は f^{\bar t} の側で同様。a = 1 は Z = 1 から自明。

(S_{1|0}), (S_{0|1}) について：
- これは「色付きの d_{±1} のホモロジーは 1 次元で、次数は r に比例する」（GS 1112.0030 予想 4.2・式 (4.4)、GGS §3.5）の Euler 標数版である。
- DAHA の側では Cherednik 2410.14703 §6.3 の「a = −t（A_0）で自明」に当たる。§6.3 の内容はサブエージェントが原典で確認したもので、私は未確認。
- 本研究のデータでは、因子の存在そのものが (S_{1|0}), (S_{0|1}) の |ρ| ≤ 3 での確認になっている。c の閉じた形は c = (t/q)^{δ/2}（§13.1）。GN/CD の構成の結び目では D3 / H1 で導出した。

## 3. 商 R_ρ の正値性（spin 表示と genus 表示）

R_ρ = \hat f_ρ / D（[1] では \hat f_{[1]}/(1+𝐚²𝐭) = rCS_{[1]}）とおく。R_ρ は σ 不変で、genus 展開が閉じる。

**D の genus 表示【導出】**：
- 𝐚²𝐪⁻²𝐭 + 𝐚²𝐪²𝐭³ = 𝐚²𝐭²(w + w⁻¹)（w = 𝐪²𝐭）、G = w + w⁻¹ − 𝐭 − 𝐭⁻¹。
- これから D = (1+𝐚²𝐭)[(1+𝐚²𝐭)(1+𝐚²𝐭³) + 𝐚²𝐭² G] となる。
- D の係数は spin 表示でも genus 表示でも非負なので、R_ρ が非負なら \hat𝐍 と \hat N も非負になる。

**観察【計算】**：R_ρ は spin 表示・genus 表示とも、負の項が 0（全体の符号を一つ選べば、両表示で同じ符号）。対象は次のとおり。
- トーラス結び目 7 個、4_1、代数的なケーブル 6 個の |ρ| ≤ 3（例：K7 の [3] は spin 270929 項、genus 254518 項）。
- ツイスト結び目 |p| ≤ 10 と 10_124, 10_139, 10_152 の 2 箱。

非代数的なケーブル K2, K4, K5a, K5b, K6b は、元の \hat f と同じく、R_ρ にも両表示で負の項がある。K5c は spin 表示では全ての ρ で負の項があり、genus 表示では [1], [2], [1,1], [1,1,1] で正、[3] と [2,1] で負が 3〜4 個である。DAHA の値がホモロジーではないという既知の事情（open_problems D5）に当たる。

**解釈【予想】**：|ρ| ≥ 2 の refined BPS のスペクトルは、外積代数 Λ(d_{0|0}, d_{1|0}, d_{0|1}) 上の自由加群で、その生成元を数えるのが R_ρ だ、と読める。
- DGR では、[1] の d_{±1} は 1 次元のホモロジーを残す。
- |ρ| ≥ 2 の BPS のスペクトルは完全に非輪状で、そのうえ商が正（単に (1+u) で割り切れるより強い）。
- genus 表示では d_{1|0} と d_{0|1} は区別できず、genus を 1 上げる 𝐚²𝐭²G の項として一緒に現れる。

## 4. framing と「d_{±1} のホモロジー ≅ 自明な結び目」

**観察と導出**：framing x ≠ 0 では、framing 付きの自明な結び目の \hat f^{(x)}_ρ が 0 でない ρ で、因子 1+u_{1|0}, 1+u_{0|1} が消える。代わりに次が成り立つ。

  \hat f^{(x)}_ρ(K) ≡ c_K^{|ρ|} \hat f^{(x)}_ρ(○)   mod (1+u_{1|0}) と mod (1+u_{0|1})

- c_K = rCS_{[1]}(K)|_{d_{1|0}} = rCS_{[1]}(K)|_{d_{0|1}} = (−𝐭)^{−Σ}、Σ は S 不変量の半分。GS の残る生成元 (Σ,−Σ,0), (Σ,Σ,Σ) の像で、σ で写り合う。
- 【導出】§2 と同じ議論で、framing の単項式を [r] と [1^r] に掛けたもの。
- 【計算】ツイスト結び目 |p| ≤ 8、x ∈ [−6, 6]、[2], [1,1] の全てで、両辺が一致した。
- framing −1 の自明な結び目の \hat f_{[2]} は −(1+𝐚²𝐭)×単項式で、[1] の自明な結び目の状態がちょうど一つある【計算】。

**同じ構造が成り立たない点【計算】**：
- 分解 \hat f^{(x)}(K) = 𝐭^{−2Σ}\hat f^{(x)}(○) + D·R^{(x)} で、商 R^{(x)} の正値性を調べた。
  - Σ = 0（p < 0 のツイスト結び目）：|x| ≤ 6 の全てで R^{(x)} は両表示で正。
  - Σ = 1（p > 0、1 ≤ p ≤ 8）：x ≠ 0 の全てで、[2] か [1,1] の少なくとも一方に負の項がある（例：三葉結び目の [2] は x = 2 で 1 個、x = −6 で 12 個）。
- 原因は、d_{1|0} と d_{0|1} で残る生成元の次数が違う（σ で写り合う 2 つの単項式）ことにある。σ 不変な単項式で同時に持ち上げられるのは 𝐭^{−2Σ} だけで、これは正値性と両立しない。
- DGR では各微分が自分のホモロジーを残すので問題にならないが、σ で商をとった BPS の言葉では、一つの「自明な結び目の部分」を選べない。

## 5. d_{1|1}（HFK 型、a = t/q）：hook 型の性質と genus の検出

**観察【計算】**：hook λ = (arm+1, 1^{leg}) について、次が成り立つ。

  rCS_λ(K)|_{d_{1|1}} = (−𝐭)^{−(|λ|−1)Σ} · A_K(𝐪^{|λ|}𝐭^{arm(λ)}, 𝐭)、A_K := rCS_{[1]}(K)|_{d_{1|1}}

- d_{1|1} は 𝐚² = −𝐭^{−3} を代入すること。
- 小文字では、A_K の t^{1/2} を q^{arm/2}t^{(leg+1)/2} に置き換えることに当たる。
- 範囲：トーラス結び目 T(2,3), T(2,5), T(3,4), T(3,5)、4_1、K1、非代数的な K2, K4 の |λ| ≤ 3 の hook 全て（|λ| ≤ 3 は全て hook）。ツイスト結び目 |p| ≤ 6 と 10_124, 10_139, 10_152 の [2], [1,1]。
- t = q では、hook 型の色付き HOMFLY-PT は a = 1 で Δ_K(q^{|λ|})、という非 refined の性質に戻る。この非 refined の性質の出典は未確認（調査で見つけていない）。refined 版を述べた文献は見つかっていない。

**帰結【導出（上の性質のもとで）】**：
- a = t/q で自明な結び目の因子が 0 になるのは、(1,1) の箱を含む λ（hook でないもの）だけである。
- したがって \hat f_ρ|_{d_{1|1}} は、全ての ρ で A_K だけの普遍な式で決まる。

**genus 表示での帰結【計算】**：
- 𝐚² = −𝐭^{−3} は 𝐪 を含まないので、genus 表示 Σ \hat𝐍_{g,β,F}𝐚^{2β}𝐭^F G^g に、genus ごとに代入できる。
  - DGR の微分のうち、genus 表示にそのまま乗るのは q 次数 0 のもの（d_{n|n}）だけである（§6）。
- 代入後に 0 でない最大の genus は、商 R_ρ について次のとおり。

  | ρ | [1] | [2] | [1,1] | [3] | [2,1] | [1,1,1] |
  |---|---|---|---|---|---|---|
  | d_{1|1} 後の最大 genus | g | 2g−3 | 2g−2 | 3g−4 | 3g−3 | 3g−3 |

  - g は Seifert genus（[1] の行の値から読んだもの。トーラス結び目と代数的なケーブルでは Seifert genus そのもの）。[1] では A_K の 𝐪 次数が HFK の Alexander 次数なので g になる。
  - 表の式は g ≥ 2 の全ての結び目で成り立つ。g = 1 では [2] と [3] が 0 になる（T(2,3) では d_{1|1} の像そのものが 0）。
  - 代入の前の最大 genus は |ρ|² に比例して大きい。例：T(4,5)（g = 6）の [3] では、代入の前が 49、代入の後が 14 = 3·6−4。
  - 範囲：トーラス結び目 7 個、4_1、代数的なケーブル、非代数的な K2, K4, K5a, K5b, K6b、ツイスト結び目。
  - 例外は K5c だけで、[2] と [3] が表より 1 大きい。
  - D は d_{1|1} で −(1−𝐭⁻²)𝐭⁻¹G となり、ちょうど genus 1 だけを持つ。そのため \hat f_ρ では表より 1 大きい。
- 解釈【予想】：HFK が Seifert genus を検出するのと同じように、genus 表示の d_{1|1} 特殊化は、|ρ| に比例する形で genus を検出する。
  - c_ρ の値の理由（[2] と [1,1] で 1 違うこと）は未解決。
  - genus 1 の結び目（ツイスト結び目、T(2,3)、4_1）では、2 箱と 3 箱の全てで genus 0 だけが残り、𝐪 によらない。

## 6. 一般の d_{n|m} と genus 表示

**【導出】**：u_{n|m} + u_{m|n} = 𝐚²𝐭^{n+m+1}(w^{n−m} + w^{m−n}) で、w^k + w^{−k} は G + 𝐭 + 𝐭⁻¹ の k 次多項式である。
- よって (1+u_{n|m})(1+u_{m|n}) は (𝐚, 𝐭, G) の多項式で、genus の次数は |n−m|。
- n = m なら 1 + u_{n|n} = 1 + 𝐚²𝐭^{2n+1} で genus 0。

**【計算】**：0 ≤ n, m ≤ 3 の全てで、この積の genus 表示の係数は非負だった。

**まとめ**：genus 表示は σ で商をとった表示なので、DGR / GGS の微分は σ の軌道 {d_{n|m}, d_{m|n}} ごとにしか見えない。
- 軌道は genus を最大 |n−m| 上げる正の演算子として働く。
- d_{n|n}（U(n|n)、HFK 型）は genus を保つ特殊化として働く。
- これが「同じ構造は成り立たない」ことの具体的な形である。

**d_{2|0}, d_{0|2}, d_{1|1} は因子にならない**【計算】：
- a = t² では、2 行以下の λ が残り、自明にはならない。U(2) の簡約で関係式は出るが、零点は出ない（conventions §18 の [3,1] の条件と同種）。
- a = t/q では §5 の hook 型の性質になる。

## 7. δ 次数は移らない

**【計算】**：
- [1] は thin な結び目（ツイスト結び目、T(2,3), T(2,5)、4_1）で、DGR の δ = e_𝐚 + e_𝐪/2 − e_𝐭 が一定の平面にのる。
- 商 R_ρ（|ρ| ≥ 2）の台は、これらの結び目でも、spin 表示・genus 表示とも 3 次元に広がる（アフィン包の次元 3）。
- 例外は三葉結び目の R_{[2]}（4 項）で、平面 3e_𝐚 + e_𝐪 − 2e_𝐭 = 4 にのる。
- thin な結び目の色付きホモロジーが δ で決まるという構造は、plethystic log と M(t)^{-1} を通ると保たれない。

## 8. 非 refined（t = q、𝐭 = −1）の観察

**【計算】**：|R| ≥ 2 の非 refined の \hat f_R(a,q) は (1−a)²(1−aq)(1−aq⁻¹) で割り切れる（[1] は (1−a) のみ）。
- 範囲：T(2,3), T(2,5), T(3,4), 4_1, K1, K2, K8 の |R| ≤ 3。
- 4_1 の [2,1] だけは (1−a)³。KN の候補の入力であることに注意。
- (1−a)² の二重の零点は、refined で別々の d_{0|0}（a = 1）と d_{1|1}（a = t/q）が t = q で重なったもの【導出】。
- 非 refined の (1−aq)(1−aq⁻¹) は genus 表示（z² = (q^{1/2}−q^{−1/2})²）で (1−a)² − a z² となり、符号が混ざる。refined の 𝐚²𝐭²G が正になるのは、genus 表示の正値性が refined で初めて意味をもつことと整合する。

**文献との関係**（サブエージェントの調査で、原典の確認はサブエージェントによる）：
- a = 1 の零点は既知である。

## 11. 辞書：σ は SU(2)_L の Weyl 反転、G 展開が閉じる ⇔ σ 不変 ⇔ KN の整合条件【導出】

コードは src/rcsknots/lmovstruct.py、テストは tests/test_lmovstruct.py（機能）と tests/test_lmovstruct_results.py（results 印）。保存値の調査は scripts/lmovstruct_survey.py（data/lmovstruct/survey.jsonl, survey.md）、801 結び目の [1] は scripts/lmovstruct_knot_table.py、特殊化の点の走査は scripts/lmovstruct_loci.py。辞書は conventions.md §19 にも転記した。

### 11.1 変数
太字の単項式 𝐚^{2β} 𝐪^{2k} 𝐭^{f+k} = 𝐚^{2β} w^k 𝐭^f（w = 𝐪²𝐭）に (β, k, f) = (a 次数, SU(2)_L の重み, U(1)_R の電荷) を対応させる。KN の 2J_r は f。

| 対象 | 小文字 | 太字 |
|---|---|---|
| w | −(qt)^{1/2} | 𝐪²𝐭（SU(2)_L の重みの変数、refined topological string の q_L） |
| 𝐭 | −(q/t)^{1/2} | 𝐭（U(1)_R の電荷の変数） |
| G（KN の種数の因子） | (q^{1/2} − q^{−1/2})(t^{−1/2} − t^{1/2}) | w + w^{−1} − 𝐭 − 𝐭^{−1} = χ_{1/2}(w) − χ_{1/2}(𝐭) |
| σ（§0 の対称性） | (a, q, t) ↦ (a, 1/t, 1/q) | (e_𝐚, e_𝐪, e_𝐭) ↦ (e_𝐚, −e_𝐪, e_𝐭 − e_𝐪)、すなわち (𝐚, w, 𝐭) ↦ (𝐚, 1/w, 𝐭)：SU(2)_L の Weyl 反転。DGR の対称性 𝐪 → 1/(𝐪𝐭) と同じ |
| q = 1 | — | w = 𝐭^{−1}（G = 0） |
| t = 1 | — | 𝐪 = ±1（G = 0） |
| t = q（unrefined、Q = T） | G = −z² | 𝐭 = −1（D11 の「変数」の節） |

（σ の導出：a = −𝐚²𝐭 を固定し、q^{1/2} = −𝐪𝐭 ↦ t^{−1/2} = 1/𝐪、t^{1/2} = 𝐪 ↦ q^{−1/2} = −1/(𝐪𝐭) を解くと 𝐭' = 𝐭、𝐪' = −1/(𝐪𝐭)、w' = 1/w。）

### 11.2 G 展開が閉じる ⇔ σ 不変 ⇔ KN の整合条件
KN の形 \hat f_ρ = Σ (−1)^{2J_r} \hat N (q^{1/2}−q^{−1/2})^g (t^{−1/2}−t^{1/2})^g (q/t)^{J_r−β/2} a^β は σ で項ごとに不変（2 つの因子が入れ替わり、q/t と a は不変）。逆に σ 不変なら各 (β, f) 行が w ↔ 1/w 対称で、G 展開（rcsknots.bps.g_expand の閉じる条件と同じ）が閉じる。
さらに (refined-GT1) と (refined-GT2) は互いに σ の像である：KN の unreduced のミラー対称性 g_λ \bar{rCS}_λ(a,q,t) = (−1)^{|λ|} \bar{rCS}_{λ^T}(a,1/t,1/q) と P_λ(x; 1/t, 1/q) = P_λ(x; t, q)、g_λ(1/t,1/q) = (q/t)^{|λ|} g_λ(t,q)、g_{λ^T}(q,t) g_λ(t,q) = 1 から、GT1 に σ を施すと GT2 の x → (q/t)x になる。よって f^{\bar t}_μ = (t/q)^{|μ|} σ(f^q_μ)（KN の f^q の尺度 (t/q)^{|μ|/2} を除く）。
f^q = M(t)\hat f、f^{\bar t} = M(q^{−1})\hat f、σ(M(t)) = M(1/q) なので、KN の整合条件 f^{\bar t} = M(q^{−1})\hat f は \hat f = σ(\hat f)（単項式倍を除く）と同値。これは D8 で見た「GT1 と GT2 は任意の \hat f で同値」の導出でもある（H8 の解決）。
【計算】保存済み 452 件（data/bps/ の 112 件、data/highbox/ の 340 件）と K7〜K9 の 3 箱で \hat f_ρ(A,Q,T) = \hat f_ρ(A, 1/T, 1/Q) が単項式倍なしで厳密に成立（正値性が破れる非代数的なケーブルでも成立）。

### 11.3 特殊化の点（微分の対応物）と gl(N|M) の切り詰め
DGR の d_N の次数（superpolynomial.tex:898-905）：N > 0 で (−2, 2N, −1)、d_0 は (−2, 0, −3)、N < 0 で (−2, 2N, −1+2N)。対 x, d_N x が 𝐚² = c 𝐪^m 𝐭^n で恒等的に打ち消す条件を解くと c = −1 で、§0 の u_{n|m} = −1 ⇔ a = t^n q^{−m} に戻る。unknot 側では次の切り詰めになる。

| 微分 | (m, n) | 小文字の点 | Macdonald の unknot の切り詰め（unknot_λ = 0 ⇔） |
|---|---|---|---|
| d_N（N > 0） | (2N, −1) | a = t^N | (N+1, 1) ∈ λ、すなわち ℓ(λ) ≤ N が残る：SU(N) |
| d_{−N}（N > 0） | (−2N, −1−2N) | a = q^{−N} | (1, N+1) ∈ λ、すなわち λ_1 ≤ N が残る：転置した SU(N)（σ の像） |
| d_0 | (0, −3) | a = t/q | (2, 2) ∈ λ、すなわち hook だけが残る：gl(1|1) |
| （(1 + 𝐚²𝐭) の零点） | (0, −1) | a = 1 | (1, 1) ∈ λ、すなわち全て消える |
| GGS の d_{N|M} | (2(N−M), −2M−1) | a = t^N q^{−M} | (N+1, M+1) ∈ λ、すなわち (N|M)-hook が残る：gl(N|M) |

切り詰めの根拠：unknot_λ(a) = (t/a)^{|λ|/2} Π_{s=(i,j)} (t^{i−1} − a q^{j−1})/(1 − q^{a(s)} t^{l(s)+1})（conventions.md §2）で、a = t^N q^{−M} のとき t^{i−1} = t^N q^{j−1−M} ⇔ (i, j) = (N+1, M+1)。【計算：|λ| ≤ 5、N, M ≤ 2 で零の条件が一致】。したがって a = t^N q^{−M} での KN の生成関数は gl(N|M) の refined CS（(N|M)-hook の彩色だけ）になる。超群の表現が (N|M)-hook で添字づけられることの Macdonald 版である。
これは Macdonald の主特殊化の積公式の直接の帰結で、新規とは主張しない（novelty.md）。

## 12. 既約表示（SU(2)_L の指標）の正値性

### 12.1 定義
各 (β, f) 行 \hat f_{β,f}(w) = Σ_k c_k w^k は σ 不変性から w ↔ 1/w 対称なので、SU(2)_L の指標 χ_j(w) = w^{2j} + w^{2j−2} + … + w^{−2j} で一意に展開できる：
  \hat f_ρ = Σ_{β, j, f} N^{(s)}_{ρ;β,j,f} 𝐚^{2β} χ_j(w) 𝐭^f、 N^{(s)}_{ρ;β,j,f} = c_{2j} − c_{2j+2}。
整数性は自動。非負 ⇔ 各行が k の偶奇ごとに |k| について単峰。KN の genus 表示 Σ \hat N G^g 𝐭^F 𝐚^{2β} とは G^g = Σ_i C(g,i)(−1)^{g−i} χ_{1/2}(w)^i χ_{1/2}(𝐭)^{g−i} で結ばれ、符号が混ざるので一方の非負性は他方を含意しない（例：G 自身は genus 表示では非負だが既約表示では χ_0 𝐭^{±1} の係数が −1。逆の例は tests/test_lmovstruct.py::test_spin_nonneg_is_not_implied_by_nonneg）。
最大 genus g_max(β) の項は最大スピン j = g_max/2 の項に一対一に対応し、N^{(s)}_{β, g_max/2, F} = \hat N_{g_max, β, F}【導出：G^g の χ_{1/2}(w)^g の係数は +1】。
spin 表示の正値性（G 展開前の \hat𝐍 ≥ 0）、genus 表示の正値性（\hat N ≥ 0）、既約表示の正値性（N^{(s)} ≥ 0）、商 R_ρ の正値性（§3）は互いに独立な主張である。

### 12.3 [1] は定理【導出】
GHM 2103.01212 の Cor. (sl2 intro)（Lefshetz_revision_upd.tex:295-298）は y 化したホモロジー上の sl₂ 作用を与え、Chandler–Gorsky 2209.13058（main.tex:198）はその帰結として HHH(K) が Δ 次数と a 次数を保つ sl₂ 作用をもち、各 Δ 次数で q 次数 mod 4 ごとに対称かつ単峰であると述べる。
ここでの行 (β, f) は (a 次数, Δ 次数) の組に当たり（Δ は e_𝐭 − e_𝐪/2 の形の一次結合）、k の偶奇は q 次数 mod 4 に当たる。よって P の各行は対称で単峰、すなわち P の既約表示は非負。\hat f_{[1]} = (1 + 𝐚^{−2}𝐭^{−1}) P の因子は行 (β, f) を (β−1, f−1) に写すだけで行の中を混ぜないので、\hat f_{[1]} の既約表示も非負。
（Δ 次数の正確な定義と y 化前のホモロジーへの帰着は原典の該当箇所を引用して論文に書く。801 結び目での計算はこの帰結の確認で、成果ではない。）

### 12.4 予想
**予想 S（既約表示の正値性）**：KN の正値性予想が成り立つ結び目・彩色では、N^{(s)}_{ρ;β,j,f} ≥ 0。
「refined LMOV 不変量を SU(2)_L × U(1)_R の指標として読んだとき、各 (β, J_r) の SU(2)_L 表現が真の表現である」という物理的に自然な主張で、KN の genus 表示の正値性（Jacobian の Lefschetz 型の基底での非負性）とは独立。両方が成り立つことは、\hat f_ρ の各 a 行が「G^g の非負結合」かつ「χ_j の非負結合」であることを意味し、それを同時に説明する構造（例：Jacobian ファイブレーションの sl₂ と底空間の重み）は未解明（H13）。
unrefined では既約表示（z² = χ_{1/2}(q^{1/2}) − 2 の代わりに χ_j）の正値性は成り立たない（HOMFLY-PT の各 a 行の係数に符号が混ざる）。𝐭 が符号を分離することが refined の正値性の本質で、既約表示の正値性はその SU(2)_L 版である。

## 13. 特殊化の点の走査【計算】

### 13.1 彩色 d_1 の閉じた形
§2 の (S_{1|0}) の c は、保存済みの全 22 結び目（トーラス結び目 9、ケーブル 13、r ≤ 3）で c = (t/q)^{δ/2}（δ は conventions.md §13 の種数型の量。T(2,3) で (t/q)^{1/2}、K1 で (t/q)^4）。c は (N1)(N2') の正規化で決まり、正規化前の値の a = t での振る舞いが M_□ の a^δ と打ち消す。
\hat f_ρ(a = t) = 0（|ρ| ≥ 2）は data/bps 100 件、highbox 340 件、K7〜K9 の 3 箱の全件で成立。非代数的なケーブル（DAHA の値）でも成立する（切り詰めは入力の正値性と無関係）。a = q^{−1} は σ の像で全件 0。
逆に \hat f_ρ(a=t) = 0（全ての |ρ| ≥ 2）なら Z_K(a=t) は次数 1 の項の plethystic exponential で、c_1 = rCS_[1](a=t) が単項式なら c_r = c_1^r が従う。

### 13.2 d_0 の点 a = t/q（gl(1|1)）
\hat f_ρ(a = t/q) は 0 ではないが項数が大きく減る（data/lmovstruct/loci.json：T(2,5) の [2] で 112 → 16、T(3,4) の [2] で 429 → 34、K1 の [2] で 4141 → 135、T(4,5) の 5 箱で約 0.4%）。三葉結び目では ρ = [2], [3]（|ρ| ≤ 3）と ρ = [4], [5]（highbox）で 0、非対称な ρ では 0 でない。
意味：a = t/q では hook の彩色だけが残り、KN の M(t)（hook の指標 B_σ）がちょうどこの構造を担う。t = q では a = 1（Alexander、gl(1|1)）に当たる。三葉結び目の対称な ρ で消える理由は未解明（H15。§5 の hook 型の普遍式から説明できる可能性）。

### 13.3 その他の点【計算：T(2,3), T(2,5), T(3,4), 4_1, K1 の |ρ| ≤ 3、𝐚² = ±𝐪^m𝐭^n、|m|, |n| ≤ 8】
- |ρ| ≥ 2 で \hat f_ρ が 0 になる点は a = 1, t, 1/q の 3 点だけ（三葉結び目の対称な ρ では a = t/q も）。
- 次に縮退が強いのは a = t/q、a = t²（SU(2)）、a = qt（gl(1|−1) 型、σ の像は a = 1/(qt)）、a = −t（𝐚² = +𝐪²𝐭^{−1}）で、順序は結び目による（T(2,5) では a = qt が a = t² より縮退し、T(3,4) と K1 では逆）。
- 4_1 では a = t² と a = qt に目立った縮退は無い（両手型の結び目で a ↔ 1/a の対称性が効く）。4_1 の両手型性は \hat f_{ρ^T}(a,q,t) = \hat f_ρ(1/a,1/q,1/t) が単項式倍なしで厳密に成立（KN の \hat N_{ρ,g,β,J_r} = \hat N_{ρ^T,g,−β,−J_r} の \hat f での形）。一般の結び目で ρ ↔ ρ^T の関係は無く、M(t) が担う。

### 13.4 δ 次数と thin
δ := f − 2β（= e_𝐭 − e_𝐪/2 − e_𝐚）。801 結び目の P では δ の値の数は 1 が 705 個、2 が 96 個（Chandler–Gorsky の Δ 次数の分布と同じ）。\hat f_{[1]} は δ ∈ {δ(P)} ∪ {δ(P) + 1}。
彩色では δ の幅は箱数とともに広がる（T(4,5) の 5 箱で [−28, 134]）。G = χ_{1/2}(w) − χ_{1/2}(𝐭) の 𝐭 の項が δ を ±1 ずらすので、genus 表示の J_r の広がりは二項係数型になる（KN の 2J_r の偶奇の一様性はこの構造の mod 2）。§7 の「δ 次数は移らない」の定量的な形である。

## 14. 種数 0（q = 1）の部分にはジェットが要る【導出 ＋ 計算】

### 知見：DGR・四重次数の構成が決まる理由
1. **未知数自身が非負の Poincaré 多項式**である。
2. **多くの方向への射影が独立に与えられる**：
   - t = −1（Euler 標数）。
   - 各 d_{n|m} の特殊化（𝐚² = −𝐪^{2(n−m)}𝐭^{−2m−1} への符号付き射影）。
   - EGP（𝐪 = 𝐭⁻¹）。
   - sl(N) の像。
   非負の整数の 3 次元配列を、いくつかの方向の射影から復元する離散トモグラフィーの問題であり、非負性があれば少数の方向で一意になる。
3. **総階数を固定する情報**がある：DGR では Khovanov、S² では EGP の 𝐭 = 1。thick な結び目では、Euler 標数で打ち消される対が多く、Khovanov や sl(2) の像のような Euler 標数でない独立な入力が必要。
4. 微分の「ホモロジー」構造（対）は、最終的な一意性にはほとんど寄与しない。射影と非負性が本質。

### D7 への含意
- D7 では、未知の rCS_{[2]} に正値性を課さず（§F の規則）、正値性を \hat f にだけ課した。\hat f は rCS の 2 次式に単項式でない係数が掛かった量なので、「非負の配列の射影からの復元」という構造がなくなり、一意に決まらなかった。

- （2026-10-11 追記）rCS に正値性を課すことは本研究の §F の規則とは衝突しない。この研究は別の研究で、§F は適用しない（ユーザーの指示、README.md）。ただし [2,1] などの非長方形の rCS は非負でないので、この方法は使えない。[2,1] には、非負の未知数として R_ρ（または \hat f）そのものを取り、その射影（t = −1、D、d_{1|1} の普遍式、q = 1 の EGP）を集める定式化が候補になる。

### 変数：t = q か 𝐭 = −1 か【導出】

- 違いは未知数の基底にある。
  - 太字では rCS_λ の単項式 𝐚^{2β} 𝐪^{2k} 𝐭^{f+k} の係数が未知数で、t = q の条件は各 (β, k) の列で Σ_f (−1)^f x = HOMFLY-PT の係数、つまり HOMFLY-PT の各係数を 𝐭 次数に分配する圏化の問題になる。正値性（長方形の rCS、\hat f の spin・genus・既約表示）、σ（𝐪 → 1/(𝐪𝐭)、𝐭 固定）、δ 次数、d_{N|M} の対の因子 1 + u はこの基底で単項式の操作である。

### 自由度の構造 Φ·g【導出】

二つの解の差 Δ は斉次の条件を満たす：Δ(𝐭 = −1) = 0、σ(Δ) = Δ、Δ(q=1) = 0、Δ(a=t²) = 0（σ で a = q^{−2} でも 0）、H を課せば Δ(a = t/q) = 0。さらに (L)：\hat f_ρ の C_{21} = unknot_{[2,1]}·rCS_{[2,1]} の項は係数 k_{ρ,21} をもち、unknot_{[2,1]} の分母は (1−t)²(1−qt²) なので、Δ は (q−1)(t−1)(1−qt²)(1−q²t) で割り切れなければならない。因子は互いに素なので積が Δ を割り切る：

  Δ = Φ · g、　Φ = (1+𝐭)(𝐪²−1)(𝐪²𝐭²−1)(𝐪⁶𝐭²−1)(𝐪⁶𝐭⁴−1)·(1+u_{2|0})(1+u_{0|2})·[(1+u_{1|1})：H を課すとき]

- 小文字では (q^{1/2}−t^{1/2})(t−1)(q−1)(1−qt²)(1−q²t)(a−t²)(a−q^{−2})[(a−t/q)]。t = q の条件から出る因子は Q − T = −𝐪(1+𝐭) であって q − t ではない（Q + T は条件に入らない）。
- 逆に Φ·g はこれらの等式を全て満たすので、解は x = x_p + Φ·g（x_p は一つの解）。g は σ 対称で、Newton 多面体の加法性から g の単項式 e は e + NP(Φ) が x の窓に入るものに限られる。
- Φ の 𝐚 の幅（u の 3 因子で 𝐚 の指数 6）は rCS_{[2,1]} の 𝐚 の幅に等しいので、**g は 𝐚 を含まない**。自由度は (𝐪, 𝐭) の 2 変数多項式 g だけ（scripts/dgr_box3.py の phi21、solve21_g。T(2,5) で変数 6.4 万 → 136、一意性の判定 63 秒 → 2 秒）。
- 三葉結び目・4_1 では Φ の次数が窓に収まらず g の変数が 0 個になる。これが一次の条件だけで決まる理由で、正値性のおかげではない。T(2,5) 以上では g の居場所が残る。
- 整数計画で見つけた T(2,5) の別解 3 個と正解の差が Φ で割り切れることはテストで確認した（tests/test_dgr_lmov.py::test_box3_phi_divides_differences）。

### 正値性では決まらない【計算】

- 多面体（scripts/lmov21_polytope.py）：解空間 x = x₀ + K y（K は 2 つの素数で復元した整数基底、整数で検算）の上で \hat f_ρ = h₀ + Σ y_j h_j（厳密な割り算）。正値性は (i) spin 表示、(ii) genus 表示、(iii) 既約表示（§11）、全体の符号 8 通り。
  - T(2,3)：零空間 0 なので 1 点。3 表示とも正で正解。
  - T(2,5)（零空間 20、hook 込み）：(i), (i)+(ii), (i)+(ii)+(iii) のいずれでも多面体は非有界（乱数の 12 方向で幅 ∞）。非有界方向 d（3 本調べた）の rCS の方向は 448〜492 単項式で符号が混ざり、\hat f_ρ の像は 440〜608 単項式で**全て非負**、𝐭 は 1..25（正解の \hat f は 1..45）、δ は正解の範囲の内側、台は正解の台の内外に半分ずつ。
- 条件 B, R（次の節）を加えた整数計画でも同じ：T(2,5) の解 8 個の g は全て g = 𝐪^{−12}𝐭⁶(α + β𝐭)（整数 α, β、正解は (0, 0)）で、正値性が (α, β) に課す領域は頂点 (−10, 10), (11, −11) をもつ非有界な錐。正解は境界の辺 α + β = 0 の上にあり、そこで \hat f の 174 個の係数が同時に 0 になる。辺の上では \hat f の係数の和は一定。

**考え方**
- 残る自由度 Δ = Φ·g に対し、正値性だけでは多面体が非有界だった（「正値性では決まらない」の節）。非有界の方向は Δ\hat f ≥ 0（正の BPS 状態を足す方向）で、framing を変えても Δ\hat f^{(x)} = 𝐭^{5x}Δ\hat f^{(0)}（[2,1] の framing の因子は 𝐭⁵、conventions §17）なので、framing の正値性を足しても多面体の後退錐は変わらない【導出】。
- そこで**選択の原理として BPS 状態の総数 Σ_ρ Σ \hat𝐍_ρ（framing 0）の最小化**を課す【仮説】。総数は g の一次式で、後退錐の方向は総数を増やすので、最適面は有界になる【計算：下の全例で有界】。既知の結び目では正解が常に最適面の上にある（最小値 = 正解の値）【計算：T(2,3), 4_1, T(2,5), T(2,7), T(3,4)】。framing x での総数は framing 0 の総数と同じ量だけ変わるので、他の framing での総数の最小化は新しい条件にならない【導出】。
- 最適面の上に残るのは、総数を変えない付け替えである。Δ\hat f は正負同数の対で、正解の台の内側で状態を 𝐭²（U(1)_R の電荷 +2）や 𝐚^{−2}𝐭（a 次数 −1）だけ動かす【計算：T(2,5) の 12 点の面の全ての別解】。これは **framing の正値性**で殺せる：framing x では正解の \hat f^{(x)} の形が変わるのに Δ\hat f^{(x)} は 𝐭^{5x} 倍されるだけなので、Δ の負の部分が覆われなくなる【計算】。framing は負（T(2,5) では整数計画の別解 3 個が x ≤ −1 で全て負の項をもつ）だけでなく正（K_{−2} では x = +2 で候補 3 個のうち 2 個が落ちる）も効く。
