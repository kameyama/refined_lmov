# 研究計画：DGR・四重次数型の構造と refined LMOV（別の研究、2026-10-11 作成、同日 D7〜D11 と S0〜S6 を追加）

この研究の規則と、本研究（KN の検証）との違いは README.md。

本研究の計画（docs/research_plan*.md）とは独立の、別の研究の計画。ユーザーの指示：
- 「DGR や quadruply graded homology のような考え方を refined LMOV invariant の spin 表示や genus 表示でできるか研究せよ」
- 「今回の研究について既存の計画とは別に計画を用意し成果を記録しながら進めよ」
- 「見つけた構造と unrefined lmov のデータから refined lmov が構成できるか。refined large N の式を逆向きに解いて refined lmov のデータから rCS が計算できるか。それが既存の rCS に一致するか。まだ計算されたことのない値はどうなるか。以上を計画に加えよ」（D7〜D10）
- 「この研究の目標は unrefined LMOV のデータから refined LMOV をいくつかの仮定の下で計算できるようになることである。その仮定を見つけたい。特に重要なのはまだ数の少ない [2,1] や [3,1] のような不変量がこのアプローチで構成できるかどうかである」「unrefined の LMOV（t = q）ではなく 𝐭 = −1 の変数の方が良い可能性がある。どちらの変数が良いかも考えよ」（D11）
- 「DGR や quadruply graded homology のような考え方を refined LMOV 不変量の既約表示や種数表示でできるか研究せよ」（S0〜S6：既約表示＝spin 表示の各行を SU(2)_L の指標にまとめ直した基底）

- 成果の記録先（全てこのディレクトリ）：report.md（本文）、progress.md（区切りごと）、open_problems.md（未解決 H1〜H18）、novelty.md（新規性）。

## 2. 段階

### D1：4 箱以上への拡張（計算）
- 入力：本体のチェックアウトの data/highbox/（トーラス結び目の N = 4〜9 箱、git の外、1.1 GB）。読むだけで、書き換えない。
- 判定（ρ ごと）：
  1. d_{n|m}（n, m ≤ 2）の各因子で割り切れるか。
  2. 商 R_ρ の spin・genus 表示の負の項。
  3. d_{1|1} 後の最大 genus。
- 準備：まず N = 4 で時間を測り、外挿して 1 件 30 分を超えるものは除くか、事前に progress.md に見積もりを書く。
- 結果は ρ ごとに data/dgr_lmov/highbox/ に保存し、保存済みは読み飛ばして再開できるようにする。

### D2：d_{1|1} の普遍式と c_ρ（導出＋計算）
- hook 性質を仮定すると、\hat f_ρ|_{d11} は A_K だけの普遍な式で決まる。
  1. 2 箱は 2 箱の公式（scripts/v4_closed.py の formula）に hook 性質を代入して、記号的に求める。
  2. 3 箱は src/rcsknots/bpsgen.py と同じ plethystic log を、A_K を記号のまま、または十分一般な A_K で行う。
- 最大 genus を A_K の 𝐪 次数（= 2g）の関数として導き、c_ρ を説明する。
- 普遍式を、D0 の実データの d_{1|1} 特殊化と全係数で照合する（テスト）。

### D3：特殊化の性質の導出（導出）
- GN/EHA の構成で、a = t（N = 1）での rCS_{[r]} と、a = t/q での hook の rCS を評価する。
- 証明できなければ、どこで止まったかを記録する（時間を区切る）。

### D4：商 R_ρ の意味（計算＋観察）
- R_ρ(1,1,1)（生成元の数）と、色付き Poincaré 多項式の次元・(dim H^{[1]})^{|ρ|} などとの比較。
- ツイスト結び目の族で、R_ρ の p についての閉じた形（ニュートン形）を作り、係数の正値性を見る。

### D5：非 refined の側（計算）
- 𝐭 = −1 の \hat f_R を (1−a)²(1−aq)(1−aq⁻¹) で割った商の genus 表示 \hat N_{R,g,Q} の符号の型を観察し、refined の R_ρ と比べる。

### D6：framing、Σ ≠ 0（探索）
- 持ち上げを 𝐭^{−2Σ}\hat f^{(x)}(○) 以外にとる候補を探す。候補の例：
  - d_{1|0} と d_{0|1} で残る生成元を別々に使う。
  - framing をずらした自明な結び目を使う。
- 商が正になる規則があるかを、ツイスト結び目で調べる。

### D7：非 refined の LMOV と構造からの refined LMOV の構成（2026-10-11 追加、ユーザーの指示）
- 問い：非 refined の \hat f_R(a,q)（= \hat f_ρ の 𝐭 = −1）を既知として、𝐭 の次数を持ち上げた refined の \hat f_ρ が、見つけた構造の条件だけで決まるか。
- 入力の 2 つの型を分けて調べる。
  - (a) 非 refined の LMOV だけ（|R| ≤ n の色付き HOMFLY-PT から作る）。
  - (b) (a) に refined の [1]（superpolynomial、HOMFLY-PT ホモロジーの Poincaré 多項式）を加える。d_{1|1} の普遍式（D2）は A_K = [1]|_{d11} を要するので、(b) でだけ使える。
- 未知数：商 R_ρ（\hat f_ρ = D R_ρ）の spin 表示の各項の 𝐭 の次数（と、𝐭 = −1 で打ち消し合う対）。
- 条件（使う順）：
  1. 𝐭 = −1 で非 refined に戻る。
  2. σ 不変（genus 展開が閉じる）。
  3. D で割り切れる。
  4. d_{1|1} の普遍式（(b) のみ）。
  5. 2J_r の偶奇。
  6. 商 R_ρ（したがって \hat f_ρ）の両表示での非負性。
- 手法：整数計画（既存の scripts/construct_superpolynomial.py, t4_ilp.py と同じ型）。解の数を数え、一意かどうか、一意でなければ解の空間の次元を記録する。
- **rCS の正値性**（2026-10-11 改訂）：本研究の open_problems §F の規則（rCS の候補に正値性を課さない）は、この研究には適用しない（ユーザーの指示「今回は研究自体が異なるので衝突しない」）。Poincaré 多項式である対称表現などの rCS には正値性を課してよい。非長方形の rCS（[2,1] など）は負の係数をもつので、正値性は課さない（数学的な理由）。
- **LMOV の正値性（条件 6）は条件に使ってよい**（2026-10-11、ユーザーの指示「この計画では refined LMOV に正値性は課して良い。今回は KN の検証をする計画ではなく新しい研究である」）。
  - この計画の目的は、構造から refined LMOV と rCS を構成することで、KN の予想の検証ではない。
  - 条件 1〜6 を全て使ってよい。記録では、解を決めるのに効いた条件を書く（どの条件を外すと解が増えるか）。
- 検証の対象（答えが既知のもの）：
  - トーラス結び目と代数的なケーブル（EHA, DAHA）の |ρ| ≤ 3。
  - ツイスト結び目の 2 箱（GNSSS）。
  - 4_1 の 2 箱。
- 第 3 期の結果（[2,1] は構造的な条件だけでは決まらない、三葉結び目で解の差の階数 6）との関係を記録する。今回は条件 3, 4 が加わる。

### D8：refined large N の式の逆解き（rCS の再構成）
- KN の (refined-GT1)：Σ_λ \bar{rCS}_λ g_λ P_λ(x) = Exp(Σ_μ f^q_μ/(q^{1/2} − q^{−1/2}) s_μ(x))、f^q = M(t)\hat f。
  - \hat f_ρ（|ρ| ≤ n）が与えられれば、f^q を作り、plethystic Exp を展開し、P_λ の係数を読むことで \bar{rCS}_λ（|λ| ≤ n）が一意に決まる。代数的には可逆。
- (refined-GT2) からも、別の \bar{rCS}_λ が決まる：Σ_λ \bar{rCS}_λ P_{λ^T}(−x; t, q) = Exp(Σ f^{\bar t}_μ/(t^{−1/2} − t^{1/2}) s_μ)、f^{\bar t} = M(q^{−1})\hat f。
  - （2026-10-11 の結果）2 つは任意の \hat f で一致し、独立な条件にならない（report.md D8）。
- 実装：src/rcsknots/bps.py の f_formulas（|μ| ≤ 3、記号的）と bpsgen.py（評価点、4 箱以上）の逆向きの計算。
- 出力：\hat f → rCS の関数と、GT1 / GT2 の一致の判定。

### D9：既存の rCS との照合（往復の検査）
- 既存の rCS → \hat f（既存の計算）→ rCS（D8）の往復が、全係数で恒等になることを確かめる（実装の検査）。対象は data/lmov の 21 結び目の |λ| ≤ 3、トーラス結び目の 4〜9 箱。
- D7 で構成した refined LMOV から D8 で作った rCS が、既存の rCS（EHA、DAHA、KNTZ の長方形、GNSSS の対称表現、KN の 4_1 の [2,1] の候補）と一致するかを確かめる。
  - 一致しなければ、どの条件が足りないかを記録する。
- t = q で色付き HOMFLY-PT（ブレイド・ケーブルからの計算、data/x0 など）に戻ることも確かめる。

### D11：3 箱の [2,1] と 4 箱の [3,1]——unrefined から refined を構成する仮定（2026-10-11 追加、ユーザーの指示）
- 未知数は rCS_{[2,1]}（または rCS_{[3,1]}）の太字の係数。(𝐚, 𝐪) の窓は非 refined の台の箱、𝐭 の窓は入力から決める規則で与える。
- 条件：U（t = q ⇔ 𝐭 = −1）、T（転置）、E（EGP）、U2（a = t²）、H（hook）、L（3 箱・4 箱の \hat f の Laurent 性）、P（\hat f の正値性。整数計画でのみ）、窓の規則 B・R。
- 手順：(1) 一次の条件だけで零空間の次元を数える（法 p の疎な消去）。(2) 零空間が残れば、解の差の因子 Φ を導出し、自由度を g の係数に落とす。(3) 正値性の多面体が有界かを調べる。(4) 選択の規則（L1 最小、項数最小）を既知の結び目で検査する。(5) 一意に決まる結び目でだけ予言する。
- 検証の対象：T(2,3), 4_1, T(2,5), T(2,7), T(3,4)（EHA、KN の候補）、ツイスト結び目 K_{±1}（GNSSS と X0 のケーブル）。4_1 の [3,1] は f41_box4 の一次の系に 4 箱の Laurent 性を加える。
- 停止点：既知の結び目で一意に決まらず、正値性と選択の規則でも決まらないとき。
