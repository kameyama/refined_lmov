# 結果の概要（論文にする場合の順序）

作成：2026-10-08。本研究（第 1〜5 期）と別研究 [2,1]（X0〜X2）の結果を、論文にする場合の順序（序論 → 方法 → 結果 → 議論）で整理したもの。

印は【導出】解析的に導出、【計算】計算機で確認（範囲つき）、【予想】、【仮説】。新規性の判断は docs/novelty_report.md の文献確認に基づく「新規と思われる」の水準。

---

## 1. 序論：問題設定
- KN（1703.05408）は、refined CS 不変量を resolved conifold 上の refined BPS 不変量（refined LMOV 不変量）に書き換え、正整数性（正値性）を予想した。検証は主にトーラス結び目だった。
- 本研究はこれを**トーラス結び目以外**へ広げ、箱の数 |ρ| ≤ 3（3 箱）まで検証した。判定は G 展開の前（\hat{𝐍}）と後（\hat N）の両方で行う。
- 鍵になる難しさ：3 箱には非長方形の彩色 [2,1] が要る。双曲結び目の refined [2,1] は定義に基づく構成が無い。

## 2. 方法と規約（論文の「準備」の節）
- **再現による規約の固定**：KN のノートブックの 27 件（トーラス結び目、|λ| ≤ 3）を、楕円 Hall 代数（GN の構成）から全係数で再現した【計算】。BPS の表も再現した。いずれも既知の結果の再現。
- **ケーブル**：refined の値は DAHA の定義を companion の段で分解した形で計算し、CD14 の明示例 8 件と照合した。素朴な Rosso–Jones の t 変形が誤りであることは既知。
- **正規化の単項式**：KN の BPS 抽出は単項式倍で結果が変わるので、正規化の規則 (N1)(N2') を定めた（[1] は t = q で HOMFLY-PT に一致し最低 𝐭 次数が 0、彩色付きは [1] の単項式と framing の固有値の積）。
  閉じた式 M_□ = (−q/t)^{b−1}(a(q/t)^{1/2})^δ は 22 結び目で成立した【計算】。refined 衛星公式【仮説】と、トーラス結び目についての定理（Mellit、Franks–Williams）から導出した【導出】。
- **計算基盤**：補間は素数を 1〜3 個使う厳密な方法、G 展開は約 100 倍の高速化。結果の信頼性は機能テストで担保している（全体 590 件）。

## 3. 結果 I（主結果）：定義どおりに計算できる結び目で 3 箱まで正
- トーラス結び目 7 個と代数的な iterated torus 結び目 7 個（K1, K3, K6a, K7, K8, K9, K10。3 本ケーブルと 2 段の反復を含む）で、|ρ| ≤ 3 の全 6 つの ρ について G 展開の前後とも非負【計算】。
- K10 の 3 箱は約 183 万項で、係数の最大は 1.1×10¹⁹。
- 注目点：入力の rCS_{[2,1]} 自体は負の係数をもつのに、BPS の段では正になる。
- 対照：非代数的なケーブル（DAHA の値はホモロジーではない）では正値性が破れ、破れ方は 3 つの型に分かれた。入力が KN の前提を満たさないので、補足の扱いにとどめる。
- 新規性：代数的なケーブルの 3 箱は新規と思われる（KN を引用する論文に該当なし）。

## 4. 結果 II：[1]（全ての結び目）
- **命題 1【導出】**：入力が非負係数で DGR の対称性（Gorsky–Hogancamp–Mellit の定理）をもてば、[1] の G 展開は整数で閉じ、前後とも非負。したがって、ホモロジーを入力とする限り任意の結び目で [1] は正。
- 11 交点以下の全素結び目 801 個で確認した（命題の確認の位置づけ）。
- 2J_r の偶奇がそろう条件は、parity knot（Chandler–Gorsky）と同じ形になった。BPS 不変量との関係は新規と思われる。

## 5. 結果 III：2 箱
- **命題 2【導出】**：2 箱の \hat f が Laurent 多項式であるためには、dim H^{[2]} = (dim H^{[1]})² が必要。9_42 が KN の形に乗らない理由はこれで説明できる。
- **ツイスト結び目**：全ての p で正【導出、入力は GNSSS の予想式】。
- **pretzel 結び目**：同符号の領域は全て正。異符号は min(|s|, t) ≤ 20 で証明し、|s|, t ≤ 40 で確認した。残りは 1 変数の 3 系列に帰着したが、そのうち d_1 の LP は打ち切り。
- **thick な非トーラス結び目 10_139, 10_152**：2 箱が正【計算、予想式に基づく】。方法は 8_19 で EHA と照合して較正した。
- 正値性は自動的ではない。t_c 次数の別の割り当てでは負の項が出る。

## 6. 結果 IV：双曲結び目の refined [2,1]（否定的な結果）
- **結び目ごと（第 3・4 期）**：構造的な条件では決まらない。解の差は「結び目によらない因子 × 自由な多項式 u」【計算＋導出】。弱い判定では、正値性を満たす [2,1] は 4_1 と 6_1 に存在し、5_2 は有理数解のみ。
- **族として（別研究 X0〜X2）**：
  1. **t = q（X0）**：ダブルツイスト結び目の [2,1] について、Morozov の式（1612.00422、1903.00259 の 𝓑）がケーブルからの定義どおりの値と一致した（ツイスト結び目 |p| ≤ 10 と 4 つのダブルツイスト結び目）【計算】。1612 の予想式の検証になる。1903 の式の正しい読み方（Z を F^{(1)}F^{(−1)} で割る）も特定した。
  2. **refined の長方形（X1）**：KNTZ の式を著者のパッケージに忠実に実装し、GNSSS と三葉結び目の EHA（[2,2] まで）と一致した。t_c 次数の規則 𝐐 → 𝐪^R も確定した。
  3. **数え上げ（X2）**：KNTZ の式は KN の変数で直接書け、refined の 𝓑 の正則な行も決まった。EGP と U(2) の過剰決定系は矛盾しなかった。しかし各チャネルの係数は一意に決まらず、自由度は第 4 期の δ の族版だった【計算＋導出】。refined な微分の単純な積という仮定は否定された。
- 位置づけ：t = q の部分は既知の式の検証。refined については「素直な拡張では決まらない」という否定的な結果と、残る自由度の明示が成果になる。

## 7. 議論と未解決の問題
- 双曲結び目の 3 箱には、定義に基づく [2,1] が要る。研究規模の課題として open_problems.md §F に記録した：F1 refined な Racah 行列、F2 DAHA/EHA 型の定義の拡張、F3 ホモロジーの計算と rCS への変換規則。
- そのほかの課題：
  - 正規化の導出のうち、Mellit の Cor (daha) の正規化を原典で確定すること（仮説 H_sat は物理的な仮説として残る）。
  - pretzel の異符号の領域の残り（d_1 の LP は打ち切り）。
  - 2 箱の単峰性（sl_2 正値性）の理由。
