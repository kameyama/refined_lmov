## 0. 要約

KN（Kameyama–Nawata、arXiv:1703.05408）は、非トーラス結び目では HOMFLY-PT ホモロジーの Poincaré 多項式（t_c 次数）を入力として refined LMOV 不変量を定義し、その正値性を予想した。
本研究では、入力を実際のホモロジー（または予想に基づく彩色ホモロジーの式）にとり、正値性がどこまで構造から従い、どこで破れるかを調べた。

1. **[1] の正値性は一般に従う【導出】（命題 1）。** 入力が非負係数で DGR の対称性をもてば、\hat f_{[1]} の G 展開は整数で閉じ、展開の前後とも非負。
   DGR の対称性は Gorsky–Hogancamp–Mellit（arXiv:2103.01212）の定理なので、ホモロジーを入力とする限り、**任意の結び目で [1] は正**。
   11 交点以下の全素結び目 801 個（Nakagane–Sano arXiv:2111.00388 のホモロジー）で確認した【計算】。
2. **[1] の 2J_r の偶奇の判定条件【導出】。** (g, β) ごとに偶奇がそろう ⇔ 𝐚 の次数が連続する範囲ごとに e_𝐭 + e_𝐚/2 の偶奇が一定。
   801 個のうち偶奇がそろうのは 9 個（トーラス結び目 7 個と 10_125, 10_140）【計算】。
3. **2 箱の必要条件【導出】（命題 2）。** \hat f_{[2]} が Laurent 多項式なら refined 指数増大性 rCS_{[2]}(q=1) = rCS_{[1]}(q=1)² が従い、非負の入力では **dim H^{[2]} = (dim H^{[1]})²** が必要。
   9_42 では 81 が必要だが S² ホモロジーの次元は 401（GGS arXiv:1304.3481 に明記）。t_c 次数をどう選んでも KN の形に乗らない。KN が観察した 9_42 の破れの原因を特定した。
   thick でもトーラス結び目（8_19 など）は指数増大性を満たすので、破れるのは 9_42 のような非トーラスの thick な結び目。
4. **Gukov–Stošić（arXiv:1112.0030）の 9_42 の S² の式の誤植【計算】。** 付録 B の式の 2 行目のブロックが余分（Euler 標数が [2] 彩色 HOMFLY-PT と合わない）。8_19 の [1] の式にも誤植がある。
   除いた後の次元 401 は GGS の値と一致するので、GGS では暗黙に修正されている（誤植の明示的な指摘は見つからなかった、§6）。命題 2 により、9_42 の結論は誤植にも、S² ホモロジーの候補の違い（§3.3）にもよらない。
5. **t_c 次数の決め方【計算】。** thick な結び目では、t_r 次数のデータから t_c 次数は決まらない（8_19 で較正）。thin な族では δ' = −S（一定）で決まり、二つの独立な方法で一致した。
6. **thin な族の 2 箱【計算、予想式に基づく】。** ツイスト結び目 K_p（p = −12〜12）の 24 個と、(2s−1,1,2t−1)-pretzel の 55 個（s, t ∈ [−5, 5]）の全てで、[2], [1,1] の \hat f が G 展開の前後とも非負。
   （2026-10-07 訂正：当初「次元が二乗にならない 16 個は Laurent にならない」としたのは、入力スクリプトの浮動小数点のバグによる。修正後は 55 個全てで次元が二乗。REPORT_phase4.md §8）
   **2 箱の正値性は自動的ではない**：5_2 で t_c 次数の別の割り当て（正の入力、Laurent、G 展開が閉じる）を 12 通り試すと、全て G 展開の前か後に負の項が出た。

## 2. [1]：命題 1 と結び目表（ステージ T1）

**命題 1【導出】**：P ∈ ℤ_{≥0}[𝐚^{±1}, 𝐪^{±1}, 𝐭^{±1}] の 𝐪 の指数が偶数で、DGR の対称性 (e_𝐚, e_𝐪, e_𝐭) ↔ (e_𝐚, −e_𝐪, e_𝐭 − e_𝐪) をもつなら、
\hat f_{[1]} の G 展開は整数で閉じ、展開の前の係数も後の \hat N もすべて非負。

- 証明の要点：u = 𝐪𝐭^{1/2} とおくと対称性は各 𝐚 行の u についての回文性になり、G = u² + u⁻² − (𝐭 + 𝐭⁻¹)。
  p_k = y^k + y^{−k}（y = u²）の w₀ = 𝐭 + 𝐭⁻¹ のまわりのテイラー係数は dp_k/dw = kU_{k−1} と母関数 1/(1 − wx + x²) = Σ_g G^g x^g/((1 − 𝐭x)(1 − x/𝐭))^{g+1} から非負。
- 系：ホモロジーを入力とする限り、任意の結び目で [1] の正値性が成り立つ。
- 結び目表での確認【計算】（`data/knot_table_summary.md`）

| 分類 | 結び目数 | G 展開が閉じる | 前後とも非負 | 2J_r の偶奇がそろう |
|---|---|---|---|---|
| thin・交代 | 562 | 562 | 562 | 5 |
| thin・非交代 | 143 | 143 | 143 | 1 |
| thick | 96 | 96 | 96 | 3 |

- 第 1 期との関係：ケーブルの DGR 型の候補が [1] で正になったのも命題 1 の帰結。DAHA の値の負は P 自体の負の係数による。逆は成り立たない（第 1 期の K5c）。
- **2J_r の偶奇【導出＋計算】**：p_k の G^g の係数の 𝐭 の指数は k − g と同じ偶奇なので、F（= 2J_r）≡ e_𝐭 − g。
  したがって (g, β) ごとに偶奇がそろう ⇔ 𝐚 の次数が連続する範囲ごとに e_𝐭 + e_𝐚/2 の偶奇が一定。801 個で計算と一致。
  偶奇がそろうのは 3_1, 5_1, 7_1, 9_1, 11a_367, 8_19, 10_124（トーラス結び目）と 10_125（thick）, 10_140（thin）。
  KN は偶奇の一致を S_R の自明作用の証拠としたが、非トーラス結び目にも偶奇がそろう例がある。
  この条件は、Chandler–Gorsky（arXiv:2209.13058）の「parity knot」（HHH 全体で t/2 の偶奇が一定、同値に t_DGR − a/2 の偶奇が一定）と、𝐚 次数の台に隙間が無いとき同じ【導出】。801 個すべてで台に隙間が無く、判定も一致した【計算、2026-10-09、tests/test_knot_table.py::test_parity_criterion_equals_chandler_gorsky】。新しいのは、それが [1] の 2J_r の偶奇と同値であることの導出。

## 3. 2 箱：命題 2 と 9_42（ステージ T4、conventions.md §12）

### 3.1 [2] 彩色 HOMFLY-PT と t_c 次数

- [2], [1,1] 彩色 HOMFLY-PT は、(2, s)-ケーブル（s = 1, 3）の HOMFLY-PT をブレイドから計算し、ケーブル公式を逆に解いて求めた。三葉結び目と 4_1 で KN の値と完全一致【計算】。
- GS（arXiv:1112.0030）の S² ホモロジーは t_r 次数（GS の old 規約）。KN の入力（t_c 次数）への変換は、生成元 x = (i, j, k) と δ'(x) から
  [2]：(2i, 2j, 4i − k + 2j + 4δ'(x))、[1,1]：(2i, −2j, 4i − k + 4δ'(x))。
  三葉結び目は δ' = −1 一定で KN の rCS に完全一致。8_19 = T(3,4)（thick）は、正解を再現する δ' が生成元ごとに −3.5〜−2 でばらつく【計算】。
  素朴な δ' = −S 一定では、正解が正である 8_19 でも \hat f が Laurent 多項式にならない【計算】。

### 3.2 GS の 9_42 の式の誤植【計算】

- 印刷された S² の式は、Euler 標数が正しい [2] 彩色 HOMFLY-PT と合わない（special polynomial の性質も破れる）。差はちょうど 2 行目のブロックの Euler 標数。
- 2 行目を除くと Euler 標数が一致し、GS が述べる微分 d₁, d_{−2}, d_{−3}, d_{2→1}, d₀ の必要条件（P − H_d = (1 + x^{deg d})R, R ≥ 0）を全て満たす。印刷どおりでは d₀ の条件が破れる。
- 8_19 の [1] の式も a⁴q³t⁶ が a³q³t⁶ の誤植（special polynomial の性質から）。

### 3.3 命題 2【導出】

\hat f_ρ（|ρ| = 2）= num/den、den = 2A²(Q⁴ − 1)(T⁴ − 1)(Q²T² − 1)（(A, Q, T) = (a, q, t)^{1/2}）。num の Q = 1 での値は (r₂ − r₁²) に比例するので、
\hat f_{[2]} が Laurent ⇒ rCS_{[2]}(q=1) = rCS_{[1]}(q=1)²。非負係数の入力では q = 1（𝐭 = −𝐪⁻¹）で各項の符号が 𝐪 の指数の偶奇で決まり、打ち消しが起きない。
したがって **dim H^{[2]} = (dim H^{[1]})²** が必要（[1,1] は t = 1 で同様）。

- 9_42：dim H^{[1]} = 9、dim H^{[2]} = 401（修正後。印刷どおりは 433）≠ 81。t_c 次数の選び方によらず KN の形に乗らない。
  9_42 の S² ホモロジーは確定しておらず、Stošić（arXiv:2402.03066）は別の候補を挙げている（文献確認のエージェントによると生成元 209 個と 241 個。本文は私は未確認）。どれも 81 ではないので、結論は同じ。
- thick なトーラス結び目は指数増大性を満たす（8_19 は 121 = 11²。トーラス結び目の二重次数版は Conners arXiv:2512.20597 が証明）。命題 2 で破れるのは非トーラスの thick な結び目。
- 整数計画（`scripts/t4_ilp.py`）でも確認：δ' ∈ [−2.5, 2.5] で、正値性を課さなくても Laurent 性と G 展開の閉じ方を満たす割り当ては無い。EGP だけでも δ' ∈ [−6, 6] で不能。
  同じ整数計画で、三葉結び目と 8_19（dim 121 = 11²）は正値性込みで実行可能【計算】。
- KN は「thick なホモロジーは指数増大性をもたない」と述べていた。命題 2 はそれが 2 箱の形の必要条件であることを示す。
