# orientifold の開弦の refined 指数：一粒子状態の分類と E・C の分離（2026-10-20）

主張の分類：【導出】（下の仮定のもとで）、【計算】、【予想】、【仮説】。記号は conventions.md と report.md に従う（q, t、ν = U t^{−1/2}、G = z_q z_t、w = (q/t)^{1/2}、σ：q → t^{−1}, t → q^{−1}）。
出典：AgSc = Aganagic–Schaeffer 1202.4456（TeX で確認、§3〜§4、§7）、KN = 1703.05408（TeX で確認）。

## 1. 設定と仮定
- M 理論：X × TN × S¹ を q, t で捻り、orientifold は X 上の反正則な対合 I と時空の z₂ → −z₂ の組 Ĩ（AgSc §3）。結び目 K の probe は t-brane（M5 が z₂ 平面を張る。開弦の分母が 1/(1 − t) であることから、report §7）で、L_K と像 I(L_K) の 2 枚がある。
- 被覆の一粒子 BPS 状態の空間 H₁ = H_int ⊗ F_{z₂}（F_{z₂} は z₂ 方向のモード、t^l、l ≥ 0）。Ĩ は H₁ の対合で、H_int には内部の作用 Ĩ_int、F_{z₂} には (−1)^l で働く。
- 【仮定】商（X/I）の一粒子状態は被覆の Ĩ の軌道で、AgSc (3.13) の積表示のとおり：(i) Ĩ で入れ替わる対 {ψ, Ĩψ} → 全モードの塔、(ii) Ĩψ = ε ψ（ε = ±1、ψ の曲線が I で不変で z₂ 方向に動ける）→ (−1)^l ε = +1 のモードだけ、(iii) z₂ = 0 に凍結した向き付けられない状態（被覆の不変な曲線で、商が向き付けられない面、例えば環を自由な対合で割った Möbius の帯）→ モードの塔なし。

## 2. 自由エネルギーの分解【導出】
被覆と商の一粒子の指数を、Y の冪和の係数ごとに比べる。状態の電荷 m（q, t, ν の単項式）について
- 被覆：f^{cov} = Σ_{対} 2m/(1 − t) + Σ_{不変} m/(1 − t)。
- 商（SO）：f = Σ_{対} m/(1 − t) + Σ_{不変} m Σ_{l: (−1)^l ε = 1} t^l + Σ_{凍結} m、ここで Σ_{l: (−1)^l ε = 1} t^l = ½[1/(1 − t) + ε/(1 + t)]。
したがって g = f − ½f^{cov} = Σ_{不変} ε m · ½/(1 + t) + C、すなわち
  **g = ½E/(1 + t) + C、E = Σ_{不変な状態} ε_ψ m_ψ（Ĩ_int の符号付きの和）、C = Σ_{凍結した状態} m。**
これは report §7 で Hopf から帰納した全 d の構造の導出である。不変な状態は Ĩ で自分自身に移るセクター（brane と image を同数もつセクター）にしかないので、E は（偶, 偶）のセクターと p₂ 型の方向（Adams の ψ²）にだけ現れる（Hopf で確認済み、結び目の 2 箱で E_(2) = −E_(1,1)）。

## 3. E と C の分離は指数からは決まらない【導出】
- 凍結した状態 m は、不変な状態 m（ε = +1）と mt（ε = +1）の組と、指数の上で区別できない：½m/(1 + t) + ½mt/(1 + t) = ½m·… すなわち E → E + 2(1 + t)X, C → C − X で g は変わらない。指数 g から決まるのは E(t = −1) だけ（t の冪級数の大きな次数）。
- 固定セクターの指数 P = (1 − t)·(固定セクターの f^{cov}) は「不変な状態 + 2 × 対」の (−1)^F 付きの和で、ボソンとフェルミオンの打ち消しを含む。E は Ĩ_int の符号を付けた和なので、P に見えない（打ち消した）状態を含みうる。実際、結び目の 2 箱では、(i) t = −1, (ii) t = q の条件を満たす E は P の単項式の台に収まらない【計算、続き 34・35】。Hopf で E が一意に決まったのは、固定セクターの状態が少なく打ち消しが無かったためと考えられる【予想】。
- 結論：E と C の分離には、状態の数（指数ではない）か Ĩ_int の作用の幾何的な決定が要る。AgSc が「refined の開弦には第一量子化の定義がまだ無い」と書いているのは、この分離の不定性に当たる。

## 4. 正値性の判定は E の不定性に影響されない方向で行える【導出】
- E は p₂ 型の方向にしか入らないので、冪和の p₁ⁿ 方向（2 箱では ĝ_(2) + ĝ_(1,1)）と、奇数のセクター（3 箱、E = 0）は E によらない。これらは凍結した状態 C と、対の寄与 ½f^{cov} の一部だけで決まる。
- これらの方向でも、普遍因子 (𝐭² − 1)(𝐚² − 𝐪²) で割った商の符号は大部分のブロックで混在する【計算：trefoil の 2 箱の和 5/10、T(2,5) の 2 箱の和 6/18、trefoil の 3 箱 2/15, 3/14, 2/13（ブロックごとにそろう数/全数）】。
- したがって、正値性が見えない原因は E の不定性ではなく、**凍結した状態（向き付けられない状態）の多重項の基底がまだ正しくないこと**にある。

## 5. 凍結した状態の多重項：手がかり
- AgSc §4 の強い整数性の導出：向き付けられた種数 g（偶数）の寄与 N^g (q^{1/2} − q^{−1/2})^{2g−2} と組になる c = 1、種数 g/2 の寄与は (q − q^{−1})^{g−1} = [(q^{1/2} − q^{−1/2})(q^{1/2} + q^{−1/2})]^{g−1}。
  - **訂正（2026-10-20、§8）**：この「差 × 和」は取っ手一つの因子ではない。類 β/2 の c = 1 の寄与を d を倍にして（ψ²）β の向き付けられた寄与と並べたときに出る ψ²z = z(q²) である。
  - c = 1 の寄与そのものは、AgSc (3.1) のとおり同じ変数で z^{2g}（BFM、Mariño と同じ）。
  - Piazzalunga–Uranga 1405.6019 §4.2（TeX で確認）によれば、Ĩ で不変な被覆の取っ手一つの捻ったトレース t⁺ − t⁻ は、同じ変数で z 一つ（−2 sinh）である。
- refined では、向き付けられた取っ手の因子は G = z_q z_t（KN）。凍結した状態の取っ手の因子の refined 版は、t = q で z² に戻るもの（Mariño の c = 1 は z^{2g}）でなければならない。
- 検査する仮定【仮説】：C = Σ_β ν^β [A_β(G, w) + X B_β(G, w)]（A, B は σ 対称、X は t = q で z になる c = 2 の余分の因子）。結果は progress.md 続き 37。

## 6. 凍結した状態の展開の仮定の検査【計算、scripts/rk_b_frozen_ansatz.py、logs/refined_kauffman/b_frozen_ansatz*.log】
V の偶奇で c = 1（偶）と c = 2（奇）に分け、c = 1 部分が Z[G, w^±] に入るか、c = 2 部分が X × Z[G, w^±]（X ∈ {z_q, z_t, (z_q ± z_t)/2}）に入るかを調べた。
| 対象 | c = 1 部分 | c = 2 部分 ÷ X |
|---|---|---|
| [1] T(2,3), T(2,5)（g^true） | G 展開できる（§8 の判定式どおり） | どの X でも割り切れない（c = 2 = −(𝐚² − 𝐪²)(𝐭² − 1) × 正、t = q で 0） |
| 2 箱の ĝ_(2) + ĝ_(1,1)（T(2,3), T(2,5)） | G 展開できない（σ 対称でない） | どの X でも割り切れない |
| 3 箱の ĝ_R（trefoil、E = 0） | G 展開できない | どの X でも割り切れない |
結論：凍結した状態の多重項の基底は、向き付けられた状態の G（KN）をそのまま使う形ではない。[1] の c = 2 で余分の因子の役をしているのは z ではなく普遍因子 (𝐭² − 1)(𝐚² − 𝐪²) である。多箱の c = 1 部分は G でも書けないので、向き付けられない取っ手の因子（§5 の「差 × 和」の refined 版）を幾何から決める必要がある【未解決】。

## 7. まとめ
- 【導出】g = ½E/(1 + t) + C は、商の一粒子状態の分類（対・不変・凍結）と AgSc のモードの射影から従う。E は不変な状態の Ĩ の符号付きの和、C は凍結した状態の和。
- 【導出】E と C の分離は指数からは決まらない（凍結した状態 ≡ 連続する二つのモードの不変な状態の組）。決めるには状態の数か Ĩ_int の幾何的な決定が要る。
- 【導出】正値性の判定は、E を含まない方向（p₁ⁿ と奇数のセクター）で E の不定性によらずに行える。そこでの符号の混在は、凍結した状態の多重項の基底がまだ正しくないことを示す。
- 【未解決】凍結した状態（向き付けられない面）の refined の取っ手の因子。unrefined では、Ĩ で不変な被覆の取っ手一つあたり z 一つで、反正則な対合の捻ったトレースに当たる（§5 の訂正、PU）。refined 版は G でも z_q, z_t の単項式倍でもない。

## 8. 閉弦の refined orientifold との照合（2026-10-20）【計算、scripts/rk_b_closed_orientifold.py】
出典：AM = Avetisyan–Mkrtchyan 2205.12832 §3（TeX で確認。変数 (q, t)_AM = (q^{1/2}, t^{1/2})）、AgSc §6、PU = Piazzalunga–Uranga 1405.6019 §4.2（いずれも TeX で確認）。

### 8.1 全 d の形での分解
- (A) D_N の積表示から −log Z の d 番目を厳密に作り、AgSc §6 の 3 項を引いた。N = 2..7 で、残りは N の 1 次式（古典的な項と定数写像）だけで、t^N を含む項はすべて一致する【計算】。
  - 3 項：½ 向き付けられた項、RP² の項 x/z_q、−½ の (t^{1/2} + t^{−1/2}) の項。
- (B) AM の D 型（C 型は c = 1 の符号だけが違う）の式は、次の和に n ごとの有理式として恒等的に等しい【計算】。
  - 奇数の n の c = 1 の項：e^{nτ₁/2}/(Q^n − Q^{−n})
  - 全 n の Klein 瓶の項：(1/2n)(Q^n/T^n − T^n/Q^n) e^{nτ₂}/((Q^{2n} − Q^{−2n})(T^n + T^{−n}))
  - 恒等式の右辺は、全 n の凍結した状態の項 e^{nτ₁/2}/(Q^n − Q^{−n}) と、不変な状態の項 −½ e^{nτ₀}/((Q^n − Q^{−n})(T^n + T^{−n})) の和である。
  - 後者は ½F_A と合わせて、z₂ の偶数のモードだけの e^{nτ₀}T^{−n}/((Q^n − Q^{−n})(T^{2n} − T^{−2n}))（AgSc (3.13) の形）になる。
- 結論【導出＋計算】：閉弦の refined SO(2N) は §2 の分類そのもの（P¹ は Ĩ で不変な状態で ε = +1、RP² は凍結した状態一つ）で、g = ½E/(1 + t) + C が厳密に成り立つ。
  - AM の「Klein 瓶（c = 2）の寄与」と、その分子 q/t − t/q は、独立な多重項ではない。奇数の d で整理したときの −½ψ²C と ½E/(1 + t) の差で、E ≠ ψ²C であることから出る。
  - AM の 3 つの Kähler 変数（τ₀, τ₁, τ₂）のうち τ₂ は独立でない：e^{τ₂} = e^{τ₁}/Q_AM（τ₁ − τ₂ = g_s/2）。E と C の 2 つの電荷（e^{τ₀} と e^{τ₁/2}）から決まる。
- AM と AgSc の規約：凍結した状態の電荷 x と向き付けられた状態の電荷 Q0 の比は、AM で x²/Q0 = w、AgSc で x²/Q0 = w^{−1}（w = (q/t)^{1/2}）。(q, t, Q) → (q^{−1}, t^{−1}, Q^{−1}) と全体の符号（log Z と −log Z）で移り合う。

### 8.2 開弦への含意
- 閉弦では凍結した状態は (q, t) の単項式一つで、σ（q → t^{−1}, t → q^{−1}）で閉じない。AgSc の「orientifold は SU(2)_L × SU(2)_R を U(1)_1 × U(1)_2 に壊し、凍結した状態は完全なスピン多重項をなさなくてよい」に合う。開弦の多箱の c = 1 部分が σ 対称でない（§6）ことも、同じ性質と考えられる【予想】。
- 閉弦の場合、E と C の分離が一意なのは、状態が P¹ と RP² の二つだけで打ち消しがないためである。開弦の E が決まらない問題（§3）は、閉弦の照合からは解けない。
- Adams 型の対応（E と ψ²C の比が単項式と簡単な因子になる）は、閉弦の E = Q0、ψ²C = x(q², t², Q²) では成り立つ。開弦では、続き 35 のとおり ν² (q/t)^{j/2}（|j| ≤ 2）のずれでも成り立たない。
- PU の M 理論の解釈：凍結した状態の数は orientifold の偶奇で重みを付けた差 ñ = n⁺ − n⁻（real BPS 不変量）である。[1] の c = 2 部分の因子 (𝐭² − 1) = −𝐭(w − w^{−1})（𝐭 = −w）は、Ĩ が成分に ± で働く SU(2)_R の二重項の捻ったトレースの形をしている【予想】。この解釈では、正値性は差 ñ ではなく n⁺, n⁻ のそれぞれについて問うべきで、指数からは分けられない（§3 と同じ形の不定性）。
- refined の取っ手：G = z_q z_t = T₊T₋。
  - T₊ = (q^{1/4} − q^{−1/4})(t^{1/4} + t^{−1/4})、T₋ = (t^{1/4} − t^{−1/4})(q^{1/4} + q^{−1/4})（V, W で T_± = (V − V^{−1}) ± (W − W^{−1})）。
  - t = q では T_± = z（PU の捻ったトレース）、σ で T₊ ↔ −T₋。
  - ただし Z[w^±][T₊, T₋] は Z[w^±][G] ⊕ (V − V^{−1})Z[w^±][G] と同じ環で、σ 対称でない c = 1 部分を展開できるようにはならない【導出】。

### 8.3 開弦の判定式のずれの向き【計算、scripts/rk_b_shift_direction.py、logs/refined_kauffman/b_shift_direction.log】
- ĝ − ĝ|_{t=q}(ν → ν w^k) が (q − t)(ν² − t) で割り切れる k を −3..3 で走査した。[1]（T(2,3), T(2,5)）、2 箱の ĝ_(2), ĝ_(1,1), 和（T(2,3), T(2,5)）、3 箱の ĝ_R（trefoil）のすべてで k = +1 だけが割り切れる。
- 閉弦との比較（保留）：
  - 閉弦（AgSc）では、凍結した状態と向き付けられた状態の比が x²/Q0 = w^{−1} になる。
  - 開弦では、凍結した状態の変数 ν~ = νw と被覆の変数 𝐚_U² = ν²w^{−1} の比が ν~²/𝐚_U² = w³ になる。
  - 両者は一致しない。開弦の規格化（一様な規格化の (t/q)^{δ/2}）と、開弦・閉弦の変数の対応（ν² と Q か、ν^{−2} と Q か）がまだ決まっていないので、比較の結論は保留する。
