## A. 査読（hep-th の査読者役：内容・正しさ・格付け・新規性）

### 【重大】

1. **「整数 Laurent 多項式」の範囲が要旨・序論・Table 1 と本文で食い違う。** 要旨 (ii)、intro「The crosscap parts are integer Laurent polynomials」、Table 1 caption「for |R|=2: 2g is integer」に対し、本文（§6.3）では 2 箱・4 箱の g_R の分母は 2×単項式×(1+t) で、整数なのは g_(2)+g_(1,1)、(1+t)(g_(2)−g_(1,1))、2(1+t)g_R（4 箱）だけ。Table 1 の「2g」は 2(1+t)g が正しいはず。Conjecture 6.8（conj:structure）も「in every color … integer Laurent polynomial」と書くが、|R| が偶数のとき ĝ_R 自身は Laurent でない（§6.5 では (1+t)ĝ_R を調べている）。→ 「|R| 奇数では g_R, ĝ_R が整数 Laurent、偶数では (1+t) を掛けた組合せが整数 Laurent（Prop. 3.2 の予言どおり）」に統一。2 箱の ĝ_(2), ĝ_(1,1) が Laurent かどうかも明記。
2. **Conjecture 5.5 の (c=2) 条件は、非 refined の c=2 不変量が消えることを含む。** (c=2) part = −(𝐚²−𝐪²)(𝐭²−1)×positive は t=q で c=2 部分が消えることを要求する。これはトーラス結び目の基本表現で N^{c=2}=0 だから成り立つ性質で、一般の結び目（ケーブル）では N^{c=2}≠0 なので「(𝐭²−1) で割れない」のは当然であり、正値性の反証にならない。→ criterion を「c=2 部分の refined part = g^{c=2} − g^{c=2}|_{t=q}(λ→λ̃) が (𝐚²−𝐪²)(𝐭²−1)×符号のそろった多項式」の形に書き直し、ケーブル・T(3,4) で本当に破れているもの（c=1 の σ 非対称性）と区別する。§9.6、§10.1、intro、abstract (iii) も同様。
3. **f_R の定義（eq:Z, eq:Zexpand）が再現可能な形でない。** (a) (eq:Z) の Z̃(Y) に (∏y_α)^N が無いのに (eq:Zexpand) にはある。付けないと log Z̃ を Schur 関数で展開できず、付けると定数項 (−1)^N の処理が要る。(b) f_R は無限個の probe で定義されるはずだが (eq:Zexpand) は λ⊆m^N の有限和で、m に関する安定性が述べられていない。(c) 「U=t^N を形式変数として扱える」根拠は §4.1 の c_{2j}(n) の式で、これは予想（4 つの有理点、j≤5, n≤30）。定義の基礎が予想に依ることが §2 から読めない。→ Z̃ の定義に (∏y)^N と定数項の正規化を入れ、f_R が m≥ℓ(R) で m に依らないことを含めて定義し、形式変数 U の扱いを定理の引用か Hypothesis で裏付ける。Prop. 2.8 の証明と整合させる。
4. **E を決める条件 (ii) が場所ごとに違い、正当化されていない。** §4.4「(ii) C equals the value of [Marino09] at t=q」、§9.4「(ii) E=−(1+q)(g_[1](q²,λ²)+1) at t=q」、§8「(i)(ii) of §4」。(ii) の中身は「t=q で C が Mariño の odd-d 不変量に一致し、½E/(1+t) が Adams 補正に一致する」という実質的な仮説で、Prop. 3.7 の不定性をこの仮説で固定している。「+1」の由来も書かれていない。→ Hypothesis「C|_{t=q}=g^{odd}」を立て、g_{ab}=g^{odd}_{ab}−½g^{odd}_{a/2,b/2}(x²) から (ii) の具体形を導出し、全箇所で同じ式を参照。
5. **先行研究の引用漏れ。** Sinha–Vafa（SO/Sp の large N duality とオリエンティフォールド、hep-th/0012136）、Gukov–Walcher「Matrix factorizations and Kauffman homology」（hep-th/0512298：Kauffman ホモロジーと T(2,2m+1) の Kauffman 超多項式）、Gukov–Stošić（1112.0030：SO/Sp と composite）。特に Gukov–Walcher の超多項式は 2 ストランドで正値なので、§5 の「criterion が 2 ストランドに特有」と §9.1「refined SO 不変量自身は bold 変数で正でない」を直接比較すべき（bold 変数の選び方が違う可能性）。Sp(N)=SO(−N) は Cvitanović、Mkrtchyan–Veselov を引用。→ Background に 1 段落、§5 と §9.1 で Kauffman 超多項式との関係を述べる。一致すれば §5 の新規性は「BPS レベルでの c=1,2 分解と G 展開」に限定される。（注：文献情報は原典で確認してから書く。）
6. **Prop. 8.7（prop:rows）に証明がなく、記号が未定義。** 「row」、κ（x=W_adj+κ−W²）、s、r が未定義。A=R²+(q−1)(t−1)G は G の定義なので、命題の内容は「x の定義と U(N_A) の次元因子から N の式が代数的に従う」こと。その導出を書く。「N is Laurent iff G is Laurent」は第 1 項の分母が 1−x^{2δ}R(qx)² を割ること（x=1,1/t,1/(qt) で x^{2δ}R(qx)²=1）を要し、reduced 超多項式の特殊化の性質から出るはずなので明記。また δ は「超多項式の δ-degree」として導入されるが thick な結び目では超多項式は δ について斉次でない。本文の値はすべて Seifert 種数 (r−1)(s−1)/2 なので、δ＝種数と定義し直す。
