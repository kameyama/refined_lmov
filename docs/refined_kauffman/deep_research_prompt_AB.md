## 指示

あなたは、位相的弦理論・結び目ホモロジー・Macdonald 理論の文献に通じた研究者として、次の 2 つの未解決の問題について文献調査を行い、報告書を書いてください。計算や推測ではなく、**文献に書かれていることの特定と、その問題への当てはめ方の検討**が目的です。

### 0. 背景（この研究の設定）

対象は、SO(2N) の refined Chern–Simons 理論（Aganagic–Schaeffer, arXiv:1202.4456, "Orientifolds and the refined topological string"）の結び目不変量の large N 双対、すなわち Mariño（arXiv:0904.1088, "String theory and the Kauffman polynomial"）の Kauffman 多項式の large N 双対の refined 版です。

記号：
- q, t は refined CS の変数（Ω 背景の 2 つのパラメータ）。t = q で unrefined に戻る。
- N は D_N のランク。U = t^N、ν = U t^{−1/2}（Mariño の ν）、ν̃ = ν (q/t)^{1/2}。
- 太字の変数（DGR の規約、Aganagic–Schaeffer と同じ）：𝐪 = t^{1/2}, 𝐭 = −(q/t)^{1/2}, 𝐚 = ν。
- z_q = q^{1/2} − q^{−1/2}, z_t = t^{1/2} − t^{−1/2}, G = z_q z_t。
- σ：q ↦ t^{−1}, t ↦ q^{−1}（ν は固定）。G は σ で不変。

設定：
- 結び目 K の probe は M5 brane で、Aganagic–Schaeffer §3 の M 理論の定義で、orientifold の作用 Ĩ は X（Calabi–Yau）上の反正則な対合 I と、時空の z₂ → −z₂ の組である。probe は z₂ 平面を張る（開弦の分母が 1/(1−t) であることによる。いわゆる t-brane）。被覆空間には L_K と像 I(L_K) の 2 枚の brane がある。
- 自由エネルギー：双対 Cauchy 核（Koornwinder の Mimachi 恒等式）で生成関数 Z̃(Y) = ⟨Π(1 − y x_i)(1 − y x_i^{−1})⟩_{SO(2N)} を作り、log Z̃ = Σ_d (1/d) Σ_R f_R(q^d, t^d, U^d) s_R(Y^d) と展開する。被覆 U(2N−1) でも同じ核で f_R^{cov} を定める。クロスキャップ部分は g_R = f_R − ½ f_R^{cov}（全 d の定義）。reformulated 不変量は ĝ = M(q^{−1})^{−1} g（M は Mariño の M_{RS}、t_M = q^{1/2}）。

この研究で確立していること（すべて計算機で確認済み、trefoil の 2 箱・3 箱と T(2,5) の 2 箱を一般の N で）：
1. **全 d の構造**（導出済み）：被覆の一粒子 BPS 状態を、Ĩ で入れ替わる対（全モードの塔 1/(1−t)）、Ĩ で不変な状態（Ĩψ = εψ、ε = ±1、(−1)^l ε = +1 のモードだけ：Σ t^l = ½[1/(1−t) + ε/(1+t)]）、z₂ = 0 に凍結した状態（モードの塔なし）に分けると
   g = ½ E/(1+t) + C、E = Σ_{不変} ε m、C = Σ_{凍結} m
   （m は状態の電荷の単項式）。E は Ĩ で自分に移るセクター（brane と image を同数もつセクター。冪和の p₂ 型の方向）にしか現れない。
2. **E と C の分離は指数からは決まらない**（導出済み）：E → E + 2(1+t)X, C → C − X で g は不変。状態の言葉では「凍結した状態 m ＋ Ĩ で入れ替わる対 {m}, {mt}」と「ε = +1 の不変な状態 m, m, mt, mt」が、商の指数 f と被覆の指数 f^{cov} の両方で区別できない。
3. **整数性**：大きな N のクロスキャップ部分 g_R は整数係数の Laurent 多項式で、(1+t) の極は p₂ 方向にだけ現れる（3 箱、すなわち奇数のセクターには (1+t) の極が無い）。
4. **普遍因子**：refined だけの部分 ĝ − ĝ|_{t=q}(ν → ν̃) は、[1]・2 箱・3 箱・Hopf 絡み目のすべてで (𝐭² − 1)(𝐚² − 𝐪²) で割り切れる。
5. **[1] の正値性**：トーラス結び目 T(2,2m+1)（m ≤ 5）の [1] では、c=1 部分（v = (qt)^{1/2} の整数冪の部分）が σ 対称で G の多項式に展開でき、ν^β のブロックごとに符号がそろうか「(𝐭²−1) × 符号のそろった多項式」になる。c=2 部分は −(𝐚²−𝐪²)(𝐭²−1) × 正の多項式。
6. **多箱での破れ**：2 箱・3 箱では c=1 部分が σ 対称でなく G に展開できない。普遍因子で割った商の 𝐚 ブロックの符号は大部分で混在する（trefoil の 2 箱の和で 10 ブロック中 5、3 箱で 15 中 2 など）。被覆（向き付けられた部分）のうち brane–brane のセクターは Kameyama–Nawata（arXiv:1703.05408）の G 展開と正値性をそのまま満たし、破れは brane–image のセクターとクロスキャップに限られる。brane–image のセクターもクロスキャップと同じ因子 (𝐭²−1) をもつ。

既に試して失敗した方法（同じ提案は不要）：
- 自由エネルギーの右辺の基底の取り替え（Hall–Littlewood、Macdonald P/Q、modified Macdonald）。
- 二次量子化の積表示の指数の符号を見ること。
- G = T₊T₋（T_± = (V − V^{−1}) ± (W − W^{−1})、V = (qt)^{1/4}, W = (q/t)^{1/4}）の因子を使う展開：σ 対称でない部分は表せない。
- E = P − 2Q（P は固定セクターの指数、Q は Ĩ の固有値 −1 の状態の部分和）の整数計画、Adams 型の E = F·(ψ²[g_[1]] + 1)、固定セクターの多重項ごとの捻ったトレース（q 平面・t 平面の π 回転、単項式ごとの符号）：trefoil は解けるが規則性がなく、T(2,5) では指数の上限の中に解が無い（打ち消しで見えない状態が要る）。
- 被覆の composite (adjoint) の値を正の Poincaré 多項式として読むこと：Cherednik–Elliot（arXiv:1503.01441）の序論のとおり、composite の DAHA 超多項式は正値性をもたない。

既に読んだ文献（再度の要約は不要。これらの中の、ここに書いていない箇所の指摘は歓迎）：
- Aganagic–Schaeffer 1202.4456（§3 の M 理論の定義と積表示 (3.13)、§4 の強い整数性、§6 の大きな N の閉弦）
- Avetisyan–Mkrtchyan 2205.12832（閉弦の D/C/B 型の GV 型展開、Klein 瓶の項、Kähler 変数の三重化）
- Piazzalunga–Uranga 1405.6019（real topological string の M 理論の解釈、不変な状態の捻ったトレース t⁺ − t⁻、real BPS 不変量 n⁺ − n⁻）
- Bouchard–Florea–Mariño hep-th/0405083, hep-th/0411227、Walcher 0705.4098（未確認の番号。"Evidence for tadpole cancellation in the topological string"）
- Kameyama–Nawata 1703.05408、Cherednik 1111.6195、Cherednik–Elliot 1503.01441、Kim–Wei 2201.12264（ON 面の refined 頂点。向き付けられない面は数えない）

### 1. 問題 A：凍結した状態（向き付けられない面）の refined の多重項

unrefined では、クロスキャップ c の種数 g の曲線の寄与は z^{2g−2+c} 型の冪で、取っ手一つあたり z² = (q^{1/2} − q^{−1/2})² である（Mariño、BFM）。refined の向き付けられた開弦では、Kameyama–Nawata のとおり取っ手一つあたり G = z_q z_t で、SU(2)_L × SU(2)_R の多重項の指標（(q/t)^{J} の因子）が付く。

問い：
- A1. refined の設定で、**向き付けられない曲線（RP² や Möbius の帯、Klein 瓶）に M2 brane が巻き付いた BPS 状態**の多重項の構造（Jacobian のコホモロジーへの反正則対合の作用、SU(2)_L × SU(2)_R から U(1) × U(1) への破れ方、取っ手一つあたりの因子の refined 版）を、物理または数学の側から扱った文献はあるか。特に、orientifold のもとでの Lefschetz 作用（sl₂ 作用）の捻ったトレース、あるいは「real Gopakumar–Vafa 不変量の refined 版」を定義した文献を探してほしい。
- A2. Aganagic–Schaeffer が「refined の開弦には第一量子化の定義がまだ無い」と書いて以降（2012 年以降）、orientifold の refined 位相的弦の開弦の BPS 展開（第一量子化の形）を提案した文献はあるか。閉弦についてでもよい（例：Avetisyan–Mkrtchyan の後続、refined の real topological vertex、O5/ON 面の refined 頂点で向き付けられない面を数えるもの）。
- A3. 数学の側：Koornwinder 多項式・D 型 Macdonald 多項式の環で、「σ: q ↦ t^{−1}, t ↦ q^{−1} で対称でない」量を自然に展開する基底（例：(q, t) と (t, q) の両方を含む対称性、Koornwinder の 4 つの境界パラメータに付随する基底）は知られているか。refined CS の SO 側に「super-duality」に当たる対称性が無いことと整合する展開の枠組みがあれば指摘してほしい。
- A4. Gukov–Walcher（hep-th/0512298）の Kauffman ホモロジー、Nawata–Ramadevi–Zodinmawia（1310.2240）の彩色 Kauffman ホモロジーは、Aganagic–Schaeffer によれば refined SO の値と変数変換では結べない。それ以降に、refined SO(2N) CS と Kauffman ホモロジーの関係を論じた文献はあるか。

### 2. 問題 B：Ĩ で不変な状態の数 E の決定

E は「Ĩ で不変な状態の、Ĩ の固有値 ε の符号付きの和」で、指数からは E の 2(1+t) を法とした類しか決まらない。Hopf 絡み目では、(2,2) と (2,4) のセクターで、固定セクターの指数（被覆を brane 側と image 側の probe に分けて取り出したもの）を状態の和とみなす仮定と、t = −1 および t = q の条件から一意に決まり、積の形
E_22 = −z_q (z_q⁺)² (ν̃ − ν̃^{−1})(t q^{−1/2} ν̃ + q^{1/2} ν̃^{−1})、z_q⁺ = q^{1/2} + q^{−1/2}
になる（固定セクターの指数 P_22 = z_q³(ν̃ − ν̃^{−1})(t q^{−1/2}ν̃ − q^{1/2}ν̃^{−1}) と比べると、差の因子 z_q² が和の因子 −(z_q⁺)² に替わり、第 2 因子の符号が反転している）。結び目では同じ方法が働かない（指数には打ち消しがあり、E の状態は指数の台に収まらない）。

問い：
- B1. 「向き付けられた M2 brane（被覆の環状の弦、商では境界を一つもつ Möbius の帯）の BPS 状態への orientifold 作用 Ĩ の固有値」を、モジュライ空間の幾何（M2 のモジュライ空間の Jacobian、あるいは Hilbert scheme / 箙のモジュライ上の対合）から決める文献はあるか。Piazzalunga–Uranga の t⁺ − t⁻ の議論を開弦（境界をもつ曲線）に広げたものがあれば最優先。
- B2. 境界のゼロモードについて、Ĩ が二つの境界（L と I(L)）を入れ替えるときの捻ったトレースが「差 z_q が和 z_q⁺ になる」という形になることを示す、または用いる文献はあるか（この研究では Hopf と結び目の両方で境界の因子が和になることを確認している）。
- B3. 第二量子化の側：Aganagic–Schaeffer の積表示 Z = Π(1 − q^{m₁+l₁} t^{m₂+2l₂} Q^β)^{M} Π(1 − q^{m₁+l₁} t^{m₂} Q^β)^{M̃} の開弦版で、整数 M（向き付けられた、Ĩ 不変）と M̃（凍結）を**独立に**決める原理（例：モジュライ空間の固定点の数と交叉形式、Witten 指数以外の保護された量、refined の壁越え）を論じた文献はあるか。
- B4. 数学の側：DAHA や楕円 Hall 代数で、A 型の composite 表現（annulus の skein、Cherednik–Elliot）の refined 不変量を「brane と image の入れ替え」に当たる対合で分解し、固有空間ごとの不変量（正値性をもちうるもの）を定義した文献はあるか。Queffelec–Rose–Sartori の環状 HOMFLY ホモロジー（1802.04131）や、逆向きの 2 本のケーブルの Khovanov–Rozansky ホモロジーで、トーラス結び目の composite（adjoint）彩色の具体的な計算例があるか。

### 3. 報告の形式

- 日本語で書く。専門用語と文献の題名は原語のままでよい。
- 各問いについて、(a) 該当する文献（arXiv 番号、著者、題名、該当する節・式番号）、(b) その文献が何を主張しているか（この問題への当てはめ方を含む）、(c) 確認の度合い（原典の本文で確認／抄録のみ／二次情報）を明記する。
- 見つからなかった問いは「見つからなかった」と書き、代わりに最も近い文献と、何が足りないかを書く。
- 書誌（arXiv 番号、著者、題名、掲載誌）は確認できたものだけを書き、確認できないものは「未確認」と明記する。推測で番号や題名を補わない。
- 文献の主張とあなたの解釈を分けて書く。解釈には「解釈」と付ける。
- 最後に、問題 A と B のそれぞれについて、**次に読むべき文献 3 件以内**と、**この研究の計算で検証できる具体的な予言があればその式**を挙げる。
