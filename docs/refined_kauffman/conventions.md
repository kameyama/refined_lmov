## refined（双対 Cauchy 型、K2'、2026-10-14）
- ホロノミー側：AS の D_N Macdonald = Koornwinder K_λ(x; q,t; 1,−1,q^{1/2},−q^{1/2})、unknot は x = t^ρ（x_i = t^{N−i}）での評価。U = t^N。
- probe 側（probe m 個、変数 y_1..y_m）：K_{λ'}(y; t,q; 1,−1,q^{1/2},−q^{1/2})。核は Mimachi の双対 Cauchy 恒等式 Π_{i,j} x_i^{−1}(1 − x_i y_j)(1 − x_i/y_j)。
- virtual 正規化：Z~ := (Π_j y_j)^N Z。probe 側の基底は (Π y_j)^N K_{N^m−λ}(y) = Rains の virtual Koornwinder \hat K_λ(y; t,q, T = U)。Z~ は y の多項式で、U を形式変数として log を展開する。
- 自由エネルギー：log Z~ = Σ L_{a…} y^a…、f = Möbius 反転（f_{ab} = Σ_{d|(a,b)} (μ(d)/d) L_{a/d,b/d}(q^d,t^d,U^d)）。
- Kähler 変数：ν = (U²/t)^{1/2}（Mariño の ν、Q = U²/t）。Hopf 絡み目では ν~ = ν (q/t)^{1/2} = U q^{1/2}/t が現れる。z_q = q^{1/2} − q^{−1/2}。

## 一様な規格化（2026-10-19、report.md §6、以後の既定）
- torus 結び目 T(2,2m+1) の data（KN の (N1)+(N2) 規格化の reduced 不変量 R_μ、U(n) の分割 μ）に対し、W_μ = (t/q)^{δ|μ|/2} R_μ P_μ(t^ρ)（δ = m）を使う。
  一般に δ は data の行列式表現のずれ R_det(U(n)) = (q/t)^{δ n/2} から決まり、調べた結び目（T(2,3), T(2,5), T(2,7)、二重ツイスト結び目 4_1, 5_2, 6_1, 7_2, 7_4, 8_1, 8_3）では [1] の superpolynomial の δ 次数 𝐚 + 𝐪/2 − 𝐭 に等しい（種数ではない）。
  理由：この規格化だけが行列式のずらし μ → μ + 1^n と荷電共役で不変で、行列式表現が 1 になる（data は R_det = (q/t)^{δ n/2}）【計算】。
- 固定 N では、SO 側（SU(4)・SU(2)² の分割）・被覆側（U(N_A) の分割、composite は移した分割）とも framing の単項式はすべて 1。trefoil（δ = 1）と T(2,5)（δ = 2）で、各表現の単項式を (t/q)^{β/2} に替える走査が β = δ|μ| を一意に選ぶことを確認した（2026-10-19）。
- 大きな N の [1]：W_SO = Z_V·T_[1]^{−2(2m+1)}·unknot、被覆は (t/q)^{δ/2}·½h^{ref}（½h^{ref} は下の K3' の式）。クロスキャップ部分は (t/q)^{δ/2} g^{ref}_[1]。
- 以下の「固定 N の framing」「trefoil（K3'）」の単項式は data の規格化での記述で、一様な規格化と (t/q) の冪だけ違う（履歴として残す）。

## 固定 N の framing（2026-10-19、report.md §6、data の規格化での記述）
- 固定 N（N = 2, 3）の trefoil では W_μ = m_μ R_μ K_μ(t^ρ)（R は data の鏡像）とし、単項式 m_μ を次の 2 条件で決める。
  (i) N 依存の極の打ち消し（m_μ は極の上でしか決まらない）、(ii) t = q で m_μ = 1。
  理由：data は t = q で framing 0 の HOMFLY に合わせてある。Spin(6) = SU(4)、SO(4) = SU(2)²、被覆 U(N_A) の framing 0 の不変量はそれぞれ一致する。
- 結果：SO 側は m_(1,1) = (t/q)^{N−1}、m_(2) = (t/q)^2（走査で一意）、1 probe の m_2 = (t/q)^{N−1}、m_3 = m_1、m_3' = (t/q)^2 m_1。被覆は [1], [1,1], [2] で 1、随伴で (t/q)^{N_A/2}。荷電共役 W_μ̄ = W_μ。
- 3 箱（2026-10-19）：SO 側の新しい表現（SU(4) の [3,3], [3,2,1]、SU(2)² の [3]⊗[3], [3]⊗[1]）も (i)(ii) で一意に決まり、m_(1) に連動する。被覆の composite (2;1), (11;1) は (t/q)^{N_A/2}。被覆は U(N_A) なので、ℓ(μ) = N_A の分割（U(3) の [1,1,1]）も data の U(N_A) の値を使う（SU に落とさない）。
- m_(1) = t/q のとき、SO 側の単項式は data の A 型の分割 μ についてすべて (t/q)^{|μ|/2} になる（|R| ≤ 3、N = 2, 3）。
- hatted の判定：SO 側の f̂^{SO} = M^{-1}(q^{-1}) f^{SO}（Schur 基底）が整数 Laurent か。冪和基底では f_ρ = φ_ρ f̂_ρ、φ_ρ = Σ_σ χ_σ(ρ) B_σ(q^{−1/2})。
- m_(1)（ベクトル）は固定 N の極に関わらず、(i)(ii) では決まらない。K3' の値 (t/q)^{1/2}（大きな N の [1] の Laurent 性）と、hatted の値 t/q（固定 N の 2 箱・3 箱で SO の f̂ が整数 Laurent、p_d 方向の ĝ が Laurent、framing が一様）が両立しない。【2026-10-19 に解決】被覆の [1] の framing も (t/q)^{1/2} にすると両立する（一様な規格化）。K3' が決めていたのは比である。

## クロスキャップ展開（K4'、2026-10-14）
- 被覆：U(N_A) refined CS、A = ν² = U²/t = t^{N_A}（N_A = 2N_D − 1）、核 Π_i(1 − y x_i)(1 − y/x_i)（fermionic、composite）。oriented 部分 = ½F^{cov}。
- クロスキャップ部分（2026-10-17 に全 d の定義へ変更、report.md §7）：g_{ab} := f_{ab} − ½ f^{cov}_{ab}（f, f^{cov} は全 d の Möbius 反転）。第二量子化（AS §3）の構造 g = ½E/(1+t) + C（E：Ĩ で固定される oriented 状態、(偶,偶) のみ；C：凍結した unoriented 状態）をもち、2(1+t)g は整数 Laurent。
  Mariño 型の Σ_{d 奇数} の定義 g^{odd}_{ab} = L_{ab} − ½L^{cov}_{ab} − Σ_{d 奇数>1}(1/d) g^{odd}_{a/d,b/d}(x^d) とは g_{ab} = g^{odd}_{ab} − ½ g^{odd}_{a/2,b/2}(x²) で結ばれ、t = q では g^{odd} = Mariño の ĝ。refined では g^{odd} の (偶,偶) に (1+t^{d/2}) の分母が残るので、整数性の判定には全 d の g（と f 自身）を使う。
  理由：refined の軌道体では z₂ → −z₂ が probe（t-brane）に沿い、固定される oriented 状態のモード射影が ½/(1+t) を生む（閉弦では AS §7 の (t^{d/2}+t^{−d/2}) の項）。E と C の分離は未確定（E(t=−1) だけが分離に依らない）。
  E の決め方（2026-10-18）：E = P − 2Q（P = (1−t)f^{cov}_{固定セクター}、Q は Ĩ 固有値 −1 の状態の部分和）、t = −1 で E = 2(1+t)g、t = q で C = ĝ（Mariño）。(2,2),(2,4) で一意、(4,4) は未確定（report.md §7）。
- 変数：z_q = q^{1/2}−q^{−1/2}、z_t = t^{1/2}−t^{−1/2}、G = z_q z_t、w = (q/t)^{1/2}、ν~ = ν w。DGR：𝐪 = t^{1/2}、𝐭 = −w、𝐚 = ν、ν~ = −𝐚𝐭。
