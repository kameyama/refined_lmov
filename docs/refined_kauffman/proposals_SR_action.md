# 結び目の固定セクターの状態を (J₂, S_R) で分けるための案（2026-10-21）

主張の分類：【導出】【計算】【予想】【仮説】。記号は theory_orientifold_index.md §11 に従う（Ĩ = I_X ⊗ e^{iπJ₂}、指数の重み (−1)^F q^{J₁−S_R} t^{S_R−J₂}、固定セクター = brane–image の環状の弦、P = (1−t)x、E = Σ_{不変} ε m）。

## 0. 前提：指数の精密化では分けられない【導出】
- 指数に入れられる電荷は、保存される超電荷 Q₊、Q̄₋（KN 表 1：(2J₁, 2J₂, 2S_R) = (+1,+1,+1), (−1,−1,−1)）と可換なものに限る。可換な電荷は J₁ − S_R と S_R − J₂（と J₁ − J₂）の張る 2 次元で尽きる。J₂ 単独、S_R 単独は Q₊ と可換でない。
- したがって、KN の refined 指数に第 3 の変数を加えて J₂ と S_R を分けることはできない。必要な情報は指数ではなく、BPS 状態の空間（モジュライ空間のコホモロジー）とその上の対称性の作用（U(1)_R、Lefschetz SU(2)_r、I_X）である。KN が U(N) で「S_R は BPS 状態に自明に働く」と仮定したのはこのためで、orientifold の固定セクターではその仮定が成り立たない（§11.9 (B)）。
- 案はすべて「指数以外の入力」をどこから取るかの違いである。

## 1. unknot で分かっている構造（案の較正に使う）【導出＋計算】
- framed unknot の固定セクターは x_sec = W_adj + κ − W₁² で、T₁² = T_adj（q U²/t²）なので W_adj = T_adj^x (qn² − κ)、W₁² = T_adj^x qn² から x_sec = κ(1 − T_adj^x)。
  κ = (1 − A)(1 − q)/((1 − t)(1 − qA/t))、A = ν²。すなわち P = (1 − t)x_sec = (1 − A)(1 − q) Σ_{k<x} (qA/t)^k。
- 一意に決まった E（§11.9 (A)）は E = (1 + A)(1 + q) Σ_{k<x} (−1)^k (qA/t)^k × (−1)^x。
- 読み：κ の三つの因子がそれぞれ二状態（または塔）で、Ĩ はどれにも「励起した状態に −1」で働く。
  - (1 − q)：境界ゼロモード（§11.3）。
  - (1 − A)：D2 電荷 β = 1 の状態。I_X が (−1)^β で働く。
  - 1/(1 − qA/t) の塔：k 番目に (−1)^k。qA/t = T_adj は随伴の framing 固有値で、この塔は Macdonald の随伴の次元の極 (1 − qA/t)（report §2、composite ([1],[1]) の分母）の展開である。
- 結び目の固定セクター x = R_adj (qn² − κ) + κ − W₁² のうち、κ の部分の Ĩ の作用はこれで決まる。未知は R_adj（簡約した随伴の不変量）の状態への作用だけである。

## 2. 案

### 案 A：κ の塔の規則を組み込み、未知を R_adj の状態に限る【計算で今すぐ可能】
- x = R_adj(qn² − κ) + κ − W₁² を、R_adj に掛かる部分と κ の部分に分け、κ の塔には §1 の規則（(1−A)→(1+A)、(1−q)→(1+q)、塔に (−1)^k）を当てる。残る未知は R_adj の係数の符号 ε だけで、整数計画の変数が減る。
- 検証：trefoil・T(2,5) で (i)(ii) を満たす解があるか、一意か。Hopf では R_adj に当たる部分が単純なので、まず Hopf で規則が E_22 を再現することを確かめる。
- 見込み：中。κ の寄与と R_adj の寄与の積の構造（qn² − κ）が分離を乱すかもしれない。

### 案 B：Hilbert scheme（平面曲線の特異点）の模型と実構造【理論、文献の裏付けあり】
- トーラス結び目の L_K に境界をもつ曲線のモジュライは、Oblomkov–Shende・ORS・Diaconescu–Shende–Vafa（書誌は要確認）で平面曲線の特異点 C_{m,n} = {x^m = y^n} の Hilbert scheme に写る。refined は Gorsky–Negut（楕円 Hall 代数、本研究で検証済み）。
- トーラス結び目の U(1)_R（Seifert の U(1)）は、この模型では C* のスケーリング (x, y) → (λ^n x, λ^m y) に当たるはずで、Hilbert scheme のコホモロジーの C* 重みが S_R を与える【仮説】。Lefschetz（コホモロジー次数）が J_r を与える。
- orientifold の I'（AgSc §6）は C_{m,n} に実構造（反正則な対合）を誘導し、固定セクター（brane–image の曲線）は I' 不変な曲線、すなわち Hilbert scheme の実点に当たる【仮説】。Ĩ の固有値は、実構造の作用の固有値 × e^{iπJ₂}。
- 最初の一歩：unknot（C = 直線、Hilb^n = Sym^n C）で、§1 の E（全 framing）を C* 重みと実構造から再現する。次に Hopf。それができたら T(2,3)。
- 見込み：中〜低。必要な文献（ORS の実構造版）は無い可能性が高く、自分で構成することになる。ただし正しい道の候補として最も根拠がある。

### 案 C：四重次数のホモロジーで S_R を分ける【第 2 の研究（docs/dgr_lmov/）と接続】
- Gorsky–Gukov–Stošić の四重次数（a, q, t_r, t_c）は、KN の 3 変数の指数より一つ多い次数をもつ。KN の指数が J₁ − S_R と S_R − J₂ しか見ないのに対し、四重次数は J_r と S_R（または J₂ と S_R）を分けている可能性がある【仮説】。
- 検証の順：(1) U(N) の brane–brane セクター（KN の正値性が成り立つ）で、長方形彩色の四重次数のデータと KN の (J_r, S_R) の対応を固定する。(2) 固定セクターに要る composite（随伴）の四重次数は文献に無いので、brane–brane で固定した辞書を Hopf の固定セクター（E が既知）に当てて検査する。
- 見込み：低〜中。composite の四重次数を作る必要があり、それ自体が別の研究になる。

### 案 D：Sp(2N) の refined CS を計算して C_{c=2} を分離する【計算、中規模】
- Sp は orientifold の射影 P₋ = (1 − Ĩ)/2 で、f_Sp = ½f^{cov} − ½E/(1+t) + C'、C' = −C_{c=1} + C_{c=2}（クロスキャップ奇数の符号が反転、AM・Mariño）。
  f_SO + f_Sp − f^{cov} = 2C_{c=2}、 f_SO − f_Sp = E/(1+t) + 2C_{c=1}。
- したがって Sp のデータは C_{c=2} を厳密に分離し、E と C_{c=1} の混合を残す。E の決定には足りないが、独立な新しい条件が一つ増え、c = 2 部分の正値性（[1] で −(𝐚²−𝐪²)(𝐭²−1) × 正）を多箱で直接判定できる。
- 必要なもの：C_N 型の Koornwinder 多項式（境界パラメータを変える）と C_N 型 DAHA-Jones（本研究の DAHA の実装は D_N と GL なので、C_N の拡張が要る。Cherednik 1111.6195 は任意の被約ルート系を扱う）。AgSc は D 型しか計算していないので、Sp の refined CS の結び目不変量の値はこれが初めてになる（literature.md §4）。
- 見込み：中。実装は 1〜2 日、計算は 2 箱の一般の N で数時間。

### 案 E：B 型（SO(2N+1)）との比較【計算、案 D と同じ道具】
- AM の閉弦では、B 型は c = 1 だけで分母に (t^{n/2} + t^{−n/2}) をもつ。固定面に貼り付いた半分の M5 のため、同じ被覆の状態に D 型と違う Ĩ の偶奇が割り当てられる可能性がある。D と B で E の見え方が違えば、その差から E と C を分けられる【予想】。
- 必要なもの：B_N 型の Koornwinder と DAHA（案 D と同じ拡張）。閉弦の B 型を §2 の分類で読むことが先（theory §8 の未着手の項目）。
- 見込み：低〜中。

### 案 F：U(1)_R × Ĩ の固定点への局所化【理論、困難】
- E は不変な状態の符号付き和なので、U(1)_R の固定点（U(1)_R 不変な環状の弦）に局所化できるはず。DSV の L_K の記述から U(1)_R 不変な曲線を数え上げ、各固定点の S_R と J₂ の重みを読む。
- 見込み：低。L_K ∪ I'L_K に境界をもつ曲線の固定点の記述が無い。
