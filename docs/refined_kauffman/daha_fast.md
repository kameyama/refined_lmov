## 方法【導出】
記号は daha_dn.py・conventions.md（DAHA-Jones の節）に従う。γ̂ = τ_+^m τ_−^k（T(2m+1, 2) は k = 2）、{H} = (H·1)(q^{−ρ_k})。
現行版は {γ̂(S_μ)}（S_d = Σ_i (X_{ε_i}^d + X_{ε_i}^{−d})）を、γ̂(X_{ε_i}) = T_{i−1}⋯T_0 γ̂(X_{ε_1}) T_0⋯T_{i−1} の語を i ごとに作用させて計算していた。
重いのは (1) X の次数が 1 箱あたり 2m + 1 増えて多項式の項数が N とともに急増すること、(2) 1 回の γ̂(S_d) に T の作用が約 10N² 回要ることだった。

### 1. φ で X と Y を入れ替える（次数の伸びを 2m + 1 から k = 2 に）
Cherednik の反自己同型 φ（X_b ↦ Y_b^{−1}、Y_b ↦ X_b^{−1}、T_i ↦ T_i）は φ τ_+ φ = τ_−、φ τ_− φ = τ_+ を満たし、評価 {·} は φ で不変
（1111.6195、references/1111.6195/src/jones.tex :738–747 と :780–797 で確認）。したがって、X の対称 Laurent 多項式 H について
  {γ̂(H(X))} = {φ(γ̂(H(X)))} = {γ̂'(H(Y^{−1}))}、γ̂' := φ γ̂ φ = τ_−^m τ_+^k。
γ̂' の下で Y_{ε_1}^{−1} は
  B := γ̂'(Y_{ε_1}^{−1}) = q^{k/2} Y_{ε_1}^{−1} (q^{−m/2} X_{ε_1}^{−1} Y_{ε_1}^{−m})^k
に移る（τ_+^k(Y^{−1}) = q^{k/2} Y^{−1} X^{−k}、τ_−^m(X^{−1}) = q^{−m/2} X^{−1} Y^{−m}）。B は X の次数を k しか上げない。m は Y の冪に移り、T の作用の回数（(1 + km)(2N − 2)）にだけ効く。

### 2. 軌道の対称化（T の作用を約 10N² 回から約 (1 + km)(2N − 2) + 2N 回に）
β = ε_1（D_N では軌道 {±ε_i}、GL_N では {ε_i}）と β = −ε_1（GL_N の {−ε_i}）は minuscule。W_1 = Stab(β) の剰余類代表 w を (b, α_j) = σ の向きにたどり（σ = +1 は β = ε_1、σ = −1 は β = −ε_1）、
  Π_σ(F) := Σ_w t^{σ l(w)/2} T_w^{(σ)} F（T^{(+)} = T、T^{(−)} は各因子を T^{−1} にしたもの）
と置く。(b, α_j) = ±1 のとき T_j^{±1} X_b = t^{∓1/2} X_{s_j b}（Demazure–Lusztig の式から直接）なので Π_σ(X_β) = Σ_{b∈Wβ} X_b。
H_d := Π_σ(X_{dβ}) とおくと次が成り立つ。
- (i) 対称な G について T_j(F G) = T_j(F) G。よって、任意の f に対し Π_σ X_{dβ} e f = Π_σ(X_{dβ})·(e f) = H_d e f（e は対称化の冪等元）。アフィン Hecke 代数の多項式表現は忠実（T_w = （0 でない有理関数）·w + Bruhat 順で下の項、自己同型 w は C(X) 上で一次独立）なので、H_aff の中で H_d e = Π_σ X_{dβ} e。特に H_d は対称（d = 1 では H_1 = 軌道和）。
- (ii) φ を当てて（φ(e) = e）γ̂' を当てると（γ̂' は T_i を保つ）、e γ̂'(H_d(Y^{−1})) = e B_β^d Π_σ^φ、B_β := γ̂'(Y_β^{−1})（B_{−ε_1} = B^{−1}）。
- (iii) 対称な g では Π_σ^φ g = W^1(t^σ) g（W^1(t) = Σ_w t^{l(w)}）。γ̂'(H_d(Y^{−1})) は T_i と可換なので対称なものを対称なものに移す。X_{ε_1}, Y_{ε_1} は W_1 の T_j と可換なので B_β^d g は W_1 で対称で、e(F) = Π_σ(F)/W^1(t^σ)（e を剰余類で分解）。以上から
  **γ̂'(H_d(Y^{−1})) g = Π_σ(B_β^d g)（g は対称）。**
したがって H_ν = Π_i H_{ν_i} について γ̂'(H_ν(Y^{−1}))·1 は、対称な多項式を Π_σ(B^{ν_i} ·) で積み上げれば得られる。

### 3. 最後の一段は評価だけ
評価は ev ∘ T_j^{±1} = t^{±1/2} ev を満たす（点 q^{−ρ_k} では X_{α_j} = t^{−1} なので、Demazure–Lusztig の式の差分商の項が打ち消す）。よって
  {γ̂(H_ν(X))} = W^1(t^σ) · ev(B^{ν_1} g')、g' = γ̂'(H_{ν_2}⋯(Y^{−1}))·1、
最後の Π_σ は不要。さらに Y_{ε_1}^{−1} = T_{u_1}^{−1} π_1^{−1} なので B の左端の Y^{−1} は ev(Y^{−1} F) = t^{−l(u_1)/2} ev(π_1^{−1} F) で済む。

### 4. 基底の変換と共有
- K_λ（D_N、data/refined_kauffman/koornwinder_DN の S_μ 表示を U = t^N で）と P_λ（GL_N、macdonald_P の冪和表示）を X の多項式にし、K_λ = Σ_ν x_ν H_ν を優勢な単項式の係数で解く（|ν| ≤ |λ|、GL_N では |ν| = |λ|）。小さな N で H_ν が一次従属なら解の一つを使う（γ̂ は線形なので値は変わらない）。
- 同じ (N, m) の λ の間で、対称な g と B^j g、評価値 {γ̂(H_ν)} を共有する。3 箱の重い作用は B·(B²·1)、B·(B·g_1)、B·g_{11}（g_1 = Π(B·1)、g_{11} = Π(B·g_1)）の 3 回だけ。
- GL_N の現行版は ρ = (N−1, …, 0) で評価している（正ルートの和の半分 ρ_GL = ((N−1)/2 − i) とは (N−1)/2·(1, …, 1) だけ違う）。高速版は φ で不変な ρ_GL で評価し、γ̂(P_λ)·1 が X の総次数 c = |λ|(mk + 1) で斉次（T・π は総次数を保ち、γ̂(X_{ε_1}) は総次数 mk + 1）なので t^{−c(N−1)/2} を掛けて現行版の値に直す。随伴は c = 0。

## 注意・未解決
- 高速版は daha_dn.DN / GLN の作用素をそのまま使う（daha_dn.py の規約を変えると両方に効く）。新しく書いたのは計算の順序、対称化 Π_σ、基底の変換、評価だけ。
- k（γ = τ_+^m τ_−^k）は k = 2 だけを照合した（D_N・GL_N とも）。k ≠ 2 も式は同じだが未検証。
- GL_N の値を現行版の規格化（ρ = (N−1, …, 0)）に直す因子 t^{−c(N−1)/2} は、γ̂(P_λ)·1 が総次数で斉次なことに基づく【導出】。照合したのは P_λ（|λ| ≤ 3）と随伴だけ。
- 小さな N（D_2 など）で H_ν が一次従属でも、解の一つを使えば値は同じ（N = 2, 3 で現行版と一致を確認）。
- さらに速くする余地：係数を gcd 付きの RF から Laurent 多項式（fmpz_mpoly と全体のずらし）に替えると 2 倍程度。最後の評価の B の T_{u_1} を点の評価の汎関数に置き換える案もある。いまの目標には不要なので実装していない。
