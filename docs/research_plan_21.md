# 研究計画（別研究）：非長方形の彩色 [2,1] の refined 不変量の構成と、3 箱の正値性

作成：2026-10-07。本研究（KN の refined large-N 双対性の非トーラス結び目への拡張、第 1〜4 期）から切り出した別の研究。
ユーザーの判断（2026-10-07）：本研究では [2,1] をここで打ち切り、別の研究として計画する。ステージ記号は W0〜W5。
長時間の計算は CLAUDE.md の規則（見積もり、高速化、再開、分割と並列、独立プロセス）に従う。

---

## 0. 出発点（本研究で分かったこと）

- **目的**：KN（1703.05408）の正値性予想を、トーラス結び目・代数的な iterated torus 結び目以外（特に双曲結び目）で、3 箱（|ρ| = 3）まで検証する。
  \hat f_ρ（|ρ| = 3）は |λ| ≤ 3 の全ての rCS_λ を使い、非長方形の [2,1] が欠けている。
- **定義どおりに得られる範囲**：トーラス結び目（EHA）と iterated torus 結び目（DAHA/EHA）。この範囲では 3 箱まで全て正（第 3・4 期：トーラス結び目は KN の表と本研究の 5 個、iterated torus は K1, K3, K6a, K7, K8, K9）。
- **構造的な条件では決まらない**：t = q（3 本ケーブルから）、ミラー、EGP、U(2) への簡約（既知）、Laurent 性、G 展開、正値性を課しても、
  解の差は δ = A⁴(A²−T⁴)(A²Q⁴−1)(Q²−1)(T²−1)(Q−T)(Q²T⁴−1)(Q⁴T²−1)·u/(Q⁵T¹¹) の形で、u は自由（REPORT_phase4.md §3）。
  他の特殊化、An. Morozov の一次ずれ公式、colored differential は新しい条件にならない。
- **弱い判定**（REPORT_phase4.md §6）：正値性を満たす [2,1] は 4_1（KN の候補）と 6_1 に存在する。5_2 は有理数解だけ（整数解は未決）。
- **文献**（docs/literature/a1_21_constructions.md）：定義・計算例・a 依存性がそろった構成は無い。
  [2,1] の定義があるのはホモロジー側の Cautis（1611.09924）と Elias–Hogancamp（1801.00191）だけで、双曲結び目の計算例は無い。
- **計算ソフト**：yui-kr（Nakagane–Sano 2111.00388）は彩色なしの HOMFLY-PT ホモロジーだけを計算する（2026-10-07 確認）。

## 1. 中心の問い

1. 双曲結び目の rCS_{[2,1]}（または自由な因子 u）を、**定義に基づいて**、あるいは**検証できる原理で**決められるか。
2. 決まった [2,1] で、3 箱の refined LMOV 不変量は G 展開の前後とも正整数か。
3. KN の rCS（index）と、ホモロジーの Poincaré 多項式は [2,1] でどう対応するか（[1] では一致、ツイスト結び目の genus 2 の refined CS では不一致：Arthamonov–Shakirov 1504.02620）。

## 2. ステージ

### W0：文献と既存ソフトの調査（ダウンロードは許可なしで可、ソフトの導入は許可が要る）

- 非長方形の彩色を扱う構成を、問い 1〜3 の観点で表にする。
  - ホモロジー：Cautis の clasp、Elias–Hogancamp の Young 冪等元、sl(N) の foam（sl(3) の随伴表現 = [2,1]）。
  - 物理・表現論：evolution 法（Mironov–Morozov–Morozov 1306.3197 など）の固有値と、その refined 版。knots–quivers の非対称表現への拡張の有無。Aganagic らのミラー対称性による構成。
  - 計算ソフト：彩色付きの sl(N) / HOMFLY-PT ホモロジーを計算できるもの（例えば khoca、foam の計算プログラム）の有無と、[2,1] に対応するか。
  - **ホモロジーを作らない構成**（2026-10-07 追加、ユーザーの指示）：本研究の主結果は、ホモロジーではない DAHA/EHA の [2,1] で BPS 不変量の段の正値性が成り立つことなので、双曲結び目でも同じ型の構成を探す。
    - 3d–3d 対応・Ẑ（F_K）の refined 版：Gukov–Manolescu 系の F_K、Ekholm–Gruen–Gukov–Kucharski–Park–Sułkowski 2005.13349（a 変形と t 変形）、Kucharski 2005.13394。双曲結び目で、彩色（特に [2,1]、高い階数）と t の精密化がどこまで定義・計算されているか。KN が引く GPV16・GPPV17 の正値性の現象との関係。
    - Cherednik の motivic superpolynomial（2607.25666「Instanton slices and their superpolynomials」）：双曲結び目（K12n242, K12n725 など）を含む非代数的な結び目に motivic な解釈を与える。彩色が minuscule に限られるかどうか、非 minuscule（[2,1]）への拡張の見通しを本文で確かめる。
    - 各構成について、(i) 双曲結び目での定義と計算例、(ii) 彩色と a 依存性、(iii) 本研究の rCS（index）の規約との対応、(iv) 正値性の主張（入力の段か BPS 不変量の段か）を表にする。
- 成果物：docs/literature/w0_21_survey.md。
- **停止点 0**：調査結果を報告し、W1〜W3 のどれを主軸にするかを決める。

> **W0 の結果（2026-10-08、docs/literature/w0_21_survey.md）**：定義に基づく双曲結び目の [2,1] は、どの系統の文献にも無い。W1 は修正が要る（ツイスト結び目の撚りは反平行なので固有値は [2,1]⊗[2,1]̄ で決まり、refined の規則は文献に無い。係数を決める情報も不足する見込み）。
> 新しい候補として「DAHA/EHA 型の構成（Cherednik の双曲 Coxeter 結び目、Galashin–Lam）の [2,1] への拡張」が挙がった。停止点 0 で主軸を決める。

### W1：refined evolution 法（主軸の候補、計算中心）

- 考え方：2 本の撚りの領域をもつ族（ツイスト結び目 K_p、double twist / pretzel K_{s,t}）では、彩色不変量が撚りの数について指数多項式になる。
  rCS_{[2,1]}(K_p) = Σ_j B_j(a,q,t) λ_j^p。固有値 λ_j は refined の framing の固有値（[2,1]⊗[2,1] の既約成分ごとの T 固有値）で、構成によらず決まる。
  本研究の V4 で、2 箱の \hat f が p について指数多項式になることを確認済み（根は 5 つ）。
- やること
  1. **固有値の決定**：トーラス結び目 T(2, 2k+1)（EHA で [2,1] まで定義どおりに計算できる）で、rCS_{[2,1]}(T(2,2k+1)) が k について指数多項式になり、その根が予想どおりかを確かめる。
  2. **係数の数え上げ**：族の中で [2,1] が定義どおりに分かる点（自明な結び目、T(2,·) などのトーラス結び目）と、構造的な条件（第 3・4 期の条件）で、係数 B_j が一意に決まるかを数える。
  3. **較正**：T(2,·) の族（全て分かっている）で、一部の点だけから残りを再現できるか。KN の 4_1 の候補（[2,1]）と一致するか。
  4. 一意に決まるなら、ツイスト結び目（4_1, 5_2, 6_1, 7_2, 8_1, …）の [2,1] を求め、3 箱の正値性を判定する。
- **停止点 1**：較正（1〜3）の結果を報告する。一意に決まらなければ、足りない条件の数を報告して止める。

### W2：ホモロジー側の [2,1]（重い。W0 の結果しだい）

- Elias–Hogancamp の [2,1] 冪等元（full twist の圏論的対角化で作る無限複体）を、4_1 の 3 本ケーブルに挿入した複体の、有限の近似を計算する。
- 前提：既存ソフトが使えなければ実装が要る（研究規模の開発）。yui-kr を土台にするなら Rust の導入（**ユーザーの許可**）が要る。
- 最初に規模を見積もる：3 本ケーブル（9 本・36 交点）＋冪等元の近似の複体の大きさ。24 時間を超える見込みなら報告して止める。
- 得られるのは Poincaré 多項式。KN の rCS との対応は W3 で扱う。

### W3：index と Poincaré 多項式の対応（解析的）

- [1] では \hat f_{[1]} = (a^{1/2} − a^{−1/2}) rCS_{[1]} が Poincaré 多項式。[2,1] で rCS（index）と Poincaré 多項式の差がどんな形になりうるかを、
  トーラス結び目（両方が分かる例）と Arthamonov–Shakirov の rank 1 の例で調べる。
- W2 の結果を KN の枠組みの入力に変換する規則を決める。

### W4：3 箱の正値性の判定

- W1 または W2＋W3 で得た [2,1] を入力に、双曲結び目の 3 箱の refined LMOV 不変量を G 展開の前後で判定する（第 3 期の u4 の判定と同じ）。
- 第 4 期 V5 の弱い判定（4_1, 6_1 で正の解あり）と整合するかを確かめる。

### W5：まとめ

- REPORT と novelty の確認（evolution 法の refined 版、[2,1] の Poincaré 多項式が既知かどうか）。
