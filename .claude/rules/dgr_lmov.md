# dgr_lmov の規則

目的・文書・コードの一覧は docs/dgr_lmov/README.md。規約は framed_knot と共通（docs/framed_knot/conventions.md）。

## framed_knot との違い
| 項目 | framed_knot | dgr_lmov |
|---|---|---|
| 目的 | KN の正値性予想の検証 | 新しい構造の発見と、構造からの構成・予言 |
| refined LMOV の正値性 | 検証の対象（予言として確かめる） | 構成の条件に使ってよい（2026-10-11、ユーザーの指示「この計画では refined LMOV に正値性は課して良い。今回は KN の検証をする計画ではなく新しい研究である」） |
| rCS の正値性 | rCS の候補を選ぶ際に課さない（docs/framed_knot/open_problems.md §F） | §F は適用しない（2026-10-11、ユーザーの指示「今回は研究自体が異なるので衝突しない」）。Poincaré 多項式である rCS（対称表現など）には課してよい。非長方形の rCS は負の係数をもつので、数学的な理由で課さない |
| 停止点 | docs/framed_knot/research_plan*.md | docs/dgr_lmov/research_plan.md の §3 |

framed_knot の novelty_report.md で既知とされた結果は、このテーマでも成果として書かない。

以下は「unrefined の LMOV（t = q の彩色 HOMFLY-PT）から refined の非長方形の彩色（[2,1], [3,1]）を一意に予想する」方向について、2026-10-14 時点の結論を記録したものである（ユーザーの判断）。記録は docs/dgr_lmov/ の report.md・progress.md・open_problems.md・novelty.md にある。

## 結論：この方向の研究は筋が悪い

unrefined のデータから refined の [2,1]・[3,1] を一意（高々 O(1) 個）に予想することは、ここまでに試した条件では達成できず、
達成できない理由も構造的であることが分かった。この方向をそのまま続けることは勧めない。
以下の結論を覆す新しい入力や原理が無い限り、同じ方向の計算（条件を足して自由度を数える、候補を列挙する）を増やさない。

## 理由（いずれも report.md D11・D12 に記録。分類は【計算】か【導出】）

1. **一次の条件は閉じない**【計算】。t = q、転置、EGP、a = t²、hook、3 箱・4 箱の \hat f の Laurent 性、窓（台と予想 R）を全部課しても、
   [2,1] が一意に決まるのは三葉結び目と 4_1 だけである。T(2,5) で自由度 20、T(2,7) で 90、T(3,4) で 560。
   残る自由度は具体的な核 Φ·g で、t = q で消える（打ち消し合う）対の付け替えに当たる。unrefined のデータは原理的にこの対を見ない。
2. **4 箱の整数性は [2,1] を削らない**【計算】。[3,1] を既知とすれば一部を削る（T(2,5) 20 → 12）が、[3,1] も未知の連立では
   [3,1] の自由度が [2,1] の変化を補償し、T(2,5)・K_2・K_{−2} のどれでも [2,1] への射影の次元は変わらない。
   箱の数を増やす方向に進んでも、未知数の増え方が条件の増え方を上回る。
3. **\hat f の正値性は上界を与えない**【計算・導出】。正値性の多面体の後退錐は framing で不変で、spin・genus・既約表示のどの表示でも非有界である。
   KN 型の正値性は refined 不変量の「必要条件」としては意味をもつが、構成の条件としては自由度を殺さない。
4. **上界を与える条件はいずれも追加の仮説である**。S（仮説 H_u″：P 正規化の hook の Schur 係数の冪級数の非負性）は代数的な結び目では成り立つが、
   4_1 と負の側のツイスト結び目で破れる。BPS 総数の最小化 ＋ framing は選択の原理であって不変量の性質ではなく、[1] の段階で既に
   9_42 のような thick な結び目で誤る（階数 7 対 9。打ち消し合う対は Khovanov の入力でしか決まらない）。
   どちらも T(2,5) までは正解を再現するが、T(2,7)・T(3,4) では候補が 100 以上残る。
5. **DGR の微分の構造は使い切っている**。微分 d_{n|m} は特殊化 a = tⁿq^{−m} として全て一次の条件に入っている。
   微分の「対」の構造が効くのは未知数が非負の Poincaré 多項式のときだけで、非長方形の rCS は非負でない（N_λ ≥ 0 ⇔ λ 長方形）。
   σ で商をとった BPS の言葉では、各微分が自分のホモロジーを残す正の分解も存在しない（D6）。
6. **予言の価値が低い**。K_2 の [2,1] は 2 つの仮説の下で一意だが独立な検証が無く、K_{−2} は仮説の一方を破る。入力のツイスト結び目の rCS 自体も予想式である。
   独立な検証ができる見込み（彩色 [2,1] のホモロジーの計算）は当面無い。
7. **外部のホモロジーの入力に頼らない**という設定の下では、1 と 4 により、この問題は原理的に unrefined のデータだけでは決まらない問題である。

## この研究から残すもの（別の枠で扱う）

否定的な結論と切り離せば、次は価値がある。扱うときは「unrefined から refined を予想する」枠ではなく、「代数的な結び目の彩色 refined 不変量の正値性」の枠で扱う。
- 仮説 H_u″（P 正規化の hook の Schur 係数の冪級数の非負性、代数的な結び目で 6 箱まで）。Mellit の定理の非長方形への拡張の予想。文献調査と導出が先。
- 予想 S（彩色の既約表示の非負性）、framed の refined LMOV の正値性、予想 R（𝐭 の両端の線の規則）。
- 【導出】G 展開が閉じる ⇔ σ 不変 ⇔ KN の整合条件。核 Φ·g による「unrefined が見ない自由度」の特徴づけ。
- framed_knot の側の命題 2（2 箱の Laurent 性 ⇒ dim H^{[2]} = (dim H^{[1]})²）と 9_42 の説明。

## 作業上の注意

- 大きな計算（4 箱の連立、760 次元の MILP など）をこの方向のために新たに始めない。始めるならユーザーの指示を得る。
- 既存の結果を書き直すときは、撤回した主張（剰余のバグによる「全て殺す」「零空間 0」）を復活させない。
- 剰余の行を Python の辞書で全部メモリに載せない（1 ρ で 14 GB）。scripts/dgr_lmov/lmov4_predict.py の CSR・RREF の経路を使う。
